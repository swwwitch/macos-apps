# InputMaestro

通常版 0.1.3（4）。macOS 13以降。

ControlMateの編集キー、FnNumpadのテンキー入力、ShotSorterの範囲選択による文字認識を新しいアプリに統合。元の3アプリ・設定・配布物は保持し、設定を自動取り込みしません。

- 編集キーとテンキーは個別に有効化。テンキー変換→編集キーの順で、単一イベントタップから処理。
- テンキーの初期トリガーはJIS・ANSIともfn。編集キーはANSI＝Control、JIS＝Caps Lock。テンキーにもCaps Lockを指定するとテンキー変換が優先。
- ControlMate／FnNumpadが起動中なら、対応する統合機能を停止。旧アプリの終了や設定変更は行いません。
- 文字認識は範囲選択→日本語／英語のローカル認識→和文間空白・全角括弧の整形→結果表示。自動コピーはOFFにもできます。認識中に利用者が別のものをコピーした場合は結果を自動コピーせず表示。
- OCRホットキーは⌘⇧1。メインの文字認識タブで変更できます。保存した別キーや明示的な解除は維持します。文字認識OFF・対象外アプリでは登録しません。
- アクセシビリティが未許可ならキー変換は行いません。範囲選択には別途画面収録の許可が必要。権限スイッチは自動変更しません。
- ログイン起動は初期値OFF。手動起動・開き直しは画面表示、ログイン起動は非表示。
- 設定は⌘,、ウインドウを閉じる操作は⌘W、終了は⌘Q。閉じても常駐するかは設定可能。
- 機能設定の書き出し・同期に対応。起動・常駐・ホットキー・対象外アプリはMacごと。クリップボードや認識結果を同期しません。
- InDesignの編集支援では必要に応じて既存のAutomation処理を使用。スクリプト未配置時は元実装のキー操作へフォールバック。

## ビルド・検証

`NO_DEPLOY=1 SKIP_PUBLISH=1 ./build.sh` でワークスペース内の `InputMaestro.app` を作成。既存の共有部品とUpdaterを利用。配信設定が未設定の間、更新確認は準備中で通信しません。開発ビルドは実行MacのCPU向けです。

`Tests/run.sh` で編集キー・テンキー・統合ルーティング・OCR整形・Vision認識・4言語を検証。VisionテストはOSサービスに接続できる環境で実行します。キー処理テストはイベントをメモリ内で扱い、他アプリに送信しません。

公証・Universal配布ビルド・DMG・配置・公開は公証担当Macで実施。今回の確認範囲は `RELEASE-VERIFICATION-20261101-BUILD4.md`、初版は `RELEASE-VERIFICATION-20261101.md` を参照。

## 画面構成

メインはテンキー入力・編集キー・文字認識・修飾キー・矢印キー、設定は起動・常駐・テンキー入力・編集キー・アプリ対応・設定の共有・情報の順です。メインの編集キー・テンキー入力は、各タブ内で「キーを置き換える」を設定します。キーボード表は上揃え。テンキー配列は青、数字列は緑、演算記号はオレンジ、編集キーは紫で表示します。色は保存された有効設定を示します。

文字認識にも独立したON/OFFを用意し、整形・ホットキー設定と処理状態はメインに集約。実行はホットキーのみとし、実行ボタン・結果欄・コピーボタン・説明グループは設けません。完了時にもメイン画面を前面化しません。設定に文字認識タブは設けず、画面収録の状態と設定ボタンは「起動・常駐」へ配置します。「アプリ対応」タブでは全機能の除外と編集キーのグループ別素通しを同じ場所で管理し、既存の保存キーと適用範囲を保持します。

⌃⌘Xは、折り返しを越えて段落先頭まで選択してコピーします。段落先頭では何もせず、AXで取得・選択できないときは失敗を表示します。InDesignは同アプリの段落先頭選択キーを使います。保存済みの機能ON/OFFを保持するため、内部IDはcopyToLineStartを維持します。

## 修飾キーと矢印キー

メインの「修飾キー」「矢印キー」の2タブで、InsertSnippetsと同じ8記号を入力するホットキーを設定できます。⌥⇧J/K/L/Iで⌃/⌥/⌘/⇧、⌃⌥⇧J/K/L/Iで←/↓/→/↑を文字として入力します。共通の記録欄で変更・解除可能。機能OFF・一時停止・対象外・自アプリ・AX未許可では実行しません。他アプリとの登録競合は欄に表示します。クリップボードは入力後に復元し、利用者の新しいコピーを上書きしません。個人スニペットは移植対象外です。

## 矢印の入力方法

初期値は「カスタム」で、保存済みホットキーを保持します。「Google日本語入力準拠」では英字入力でzh→←、zj→↓、zk→↑、zl→→と変換します。zは通常どおり入力し、直後の文字が一致した場合だけzを置き換えます。不一致・クリック・カーソル移動・入力先変更・入力モード変更で候補を解除します。日本語IMEの未確定文字は操作せず、IME側の入力へ通します。Google日本語入力をインストール・設定変更する機能ではありません。

コピー3機能は従来キーに加えて、⌃⇧←（段落先頭）・⌃⇧→（段落末尾）・⌃⇧⌘→（文章末尾）にも対応します。追加キーは物理Controlで動作し、各機能のON/OFF・対象外・素通し設定は従来キーと共通です。

## 0.1.3の整理

メイン上部の通常の3行を削除し、必要な警告は各タブへ表示します。全5機能を一時停止・再開でき、機能別ON/OFFは保持されます。認識中に停止したOCR結果は保持し、自動コピーは行いません。配列選択は設定の起動・常駐に1箇所だけ用意し、両キーボード図へ共通適用します。設定検索とホットキー一覧は設定画面で使用でき、一覧への入口はメインにもあります。
