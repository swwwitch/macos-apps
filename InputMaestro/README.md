# InputMaestro

通常版 0.1.0（1）。macOS 13以降。

ControlMateの編集キー、FnNumpadのテンキー入力、ShotSorterの範囲選択による文字認識を新しいアプリに統合。元の3アプリ・設定・配布物は保持し、設定を自動取り込みしません。

- 編集キーとテンキーは個別に有効化。テンキー変換→編集キーの順で、単一イベントタップから処理。
- テンキーの初期トリガーはJIS・ANSIともfn。編集キーはANSI＝Control、JIS＝Caps Lock。テンキーにもCaps Lockを指定するとテンキー変換が優先。
- ControlMate／FnNumpadが起動中なら、対応する統合機能を停止。旧アプリの終了や設定変更は行いません。
- 文字認識は範囲選択→日本語／英語のローカル認識→和文間空白・全角括弧の整形→結果表示。自動コピーはOFFにもできます。認識中に利用者が別のものをコピーした場合は結果を自動コピーせず表示。
- OCRホットキーは初期値未設定。設定の記録欄から割り当てます。ShotSorterの既定キーを自動で取得しません。
- アクセシビリティが未許可ならキー変換は行いません。範囲選択には別途画面収録の許可が必要。権限スイッチは自動変更しません。
- ログイン起動は初期値OFF。手動起動・開き直しは画面表示、ログイン起動は非表示。
- 設定は⌘,、ウインドウを閉じる操作は⌘W、終了は⌘Q。閉じても常駐するかは設定可能。
- 機能設定の書き出し・同期に対応。起動・常駐・ホットキー・対象外アプリはMacごと。クリップボードや認識結果を同期しません。
- InDesignの編集支援では必要に応じて既存のAutomation処理を使用。スクリプト未配置時は元実装のキー操作へフォールバック。

## ビルド・検証

`NO_DEPLOY=1 SKIP_PUBLISH=1 ./build.sh` でワークスペース内の `InputMaestro.app` を作成。既存の共有部品とUpdaterを利用。配信設定が未設定の間、更新確認は準備中で通信しません。開発ビルドは実行MacのCPU向けです。

`Tests/run.sh` で編集キー・テンキー・統合ルーティング・OCR整形・Vision認識・4言語を検証。VisionテストはOSサービスに接続できる環境で実行します。キー処理テストはイベントをメモリ内で扱い、他アプリに送信しません。

公証・Universal配布ビルド・DMG・配置・公開は公証担当Macで実施。現在の確認範囲は `RELEASE-VERIFICATION-20261101.md` を参照。
