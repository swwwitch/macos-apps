# UX点検（2026-10-10）

BASELINE.md の B23〜B28 と、既存の B04・B06・B08・B09・B11・B14 の観点で全16本のソースを読んで点検した記録。実機での操作確認ではない。行番号は点検時点のもの。

判定：✓ 満たす／△ 一部／× 満たさない／対象外

点検項目：1 開き直し（B04・B23）、2 ⌘Tab（常駐アプリのみ、B23）、3 設定（B06・B24）、4 キーボード（B06・B27）、5 メニューバー（MenuBarPresence）、6 画面外復帰（B08・B28）、7 権限（B09）、8 VoiceOver（B14・B28）、9 外観（B14・B28）、10 失敗の伝え方（B11・B12・B27）

## 共通部品で確認したこと

- メニューバーアイコンは `Shared/MenuBarPresence/MenuBarPresence.swift` でテンプレート画像になり、非表示にできる。
- 設定タブ（`SettingsSection.swift` の SettingsUI.tabs／SettingsTabs）は選んだタブを保存しない。起動中は同じウインドウを使い回すので前回のタブで開くが、再起動すると先頭に戻る（全アプリ △）。
- 背景色 `AppSurface` は外観に追従する。
- 通常アプリ8本ではアニメーションは見当たらず、「視差効果を減らす」は該当しない。

## 優先して直す点

1. **設定のタブを再起動後も覚えていない（全アプリ）**：共通部品 SettingsUI.tabs／SettingsTabs に選択タブの保存・復元を入れれば一括で直る。MightyEdit（独自 NSTabView）と BrowserSwitcher（シートを毎回作り直す）は別途。
2. **VoiceOver で読めない部品**：KageTrimmer の DropView とホットキーのポップアップ、ExtensionLinker の再読み込み・検索クリア、FileCaravan の入れ替え、CarmaChameleon のドロップ領域。
3. **Esc で閉じない**：BrowserSwitcher の設定シート、PodiumFlight のアプリ一覧シート、KakkoReplace・MightyEdit のパレット類、FileCaravan の移動確認、MenuBarPresence の追加確認（「あとで」）。
4. **beep だけで理由が出ない**：FolderHopper（:466 ほか）、CommandDee（:44-45、:238）、KakkoReplace（:134）、KageTrimmer（:112）、BrowserSwitcher（:394）。
5. **初回・画面外のウインドウ位置**：KeynoteSweeper・PDF2Keynote・CarmaChameleon は初回の center がない。PodiumFlight は画面内かを見ていない。SwiftUI の WindowGroup 3本（QuickIconExporter・BundleIDInspector・PrefsPreset）と ExtensionLinker は明示チェックなし。
6. **権限の案内にボタンがない**：CarmaChameleon（Illustrator / Photoshop / InDesign）、FolderHopper・PodiumFlight（オートメーション）。
7. **細かい点**：FolderHopper の開き直しが処理中に前面に出ない。設定タイトルの元キー「環境設定」（FolderHopper・QuickIconExporter）。固定色の tint（CarmaChameleon・KeynoteSweeper・PDF2Keynote）。アニメーションと「視差効果を減らす」（QuickIconExporter・BundleIDInspector）。BrowserSwitcher のホットキーだけ「適用」が必要。KakkoReplace のメニューバーアイコンが文字。
