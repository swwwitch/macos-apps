# 設定同期 v2

同期先は既存の選択フォルダーを引き継ぎ、`<App>-Settings.sync/<UUID>.plist` へ変更履歴を追加する。作成済みファイルと旧 `<App>-Settings.plist` は上書きしない。旧競合コピーは自動採用・削除しない。

設定キーごとの変更と削除を記録し、論理変更番号、同番号ならUUIDの辞書順で勝者を決める。別キーの同時変更は両方を反映する。配列やDataは一つの設定値として扱い、一覧の要素単位の統合はしない。既存履歴は保持するため、同時変更で不採用になった値もファイル内に残る。時計のずれは競合解決に影響しない。

最初の移行時だけ旧plistを参照する。旧形式の最終同期日時より新しい他Macの保存済み設定があれば初期値として採用し、このMacの未送信変更は差分として重ねる。新形式の履歴があれば旧plistの更新は無視する。全Macのアプリを対応版へ更新すること。旧版との双方向同期は行わない。競合コピーの設定を使いたいときは既存の「読み込む…」で内容を確認して取り込む。

受信した設定は共有キーだけを反映し、受信しただけで履歴を再生成しない。最後に観測した設定をMac固有のUserDefaultsへ保持し、再起動後の未送信変更も差分として送る。バックグラウンド処理中の追加変更は保存後に次の差分へ回す。書き込み失敗時には基準値を更新せず再試行する。未完了・破損履歴を検出した場合は設定を置き換えずエラーを表示する。

同期を停止・フォルダーを変更した後は古い読み取り結果を画面へ適用しない。停止前に始まったファイルI/Oは完了する場合があるが、以降の書き出しは停止する。選択フォルダーのsecurity-scoped bookmarkを引き続き使用する。

既存の「書き出す…」は単独で読み込める従来形式のplistを作る。v2の履歴ファイルそのものは書き出し用plistの代わりにはしない。履歴の自動削除・圧縮は行わない。

検証: `zsh Shared/SettingsSync/test.sh`。2つの独立した一時フォルダーをMacのオフライン状態に見立て、ファイル交換後の収束、削除・復元、初期移行、遅れた移行、I/O失敗を確認する。本物の複数MacとDropboxの遅延・再起動を含む実機検証は別途必要。
