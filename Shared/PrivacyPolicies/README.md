# 公開用HTML

- 6アプリ分のサポート・プライバシーポリシーと一覧ページを収録しています。
- HTMLだけで表示でき、外部フォント、JavaScript、アクセス解析を含みません。
- 各アプリ名のHTMLをWebサーバーへ公開し、その公開URLをApp Store ConnectのプライバシーポリシーURL・サポートURLに登録してください。
- ローカルのファイルパスは申請用URLにできません。Web公開は未実施です。
- BrowserSwitcher・ExtensionLinkerはHomebrew等をインストールしないApp Store版を対象とします。
- PodiumFlightは現在のソースに基づきます。申請用ビルドで機能が変わる場合は、本文も合わせて更新してください。
- 公開先サーバーのアクセスログや解析機能は別途確認してください。このHTML自体に解析機能はありません。
- 元のMarkdownは変更せず、QuickIconExporterの仮メールアドレスと旧名称はHTMLで修正しました。
