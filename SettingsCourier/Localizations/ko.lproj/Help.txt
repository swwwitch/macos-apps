SettingsCourier는 등록한 앱의 설정(defaults)을 하나의 파일로 내보내고 다른 Mac에서 가져오는 앱입니다. App Store 앱처럼 설정이 샌드박스 컨테이너에 있는 앱도 지원합니다.

## 사용 방법
### 앱 등록
1. 왼쪽 목록 아래의 ‘+’를 클릭하거나 파일 > 앱 추가…를 선택합니다. 앱을 목록이나 Dock의 SettingsCourier 아이콘에 놓아도 등록됩니다.
2. 목록에서 앱을 선택하면 오른쪽에 설정의 키·유형·값과 설정 파일의 위치가 표시됩니다.

### 내보낼 키 선택
- ‘내보내기’ 열의 체크상자로 내보낼 키를 선택합니다. 여러 행을 먼저 선택한 뒤 체크상자를 클릭하면 선택한 행을 한꺼번에 전환합니다. 오른쪽 클릭으로 **내보내기**·**내보내지 않음**을 선택할 수도 있습니다.
- 창 위치·메뉴 막대 순서·업데이트 확인 기록 등 Mac마다 다른 키와 날짜 값(최초 실행일 등)은 처음부터 선택 해제되어 있습니다. 필요하면 선택하십시오.
- ‘처음 선택으로 되돌리기’를 누르면 해당 앱의 선택을 처음 상태로 되돌립니다.

### 함께 옮길 파일
- 설정 파일 밖에 데이터를 두는 앱(Default Folder X의 즐겨찾기 등)은 오른쪽 아래 ‘함께 옮길 파일’의 ‘파일 추가…’로 그 파일을 선택하면 설정과 함께 내보내고 가져옵니다. 홈 폴더 안의 파일만 옮길 수 있습니다(파일당 20MB까지).
- Default Folder X를 등록하면 사용 중인 폴더 세트의 즐겨찾기(Favorites.plist)를 자동으로 추가합니다. 이미 등록되어 있으면 ‘추천’으로 표시되므로 ‘추가’를 누릅니다.
- 가져올 때는 파일의 현재 내용도 백업한 뒤 기록합니다. 되돌리면 가져오기로 늘어난 파일은 삭제합니다.
- 즐겨찾기 등에는 폴더 위치가 들어 있습니다. 사용자 이름이나 폴더 구성이 다른 Mac에서는 가져와도 열리지 않는 항목이 있습니다.

### 내보내기
1. 왼쪽 목록에서 내보낼 앱을 선택하고 ‘내보내기…’(⌘S)를 누른 뒤 저장 위치를 선택합니다. 그 앱의 선택한 키 값을 ‘<앱 이름>.settingscourier’ 파일로 저장합니다. 목록의 앱을 오른쪽 클릭하고 **내보내기…**를 선택해도 됩니다.
2. AirDrop·iCloud Drive·Dropbox 등으로 파일을 다른 Mac에 전달합니다.

- 목록에서 ⌘클릭·⇧클릭으로 여러 앱을 선택한 뒤 ‘한꺼번에 폴더로 내보내기’를 누르면 앱마다 파일을 한꺼번에 내보냅니다. 파일 > 모든 앱 내보내기는 등록한 앱을 모두 내보냅니다. 동기화 폴더를 선택하지 않았으면 내보낼 폴더를 선택합니다.

### 가져오기
1. 다른 Mac에서 .settingscourier 파일을 이중 클릭하거나 ‘가져오기…’(⌘O)로 엽니다. 윈도우에 놓아도 열립니다.
2. 앱마다 이 Mac의 현재 값과 비교한 변경·추가 개수가 표시됩니다. 가져올 앱의 체크상자를 켜고 ‘가져오기’를 누릅니다. 이 Mac에서 내보내지 않기로 한 키는 기록하지 않습니다.
3. 가져올 앱이 실행 중이면 종료해도 되는지 확인한 뒤 종료하고, 기록한 뒤 다시 엽니다. 실행 중인 앱은 종료할 때 설정을 다시 기록하므로 종료하지 않고 기록하면 원래대로 돌아갑니다.
4. 가져온 앱은 목록에 등록됩니다.
- ‘가져오기…’에서는 여러 파일을 선택할 수 있습니다. 하나의 확인 화면으로 합치며, 같은 앱이 겹치면 나중에 내보낸 것을 사용합니다. 백업 파일은 하나씩 엽니다. ‘폴더에서 가져오기…’ 목록에서는 ‘모두 선택’을 쓸 수 있습니다.

### 폴더로 주고받기
1. 설정의 ‘설정 공유’ > ‘설정 동기화’에서 Dropbox·iCloud Drive 등 다른 Mac과 동기화하는 폴더를 선택합니다(메인 윈도우 아래의 ‘동기화 폴더 선택…’으로도 선택할 수 있습니다). 주고받기에는 그 안의 SettingsCourier 폴더를 사용합니다. 두 Mac에서 같은 폴더를 선택하십시오.
2. 폴더를 선택하면 오른쪽 아래 버튼이 ‘폴더로 내보내기’(⌘S)가 되어, 선택한 앱의 설정을 ‘<앱 이름>.settingscourier’로 폴더에 둡니다. 같은 앱의 이전 이름 파일은 교체합니다. 저장 위치를 골라 내보내려면 파일 > 파일로 내보내기…(⇧⌘S)를 사용합니다.
3. 다른 Mac에서도 같은 폴더를 선택합니다. 이 Mac의 설정보다 새로운 파일이 있으면 목록의 앱에 ‘새 설정이 있습니다’가 표시되고 아래에 개수가 나옵니다.
4. ‘폴더에서 가져오기…’로 가져올 앱을 선택하고 ‘다음…’으로 가져오기 확인으로 넘어갑니다. 아직 등록하지 않은 앱도 가져올 수 있습니다(가져오면 등록됩니다).
5. ‘등록한 앱을 종료할 때 내보내기’를 켜면 앱을 종료할 때마다 폴더로 내보냅니다. 값이 바뀌지 않았으면 기록하지 않습니다. 가져오기는 자동으로 하지 않습니다.
- 새로운지는 파일을 내보낸 시각을 이 Mac의 설정 파일이 마지막으로 바뀐 시각 및 이 Mac에서 마지막으로 가져온 파일의 시각과 비교해 판단합니다. 이 Mac에서 내보낸 파일, 이미 가져온 파일, 이 Mac과 같다고 확인한 파일에는 ‘새 설정이 있습니다’를 표시하지 않습니다.
- 설정 파일을 심볼릭 링크로 공유하는 방법은 쓰지 않습니다. macOS는 설정을 저장할 때 링크를 일반 파일로 바꾸므로 공유가 끊어집니다.

## 백업과 복원
- 가져오기 전에 바꿀 앱의 현재 설정을 모두 ~/Library/Application Support/SettingsCourier/Backups/에 저장합니다. 파일 > 백업 폴더 보기로 열 수 있습니다.
- 백업 파일을 가져오면 해당 앱의 설정을 가져오기 전 상태로 되돌립니다(가져오기로 늘어난 키는 삭제합니다).
- 목록에서 제거해도 앱의 설정 자체는 바뀌지 않습니다.

## 설정
메인 윈도우의 ‘설정’ 버튼(⌘,)으로 엽니다.
- **실행·상주**: 전체 디스크 접근 권한 상태와 설정을 여는 버튼. 로그인 시 열기, 시작 시 메인 윈도우 가리기, Dock 및 앱 전환기에서 가리기, 메뉴 막대에 표시. ‘Dock 및 앱 전환기에서 가리기’를 켜면 Dock과 ⌘Tab 전환에 아이콘이 나타나지 않습니다. 메뉴 막대 아이콘(표시 중일 때)이나 Finder에서 앱을 다시 열면 표시할 수 있습니다
- **설정 공유**: 등록한 앱 목록과 내보낼 키 선택을 내보내고 가져오며, iCloud Drive·Dropbox 등의 폴더로 다른 Mac과 동기화합니다. 그 아래의 ‘등록한 앱을 종료할 때 내보내기’로 종료 시 자동 내보내기를 켜고 끕니다(마지막 결과도 표시). 앱 설정은 동기화 폴더 안의 SettingsCourier 폴더로 주고받습니다. 앱의 설정 값은 자동으로 가져오지 않습니다.
- **정보**: 버전과 링크.

## 단축키
- **⌘O**: 가져오기
- **⌘S**: 내보내기(동기화 폴더가 있으면 폴더로)
- **⇧⌘S**: 파일로 내보내기
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: SettingsCourier 도움말
- **⌘Q**: SettingsCourier 종료

## 접근 권한과 개인정보
- 손쉬운 사용 권한은 필요하지 않습니다.
- 샌드박스 앱(App Store 앱 등)의 설정을 읽으면 macOS가 다른 앱의 데이터 접근을 확인합니다. 이 확인은 Mac을 재시동할 때마다 표시되므로 SettingsCourier는 열기만 해서는 읽지 않고 ‘설정 읽기’·내보내기·가져오기를 누를 때 읽습니다. 설정의 ‘실행·상주’에서 전체 디스크 접근 권한을 허용하면 확인 없이 읽습니다.
- 접근을 허용하지 않으면 해당 앱의 내보내기·가져오기를 중단합니다(빈 설정으로 취급하지 않습니다).
- 설정은 macOS의 설정 구조(cfprefsd)를 통해 읽고 씁니다. 설정 파일을 직접 고치지 않습니다.
- 내보낸 파일에는 앱 설정 값이 그대로 들어갑니다. 라이선스 정보나 계정 이름 등이 포함될 수 있으므로 보관 장소와 전달 상대에 주의하십시오.
- 네트워크 통신은 하지 않습니다(‘업데이트 확인…’ 제외).

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하거나 ⌘0으로 메인 윈도우를 다시 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 켜면 메뉴 막대 아이콘에서도 ‘메인 윈도우 열기’, ‘설정…’, ‘도움말’을 선택할 수 있습니다.
- 종료하려면 앱 메뉴의 ‘SettingsCourier 종료’(⌘Q)를 선택합니다.
- 앱 메뉴의 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다. 배포 준비가 끝날 때까지는 업데이트 배포 준비 중으로 표시되며 통신하지 않습니다.

## 문제 해결
- 설정이 표시되지 않으면 해당 앱을 한 번 열어 설정을 바꾼 뒤 ‘다시 읽기’를 누르십시오. 설정 파일은 앱이 처음 설정을 저장할 때 만들어집니다.
- 가져왔는데 반영되지 않으면 해당 앱을 종료한 뒤 다시 가져오십시오. 종료 확인에서 ‘취소’를 선택하면 기록하지 않습니다.
- ‘이 Mac에 없음’으로 표시되는 앱은 이 Mac에 설치되어 있지 않습니다. 설치하고 한 번 연 뒤 가져오십시오. 샌드박스 앱은 처음 열 때 설정 위치(컨테이너)가 만들어집니다.
- 가져온 뒤 앱이 이상하게 동작하면 백업 파일을 가져와 되돌리십시오.

## 도움말과 note 글
- 이 도움말은 도움말 > SettingsCourier 도움말(⌘?)로 엽니다.
- 도움말 > note 글 열기를 선택하면 note의 해설 글을 브라우저에서 엽니다.

## 앱 삭제
1. ‘로그인 시 열기’를 끕니다.
2. ‘SettingsCourier 종료’를 선택합니다.
3. SettingsCourier를 휴지통으로 옮깁니다. 백업은 ~/Library/Application Support/SettingsCourier에 남으므로 필요 없으면 삭제합니다.
