# 【macOSアプリ】アプリの設定をほかのMacへ運ぶ「SettingsCourier」を作りました

Macを使い分けていると、アプリの設定を変えたあと、もう1台でも同じ設定にし直すことがあります。

アプリごとの設定を書き出し、ほかのMacで取り込むためのアプリ「SettingsCourier」を作りました。

## 運びたい設定を選ぶ

「＋」ボタンやドロップでアプリを登録すると、設定のキー・種類・値を確認できます。「書き出す」のチェックボックスで、ほかのMacへ運ぶ項目を選びます。

ウインドウの位置などMacごとに異なる項目や、日付の値は初めから外しています。必要な項目は、自分でチェックを入れられます。

## 書き出して、ほかのMacで取り込む

1. 一覧でアプリを選び、「書き出す…」で保存します。
2. 作成された「アプリ名.settingscourier」ファイルを、AirDropやDropboxなどでほかのMacへ渡します。
3. 受け取ったMacで「取り込む…」を選び、変更・追加される内容を確認して取り込みます。

取り込み前に、現在の設定をバックアップします。対象アプリが起動中なら、確認して終了し、書き込み後に起動し直します。

## 同期フォルダーを使う

設定の「設定の共有」でDropboxなどのフォルダーを選ぶと、その中の「SettingsCourier」フォルダーを受け渡しに使えます。ほかのMacでも同じフォルダーを指定します。

複数のアプリを選んでまとめて書き出したり、「フォルダーから取り込む…」で取り込むアプリを選んだりできます。「登録したアプリを終了したときに書き出す」をオンにすると、終了時に自動で書き出します。

取り込みは自動では行いません。受け取るMacで内容を確認してから実行します。

## お気に入りのファイルも一緒に

設定ファイルの外にあるデータは、「一緒に運ぶファイル」に追加できます。ホームフォルダー内のファイルが対象で、1つ20MBまでです。

Default Folder Xでは、使用中のフォルダーセットのお気に入り（Favorites.plist）を追加できます。お気に入りに含まれるフォルダーの場所はそのままなので、Macごとにユーザー名やフォルダー構成が異なる場合は、取り込んだあとに確認してください。

## バックアップから戻せます

ファイルメニューの「バックアップフォルダを表示」で、取り込み前のバックアップを開けます。バックアップのファイルを取り込むと、取り込み前の状態に戻します。設定と一緒に運んだファイルも復元の対象です。

## 使う前に知っておきたいこと

- 対象はアプリの設定と、自分で追加したファイルです。Macの環境全体を移行するものではありません。
- App Storeのアプリなどでは、設定を読むときにmacOSからアクセス許可を求められる場合があります。アクセシビリティの許可は不要です。
- 書き出したファイルには設定値が入ります。ライセンス情報やアカウント名を含む場合があるので、共有する項目と保存先を確認してください。
- 自動アップデートの配信は準備中です。

macOS 14以降・Appleシリコン対応。
