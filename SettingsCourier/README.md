# SettingsCourier

登録したアプリの設定（defaults）をアプリごとのファイルに書き出し、ほかのMacで取り込むユーティリティです。App Storeのアプリなど、設定がサンドボックスのコンテナにあるアプリにも対応します。

- 一覧にアプリを登録（＋ボタン・ドロップ・Dockアイコンへのドロップ）すると、設定のキー・種類・値と設定ファイルの場所を表示
- 書き出すキーをチェックボックスで選ぶ。ウインドウの位置・メニューバーの並び・アップデート確認の記録などMacごとに異なるキーと、日付の値は初めから外す
- 「書き出す…」で選んでいるアプリを `<アプリ名>.settingscourier` に保存。「設定の共有」で同期フォルダー（Dropbox など）を選ぶと「フォルダーに書き出す」になり、その中の SettingsCourier フォルダーに置く。ほかのMacでは「フォルダーから取り込む…」で新しい設定を選んで取り込む
- 取り込みは確認画面で変更・追加の件数を示し、今の設定をバックアップしてから書き込む。起動中のアプリは確認して終了し、書き込み後に起動し直す。書き込んだ値は読み直して確かめる
- バックアップのファイルを取り込むと、取り込む前の状態に戻る（取り込みで増えたキーも消す）
- 「一緒に運ぶファイル」で、設定ファイルの外にあるデータ（Default Folder X のお気に入りなど）も一緒に運ぶ。Default Folder X は登録すると自動で追加
- 「登録したアプリを終了したときに書き出す」で、終了のたびに受け渡しフォルダーへ自動で書き出す（値が同じなら書かない）。取り込みは自動では行わない

通信はしません（アップデート確認を除く）。アクセシビリティの許可は不要です。

## ビルド

```sh
./build.sh            # ビルド → 検証 → /Applications と Latest Builds へ配置
NO_DEPLOY=1 ./build.sh  # 配置せず build/ にだけ作る
```

- SwiftPM（`Package.swift`）。ソースは [Sources/SettingsCourier](Sources/SettingsCourier/)、文字列・ヘルプは [Localizations](Localizations/)（ja / en / zh-Hans / ko）。
- 共通部品（AboutSection・AppSurface・StartupWindow・SettingsSection・HelpDocument・MenuBarPresence・LoginAtLaunch・SettingsSync・UpdateSupport）は各 `sync` スクリプトがビルド時に上書きするので、直接編集しない。
- 画面の文字列を足したら、[Tools/translations.tsv](Tools/translations.tsv) に訳を加えて `python3 Tools/make-strings.py` で Localizable.strings を作り直す（訳の無いキー・使わないキーがあると止まる）。
- アイコンは [Assets/make-icon.sh](Assets/make-icon.sh)（GenerateIcon.swift から .icns を生成）。

## 実装メモ

- サンドボックスのアプリは、CFPreferences に Bundle ID を渡してもコンテナの設定に届かない（空になる）。`~/Library/Containers/<id>/Data/Library/Preferences/<id>` をドメインとして渡すと cfprefsd 経由で読み書きでき、`defaults` やアプリ側とも食い違わない（[Courier.swift](Sources/SettingsCourier/Courier.swift) の `preferencesDomain`）。
- コンテナを読むと macOS の「ほかのアプリからのデータ」の確認が出て、許可してもMacを再起動するたびに出る。起動時や画面の切り替えでは読まず、「設定を読む」・書き出し・取り込みのときか、フルディスクアクセスがあるときだけ読む（HotkeyHound と同じ方針）。確認で拒否されると空の値が返るので、中身のある設定ファイルが空に見えたら書き出し・取り込みを止める（空のバックアップを作らない）。
- 設定ファイルをシンボリックリンクにして共有する方式は採らない。CFPreferences で書き込むとリンクが普通のファイルに置き換わり、リンク先は更新されない（2026-10-24 実測）。
- 受け渡しフォルダーは `SettingsSync.shared.folder` の中の `SettingsCourier` フォルダー（[Folder.swift](Sources/SettingsCourier/Folder.swift)）。1.0.1 までの `courierFolder` は最初の読み込みで移して消す。
- 一緒に運ぶファイルは「~/…」で持ち、書き出しファイルの `files` に中身を入れる（[Files.swift](Sources/SettingsCourier/Files.swift)）。バックアップは書き換えるファイルの今の中身と、無かったファイル（`removedFiles`）を持つ。Default Folder X のお気に入りは `~/Library/Application Support/com.stclairsoft.DefaultFolderX5/<フォルダーセット>/Favorites.plist`（Setapp 版も「-setapp」の付かないフォルダーを使っていた）。
- 受け渡しフォルダーのファイルは中身の Bundle ID で探す。書き出すと、同じアプリの別名のファイルは置き換える。別のアプリが同じ名前のときだけ `<アプリ名> (<Bundle ID>).settingscourier` にする。
- 「新しい設定」は、ファイルの書き出し日時を、このMacの設定ファイルの更新日時と処理済みの記録（`handledFolderExports`、Macごと）の新しい方と比べて判定する（値を読まないので確認が出ない）。cfprefsd はファイルへの書き出しを後回しにすることがあり、取り込んでも内容が同じなら書かないので、更新日時だけでは取り込んだ直後も「新しい」と出てしまう。このMacで書き出したファイル（host が同じ）は新しいとしない。
- 取り込みのために終了させたアプリは、終了の通知で自動書き出しをしない（取り込む前の値でフォルダーのファイルを上書きしてしまうため）。

### 保存値と画面上の項目の照合（1.3.3）

設定一覧に「画面上の項目／意味」を表示します。共通部品のソースで確認できる項目、同じキーが対象アプリのLocalizable.stringsにある候補、内部保存値、対応不明を区別します。候補は画面との対応が確定したものではなく、版・言語によって文言が異なる場合があります。対象アプリを操作したり、設定を書き換えて推測したりはしません。

項目名でも検索できます。行を1つ選び「取得値の詳細…」で、配列・辞書・データ（Base64）を含む型付きplistを表示・コピーできます。取得対象は既存のCFPreferences経由の保存値のままで、未保存の初期値・別ドメイン・別ファイルの設定を網羅するものではありません。

### 列の表示・手入力・スクショでの照合（1.4.0）

「画面上の項目／意味を表示」で一番右の列を表示・非表示にできます（初期値OFF、選択を保持）。行を1つ選び「項目名を編集・スクショで照合…」から項目名を入力・保存します。手入力を解除するには「自動表示に戻す」を押して保存します。

スクショ（PNG/JPEG/TIFF/HEIC）を読み込むと、Apple VisionによるMac内の文字認識で候補を表示します。画像・キー・取得値を見比べ、候補を選んで修正・保存してください。スクショだけでキーとの対応を確定する機能ではありません。画像は保存・送信しません。1.4.0〜1.4.1の項目名は `~/Library/Application Support/SettingsCourier/SettingLabels.json` に保存されていました。1.4.2以降は以下の同期対応方式へ移行します。

### セル内編集（1.4.1）

右端の「対応不明」や項目名をダブルクリックすると、そのセル内で編集できます。Enterまたは他のセルへの移動で保存、Escでキャンセルします。空欄を保存すると手入力の項目名を解除します。スクショを使った編集画面は従来のボタン・右クリックメニューから開けます。


### 項目名の設定同期（1.4.2）

手入力・スクショ候補から登録した「画面上の項目／意味」も、設定の共有の書き出し・読み込みと同期に含まれます。同期するすべてのMacを1.4.2以降へ更新し、同じ同期フォルダーを指定してください。画像や列の表示ON/OFFは同期しません。

既存のJSONは初回起動時にUserDefaultsへ移行し、原本をバックアップとして保持します。各項目を`courierLabel.v1.`で始まる独立したキーとして共有v2変更履歴方式で同期するので、異なる項目の変更をまとめられます。同じ項目の同時変更は共有エンジンのリビジョン・UUID順で解決します。空欄による手入力解除も同期します。受信後は一覧を再読込します。
