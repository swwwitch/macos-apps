# FolderMaker

![macOS](https://img.shields.io/badge/macOS-13%2B-lightgrey) ![version](https://img.shields.io/badge/version-1.5.0-blue) ![license](https://img.shields.io/badge/license-private-lightgrey)

ダイアログボックスでクライアント・地域・日付・備考を入力し、案件フォルダー（例：ricoh-osaka-20261014）を作るメニューバー常駐アプリ。Keyboard Maestro のマクロ「Folder Maker（案件）」（[KM](KM/)）の移植。

- ビルド：`./build.sh`（署名後に /Applications と Latest Builds へ配置）。配置しない確認用は `FOLDERMAKER_SKIP_PUBLISH=1 ./build.sh`
- テスト：`./test.sh`（フォルダー名の規則、シンボリックリンク、KMマクロとの一致、4言語の文字列）
- 文字列：`Resources/*.lproj/Localizable.strings`（ヘルプ本文は `helpText`）
- アイコン：`Assets/draw-icon.swift`

## 構成

| ファイル | 内容 |
| --- | --- |
| Sources/FolderName.swift | フォルダー名の組み立てと入力チェック、年の初期値（11月から翌年）、バルクモードの行の解析 |
| Sources/FileViewers.swift | 前面の Finder・Path Finder のフォルダー（AppleScript）、最近使ったフォルダー（LinkMaker から移植）、作成後の表示、Path Finder のサイドバー（AXでメニューを押す）、AT-Recent へのリンク |
| Sources/Project.swift | プロジェクト（フォルダー構成）の保存形式と構成の解析 |
| Sources/FileTemplates.swift | ファイルのテンプレートの配置・検索・差し込み |
| Resources/FileTemplates/ | 同梱のテンプレート（初回にユーザーのフォルダーへコピー） |
| Sources/Creation.swift | 作成の本体（階層ごとに作成・NFC への改名）、取り消しの記録、Windows 名と大文字小文字の判定 |
| Sources/Library.swift | 名前の規則と、共有フォルダーの Library.json |
| Sources/Model.swift | 入力欄・設定・アプリを呼び出すホットキー・作成処理 |
| Sources/main.swift | 画面・設定・メニュー |

## 移植の差分

- 年・月・日の入力をチェックし、作られるフォルダー名を入力中に表示する。日を省略すると「年月」、月も省略すると「年」だけ（マクロでは「00」になっていた）。
- 「最前面のフォルダー」はマクロでは無効化されていた（常に Dropbox-shared）。アプリでは前面の Finder・Path Finder のウインドウのフォルダーを使う。オフのときは設定の既定の作成先（初期値は Dropbox-shared）。
- 同じ名前のフォルダーがあるときは作らない。AT-Recent のリンクは同名のリンクだけ置き換え、本物のファイル・フォルダーは消さない。
- Path Finder のサイドバーへの追加は初期値オフ（アクセシビリティが必要なため）。キー操作（⌘↑）の代わりに Path Finder の `reveal` で選択してから「サイドバーへ追加」を押す。
- 作成後に Finder でも選択表示していた手順は省き、開くアプリを設定で選ぶ形にした。

## 更新履歴

- 1.5.0（build 7, 2026-10-14）：1件ずつで「プロジェクトの構成も作る」（作ったフォルダーの中に構成）。構成の名前に {{project}}・{{date}} を差し込み。「直前の作成を取り消す」（⌥⌘Z・結果欄のボタン・常駐メニュー。手付かずのものだけゴミ箱へ、AT-Recent のリンクも外す）。設定に「名前の規則」タブ（並び・日付の書式・項目名、NFC にそろえる＝初期値オン、Windows で使えない名前を作らない＝初期値オフ）。作成先のボリュームの大文字小文字の区別に合わせて重複を判定。共有フォルダー（Library.json と Templates を Dropbox などに置いて複数の Mac で共用）。まとめて・プロジェクトでも AT-Recent にリンク（設定でオン・オフ）。ホットキーもメニューバーアイコンも無いとき初回に呼び出し方を案内。作成先を1行ずつのラジオボタンにして「選択…」を「指定したフォルダー」の右へ、フォルダーが無い「最前面のフォルダー」「最近使ったフォルダー」は淡色に。「地域」を「プロジェクト」に、クライアントも省略可に（すべて空欄でも日付だけの名前になる）。

- 1.4.0（build 6, 2026-10-14）：ファイルのテンプレート（Post Haste の同梱書類を参考）。~/Library/Application Support/FolderMaker/Templates から「<」で指定した名前 → 同じファイル名 → template.拡張子 の順に探してコピー、{{project}}・{{file}}・{{date}} を差し込み。html・css・scss・js・md の雛形を同梱（既存は上書きしない）。設定の「プロジェクト」にテンプレートフォルダーを開く・同梱を補うボタン、一覧に使うテンプレートを表示。

- 1.3.0（build 5, 2026-10-14）：プロジェクトでファイルを作成（拡張子のある名前は空のファイル、既存は上書きしない、ドット入りのフォルダーは末尾「/」）。階層をインデント（タブ・スペース。一番浅いスペースのインデントを1段）でも指定可能に。見本「Web（SCSS）」を追加し、見本のIDを固定（再起動で選択が戻っていた）。モードの切り替えをウインドウの左右中央に。

- 1.2.0（build 4, 2026-10-14）：プロジェクトモードを追加（設定の「プロジェクト」でフォルダー構成を登録。「/」なしは最上位、「/」は直前の最上位の中、「//」はさらに下。フォルダー名の中、または作成先に直接作り、既存は飛ばす。見本「Web」入り）。まとめてモードに見出し＋「-」行の連結（Project ／ -A → Project A）と範囲の展開（A...C、01...12）を追加。保存した大きさがモードより高いとき開いた時点で合わせる。

- 1.1.1（build 3, 2026-10-14）：作成先の3択をポップアップメニューからラジオボタンに。

- 1.1.0（build 2, 2026-10-14）：バルクモード（「まとめて（テキストから）」）を追加。大きなテキスト欄の1行を1つのフォルダー名として一括作成（空行・箇条書き記号は除去、「/」で階層、既存は飛ばす、作成前に一覧で確認、⌘returnで作成）。作成先を「指定したフォルダー／最前面のフォルダー／最近使ったフォルダー（Finder・Path Finderの履歴）」の3択に（1.0の「最前面のフォルダー」のオン・オフは引き継ぐ）。ウインドウが内容より高いとき内容が上下中央に寄っていたのを上揃えに。

- 1.0.0（build 1, 2026-10-14）：最初の版。
