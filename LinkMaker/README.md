# LinkMaker

![macOS](https://img.shields.io/badge/macOS-13%2B-lightgrey) ![version](https://img.shields.io/badge/version-1.3.0-blue) ![license](https://img.shields.io/badge/license-private-lightgrey)

ブラウザーで表示中のページのタイトルとURLを、ホットキーでコピー・ファイル書き出し・開き直しするメニューバー常駐アプリ。Keyboard Maestro のマクログループ「Make Link」「Make Link (misc)」（[Reference](Reference/)）の移植。

- ビルド：`./build.sh`（署名後に /Applications と Latest Builds へ配置）。配置しない確認用は `LINKMAKER_SKIP_PUBLISH=1 ./build.sh`
- テスト：`./test.sh`（URL・タイトルの整形、既定キーとKMマクロのトリガーの一致、4言語の文字列）
- 文字列：`Resources/*.lproj/Localizable.strings`（ヘルプ本文は `helpText`）
- アイコン：`Assets/draw-icon.swift`

## 構成

| ファイル | 内容 |
| --- | --- |
| Sources/LinkRules.swift | タイトル・URLの整形、書式、Amazon、編集モードのURL変換（マクロ「Make Link（エンジン）」） |
| Sources/LinkAction.swift | 機能一覧と既定のホットキー（KMのトリガーと同じ） |
| Sources/Browser.swift | 対象ブラウザー、AXでのURL・タイトル取得、キー送信、タブ一覧（AppleScript、Firefoxはセッションファイル） |
| Sources/ActionRunner.swift | 各機能の実行 |
| Sources/LinkFiles.swift | webloc・QRコード（CoreImageでローカル生成） |
| Sources/Model.swift | 設定、ホットキー登録（対象ブラウザーが前面のときだけ） |
| Sources/Palette.swift | パレット（KakkoReplace の BracketPalette と同じ作り。フォーカスを奪わない浮動パネル） |
| Sources/main.swift | 画面・メニュー、パレットの表示制御 |

## 設定の共有

- 設定の「設定の共有」タブ（共通部品 Shared/SettingsSync）で、ホットキー（shortcuts・actionEnabled・doubleTap）、パレット（paletteShortcut・paletteHotkeyEnabled・paletteMode・paletteSimple・paletteSimpleActions）、対象ブラウザー、出力の設定（simplifyURL・associateID・translateTarget・notifySuccess）を LinkMaker-Settings.plist に書き出し・読み込み（置き換え）し、iCloud Drive・Dropbox などのフォルダーで同期する。
- ログイン起動・常駐・メニューバー・対象外アプリ・書き出し先のフォルダー・ウインドウ位置はMacごと。
- 対象外アプリは共通部品 Shared/ExcludedApps（キー excludedBundleIDs、1.2.10 までの excludedApps を引き継ぐ）。アクセシビリティは「起動・常駐」の共通グループ（AccessibilitySection）。

## 移植の差分

- QRコードは外部API（api.qrserver.com）ではなくMac内で生成。
- 確認ダイアログボックス（1秒で閉じる）は画面上部の短い表示に置き換え（設定でオフ可）。
- 「新規ウインドウで開く」は元のタブを ⌘W で閉じてから新規ウインドウを開く（KMと同じく元のタブは残らない）。Finderタグ（パープル）・Finderコメントの付与、Path Finder対応は省略。
- misc の機能は「選択した文字列から」グループ。どのアプリでも動き、設定の「対象外アプリ」（初期値はKMグループと同じ Illustrator・InDesign・Photoshop・Word）を除く。選択は ⌘C で読み取り、元のクリップボードは戻す。
- 「ほかのタブを閉じる」はAppleScriptで前面のウインドウの表示中以外のタブを閉じる。FirefoxはAppleScriptでタブを扱えないため、タブバーの各タブの閉じるボタンをアクセシビリティで押す（ピン留めは閉じるボタンが無いので残る。KMはすべて閉じてから開き直していた）。初期値は ⌥⇧⌘W。旧初期値の ⌃⌥⇧⌘W を保存済みの場合も移行し、独自の割り当ては保持する。
- 未移植：タブ切り替え・「タブを閉じる」「すべてのタブを閉じる」、Notion専用（開き直し以外）・Biscuit・Notefile専用、カンマ削除ペースト、セル内改行の「"」削除（CellCopyCleaner）、デフォルトブラウザーの変更（BrowserSwitcher）、クリップボードで起動するマクロ（KMで無効）。

## 1.3.1（33）

⌥Lで、選択した文字列（選択がない場合はクリップボード）のURLを開く方法をマウス位置のメニューから選べます。デフォルトブラウザー／ブラウザーを選択／Safari・Firefox・Chromeで同時に開く、の3種類です。Escでキャンセルします。従来の個別操作の標準キーは解除し、ユーザーが変更したキーは保持します。

⌥Nで、強制再読み込み／Google翻訳で開く／プライベートウインドウで開く／新規ウインドウで開く、を同じ形式のメニューから選べます。従来の個別操作の標準キーは解除し、変更済みのキーは保持します。

- 1.3.3（build 35）：「ページの開き直し方を選ぶ…」へSafari・Google Chrome・Firefox・Microsoft Edge・Notionを追加。未インストール、同じブラウザー、URLを取得できない場合はディム表示。Notionはnotion.so／notion.siteとそのサブドメインのみ有効。

- 1.3.4（build 36）：「新規ウインドウで開く」はChrome・Safariで標準のタブ移動メニューを実行。無効時は選択メニューでもディム表示。Firefoxなどは従来の方式を維持。

- 1.3.5（build 37）：機能ホットキーではクリップボード内のURLを開く（⌃⌥⌘L）のみグローバル化。対象外アプリを除外し、実行直前にも適用範囲を再確認。その他の機能キーは対象ブラウザー内に限定。パレット呼び出しキーは従来どおり。
