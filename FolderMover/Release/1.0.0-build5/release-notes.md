FolderMover 1.0.0 (build 5) — 試用版

macOSの `/bin/mv -n` を使って、フォルダ内の項目を別のフォルダへまとめて移動します。

- ソース/コピー先をクリックまたはドラッグ＆ドロップで指定
- 同名項目を上書きせずスキップ。フォルダは統合しません
- 進捗・停止・結果履歴、Dropboxパス簡易表示
- 4言語の表示とオフラインヘルプ

「コピー先」は移動先の欄です。コピー機能ではなく、移動済み項目は元の場所からなくなります。自動Undoはありません。

Apple Silicon / macOS 13以降（実機検証: macOS 26.7.1）。この試用版はad-hoc署名で、公証されていません。macOSのセキュリティ機能により起動が制限される場合があります。自動更新は未設定です。

DMGを開き、FolderMover.appをApplicationsへコピーしてください。最初はバックアップのあるテスト用フォルダで動作を確認してください。

別ボリュームの途中失敗ではコピー途中の項目が残り得ます。強制終了やドライブの取り外しを避けてください。
