# EventDocMaker

イベントごとの情報を保存して管理し、EventDocフォルダーのテンプレートに値を差し込んで、案内文・メール・告知などの文書をまとめて書き出すAppKit/SwiftUIアプリ。Apple Silicon / macOS 13以降。個人用で公開しない（note記事・個別リポジトリ・公証・配布はしない）。

- イベント管理：左にイベントの一覧（新しい仮の日付順、検索）、右に「開催前」「終了後」のタブで約125項目を入力（自動保存）、「文書を作る」タブで書き出し。項目は `Source/Schema.swift`（「配信に関してのまとめ.xlsx」の行4〜129と同じ並び・グループ分け）。
- 保存：イベントのフォルダー（`<親フォルダー>/<種別小文字・空白なし>-<仮の日付>-<タイトル（abc）>`）があれば `event.json`、無ければ `EventDoc/EventData/<id>.json`。文書を作ってフォルダーができると移る（`Source/Store.swift`）。
- 取り込み：「配信に関してのまとめ.xlsx」のシート「新しいまとめ」（A列＝項目名、B列以降＝1列1イベント、3行目＝#）を読む（`Source/XLSX.swift`、`/usr/bin/unzip` とXMLParser、ルビを除く）。日付シリアル値→20261202／2026-12-09、時刻（1日の割合）→21:00。同名の行（Spend〜Engagement Rate、Twitterアカウント）は2つ目を「CSS Nite：…」「Twitterアカウント（プロフィール）」に。#が同じイベントは上書きしない（確認画面で選べば上書き）。
- 書き出し：入力値をExcelの整形列（GV列）と同じ規則で文字にする（空・0→「-」、Doorkeeper購入者数は「0」、アンケート回答期限は「M月d日(曜) 21:00」か「準備中」、プロフィールの末尾に「∥」）。そのうえで 1.0.0 と同じ変数の組み立て（`Source/Variables.swift`）とテンプレートの差し込み・QRコード・STORES用コピー・最近のイベントへのリンク（`Source/Generator.swift`）。
- ⌃⌥E でメインウインドウを呼び出す。

Keyboard Maestroの「____ドキュメント生成」グループ（「キーボードショートカットで実行」→「〓ドキュメント作成のみ4」）を元にした。

## 元の手順から変えたところ

- 表の読み取りを、項目ごとの正規表現ではなくタブ区切り（Excelの引用符つき）として解釈する。プロフィール・セッション概要のような複数行の値も、その項目だけを読む。
- Excelの表で「YouTubeコメント人数」（行95）に整形の数式が無く、次の GOOD と1行につながって読めていなかった。アプリでは GOOD を渡す。セッション概要・プロフィールはExcelの表の範囲外で渡っていなかったので、空のときは空のまま。
- 数値の欄が「-」のときに「NaN」になっていた（JavaScriptで数値に変換）のを「-」のままにする。
- 配信URLからチャットURLを作る置換を順につなげた（元は2つ目の置換が1つ目の結果を上書きし、youtu.be の形は変換されなかった）。
- QRコードは外部のAPI（api.qrserver.com）ではなくMac上で作る。
- 最近のイベントのリンクは `ln -s -f` ではなく、同名の古いリンクだけを置き換えて作る。
- Excelでの列の選択と、Path Finderのサイドバー登録・並び替えは行わない（フォルダーを開くアプリは設定で Path Finder／Finder）。

## ビルド・テスト

```
./test.sh            # 表の解析・変数・トークン・QR・書き出し・整形・Excelの値の変換・保存場所の単体テスト＋4言語の翻訳検証
./build.sh           # build/EventDocMaker.app
./build.sh --deploy  # /Applications と Latest Builds へ配置
Assets/make-icon.sh  # アイコンを作り直す
```

## 更新履歴

### 1.1.0（build 2、2026-10-26）

- イベント管理に変更：イベントごとの情報を保存し、一覧から選んで「開催前」「終了後」のタブで入力（自動保存）。新規・複製・削除・検索・読み直す。
- 「配信に関してのまとめ.xlsx」から198件を取り込む機能（#が同じものは上書きしない）。
- 保存はイベントのフォルダーの event.json（フォルダーが無いものは EventDoc/EventData）。
- 文書は入力値をExcelの整形列と同じ規則で文字にしてから作る（#195で、Excelが作っていた表と113項目が一致）。
- 「クリップボードの表から入力」で、コピーした「項目⇥値」を選んでいるイベントに入力。
