PrefsPreset은 Mac의 설정(Dock, Finder, 트랙패드, 키보드 등)을 목록으로 보여 주고, 값을 골라 한 번에 변경하는 앱입니다. 현재 설정을 파일로 내보낸 뒤, 새로 설치한 다른 Mac에서 읽어 적용할 수도 있습니다.

## 사용 방법
### 설정 변경
1. 왼쪽 사이드바에서 카테고리를 선택하거나, 검색 필드에 항목 이름이나 키를 입력합니다.
2. ‘새 값’ 열에서 값을 고릅니다. 켬/끔 등 선택지가 있는 항목은 메뉴에서 고르고, 숫자나 문자열은 필드에 입력한 뒤 Return 키를 누릅니다.
3. 변경한 행에는 연필 표시가 붙고 항목 이름이 굵게 표시됩니다. 사이드바의 ‘변경한 항목’에서 변경한 행만 볼 수 있습니다.
4. 오른쪽 아래의 ‘적용’을 누르고 확인에서 ‘적용’을 선택하면, 변경한 행만 Mac에 기록됩니다.

### 새 Mac으로 옮기기
1. 현재 Mac에서 ‘내보내기…’(⌘S)를 선택해 설정을 .prefspreset 파일로 저장합니다.
2. 새 Mac에서 그 파일을 엽니다. 이중 클릭, 윈도우에 드롭, ‘열기…’(⌘O) 중 어느 방법이든 됩니다.
3. 새 Mac과 값이 다른 항목이 ‘새 값’에 들어가고 ‘변경한 항목’으로 좁혀집니다. 내용을 확인하고 ‘적용’을 누릅니다.

### 변경 취소
- 한 행씩 되돌리려면 행을 오른쪽 클릭하고 **현재 값으로 되돌리기**를 선택합니다.
- **설정 안 함(기본값)으로 지정**을 선택하면 적용할 때 그 설정을 삭제해 macOS 기본값으로 되돌립니다.
- 아래의 ‘모든 변경 취소’로 아직 적용하지 않은 변경을 모두 되돌립니다.

### 목록에 없는 설정 추가
- ‘항목 추가…’에서 도메인과 키를 입력하면 ‘추가한 항목’ 카테고리에 표시됩니다. 전체 설정은 도메인에 NSGlobalDomain을 입력합니다.
- 추가한 항목도 내보낸 파일에 저장됩니다.

### 추천 설정 사용
- 목록 위의 ‘추천 설정’ 또는 파일 메뉴의 ‘추천 설정 불러오기’를 선택하면 다음 값이 ‘새 값’에 들어갑니다. 내용을 확인하고 ‘적용’을 누릅니다.
- 자동 대문자, 스페이스 두 번으로 마침표, 스마트 따옴표, 스마트 대시를 끄고, 키보드 탐색을 켜며, 스크린샷 파일 포맷을 PNG로 지정하고, Mission Control의 ‘응용 프로그램별로 윈도우 그룹화’와 ‘디스플레이마다 별도의 Spaces 사용’을 끄고, 스테이지 매니저를 끄고, 터미널 윈도우 초점을 켜고, 윈도우 확대/축소, 정보 가져오기 애니메이션, 시차 효과를 끄고, 확대/축소 키보드 단축키를 켜고 트랙패드·스크롤 제스처와 포인터 따라가기를 끄며 전체 화면 스타일을 사용하고(최대·최소 확대/축소는 이 Mac의 값, F1로 켜기/끄기, F2로 확대), ‘다음 윈도우로 초점 이동’을 ⌘`로 지정하고, Caps Lock 표시기를 끄고(Mac 재시동 후 반영), 마우스 포인터 크기를 약 1.8로 지정하고, 시동 사운드를 끕니다(관리자 암호 필요).
- 다른 행의 변경은 그대로 유지됩니다.

### 내 프리셋에 저장해 다음 Mac에서 사용
1. 목록 위의 ‘내 프리셋’에서 ‘현재 설정을 내 프리셋으로 저장…’을 선택합니다. 모든 항목의 현재 값을 iCloud Drive의 PrefsPreset 폴더에 ‘My Preset.prefspreset’으로 저장합니다.
2. 새로 설치한 Mac에서 Apple 계정에 로그인하고, PrefsPreset의 ‘내 프리셋’에서 ‘내 프리셋 불러오기’를 선택합니다.
3. 다른 항목이 ‘새 값’에 들어갑니다. 내용을 확인하고 ‘적용’을 누릅니다.
- 다시 저장하면 이전 것은 ‘My Preset (previous).prefspreset’으로 하나만 남습니다.
- 저장 위치는 설정의 ‘내 프리셋’ 탭에서 바꿀 수 있습니다.

## 반영 시점
- 적용 후 필요에 따라 Dock, Finder, SystemUIServer, ControlCenter, WindowManager를 자동으로 다시 시작합니다.
- 키보드, 트랙패드, 일반 설정 등 일부는 다시 로그인해야 반영됩니다.
- 다른 앱이나 시스템 설정에서 바꾼 뒤에는 ‘다시 읽기’로 현재 값을 다시 읽습니다.

## 백업과 복원
- 적용하기 전에 바꾸는 항목의 원래 값을 ~/Library/Application Support/PrefsPreset/Backups/에 저장합니다.
- 되돌리려면 파일 메뉴의 ‘열기…’로 그 백업을 열고 ‘적용’을 누릅니다.
- 파일 메뉴의 ‘백업 폴더 보기’로 폴더를 열 수 있습니다.
- 백업을 저장할 수 없으면 아무것도 기록하지 않고 중단합니다.

## 설정
메인 윈도우의 ‘설정’ 버튼이나 앱 메뉴의 ‘설정…’(⌘,)으로 엽니다.
- **시작 및 백그라운드**: 로그인 시 실행, 시작 시 메인 윈도우 표시 안 함, 메뉴 막대에 표시
- **표시**: 메인 윈도우에 사용 방법 표시
- **내 프리셋**: 저장 위치(기본값은 iCloud Drive)

## 단축키
- **⌘O**: 열기
- **⌘S**: 내보내기
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: PrefsPreset 도움말
- **⌘Q**: PrefsPreset 종료

## 권한과 개인정보
- 손쉬운 사용 등의 권한은 필요하지 않습니다.
- ‘새 값’에서 바꾸고 적용한 항목만 기록합니다. macOS 환경설정 파일(defaults)을 직접 기록합니다.
- 네트워크 통신을 하지 않습니다. 내보낸 파일에는 설정 값과 Mac 이름이 들어 있습니다.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하거나 ⌘0으로 메인 윈도우를 다시 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 켜면 메뉴 막대 아이콘에서도 ‘메인 윈도우 열기’, ‘설정…’, ‘도움말’을 선택할 수 있습니다.
- 종료하려면 앱 메뉴의 ‘PrefsPreset 종료’(⌘Q)를 선택합니다.
- 앱 메뉴의 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다. 배포 준비가 끝날 때까지는 업데이트 준비 중이라고 표시되며 통신하지 않습니다.

## 문제 해결
- 적용해도 모양이 바뀌지 않으면 다시 로그인하세요.
- ‘기록하지 못한 항목’이 표시되면 macOS가 그 설정을 받아들이지 않은 것입니다. 시스템 설정에서 변경하세요.
- 결과가 마음에 들지 않으면 백업을 열고 ‘적용’을 눌러 이전 값으로 되돌릴 수 있습니다.

## 도움말과 note 글
- 이 도움말은 도움말 메뉴의 ‘PrefsPreset 도움말’(⌘?)로 엽니다.
- 도움말 메뉴의 ‘note 글 열기’로 note의 해설 글을 브라우저에서 엽니다.

## 앱 삭제
1. ‘로그인 시 실행’을 끕니다.
2. ‘PrefsPreset 종료’를 선택합니다.
3. PrefsPreset을 휴지통으로 옮깁니다. 백업도 필요 없으면 ~/Library/Application Support/PrefsPreset을 삭제합니다.
