# ListMatch

macOS 13以降 / Intel・Apple Silicon対応（Universal）のネイティブアプリ。ウインドウの左右のペインに貼り付けた2つのリスト（メールアドレス・名前・品番など）を比べ、「左にしかないもの」「右にしかないもの」をウインドウの下に表示します。

- 比較：1行を1項目とし、行の前後の空白・空行・BOMを無視。同じリスト内の重複は1件にまとめ、件数を見出しの横に表示。結果は最初に出た行の表記で、元のリストの順（設定で並べ替え可、`localizedStandardCompare`）。比較のロジックは `Source/ListComparison.swift`。
- 入力するたびに比較（0.15秒の間を置いてバックグラウンドで計算、10万行で約0.2秒）。共通・左だけ・右だけの件数を中央の行に表示。
- 比較の単位（リストの上のポップアップ、ファイルメニューでも可）：「行ごと」と「メールアドレスのみ」。メールアドレスのみでは、宛先欄（`名前 <a@x.jp>`）・カンマ区切り・CSV・署名などから正規表現でアドレスだけを取り出して比べる（1行の複数アドレスも可、全角は半角にしてから抽出、アドレスのない行は無視して件数を表示）。
- 設定「比較」タブ：共通の項目を薄く表示する（初期値オン、表示だけ）、大文字と小文字を区別しない（初期値オン）、全角と半角を区別しない（オフ、`fullwidthToHalfwidth`）、結果を並べ替える（オフ）。メールアドレスのみのときは全角半角の設定を使わない。
- 区切り文字（リストの上、比較の単位の右）：改行のほかにスペース・カンマ・タブを個別に選択（初期値はすべてオフ、全角のスペース・カンマを含む）。メールアドレスのみでは使わない。区切り文字をオンにしたとき・ファイルを読み込んだとき・ペーストしたときは、リストを1行1項目に並べ直して表示（⌘Zで戻せる、連携中のファイルは「未保存」になるだけ）。
- ファイルとの連携（MarkdownKitchenと同じ形）：読み込んだファイルはリストの上にアイコン・名前・フォルダーを表示。書き換えると「未保存」、「保存」（左⌘S・右⌥⌘S）で元の文字コードのまま上書き（上書き前を ~/Library/Application Support/ListMatch/Backups に20件まで控える、ほかのアプリで変更されていたら確認）。Finderで表示・連携を解除。未保存のまま終了すると確認。
- 「右のリストに追加」「左のリストに追加」（結果の下）：片方にしかないものをもう一方のリストの末尾に追加（⌘Zで取り消し可）。
- 「マージして保存…」（⇧⌘S、ウインドウ下）：左右のリストを重複なしでまとめ（左の順＋右にしかないもの）、1行1項目のUTF-8で新しいファイルに保存。
- 結果は「コピー」ボタン（⇧⌘L・⇧⌘R）で1行1項目のテキストとしてクリップボードへ。「左右のリストを消去」（ファイルとの連携も外す）。
- テキストファイル（UTF-8・UTF-16・Shift_JIS）をペインにドロップ、または ⌘O（左）・⌥⌘O（右）で読み込み。
- 貼り付けたリストは保存しない（メモリ上だけ）。外部通信なし。ウインドウを閉じても常駐（設定で変更可、初期値オン）。ログイン時に起動（初期値オフ）・起動時にメインウインドウを表示しない（初期値オフ）・メニューバー表示（初期値オフ）。
- Bundle ID は `jp.dtp-transit.listdiff`（旧名 ListDiff のまま、設定を引き継ぐため）。
- 設定の「設定の共有」タブ（共通部品 Shared/SettingsSync）：「比較」タブの設定と区切り文字・比較の単位・列・見出し行の選択を `ListMatch-Settings.plist` に書き出し・読み込み、iCloud Drive・Dropbox などのフォルダーで同期。ログイン起動・常駐・メニューバーはMacごと、リストの内容は含まない。
- 4言語（日本語・英語・簡体字中国語・韓国語）。アクセシビリティなどの許可は不要。

## 開発

```sh
./build.sh   # build/ListMatch.app（SKIP_DEPLOY=1 で配置を省略）
./test.sh    # 比較ロジックの単体テスト
```

文字列・ヘルプ・Info.plistは `make-resources.py`、アイコンは `Assets/make-icon.sh`（`GenerateIcon.swift`）から再生成します。共有の `AppHeader.swift`・`AppSurface.swift`・`StartupWindow.swift`・`HelpDocument.swift`・`SettingsSection.swift`・`AboutSection.swift`・`LoginAtLaunch.swift`・`SettingsSync.swift` をビルド時に参照します。`MenuBarPresence.swift`・`UpdateSupport.swift` は共通部品のコピーです（`Shared/MenuBarPresence/sync.py`・`Shared/Updater/prepare.py` に登録済み）。

## 制限

行の中の空白（「a @x.jp」など）は区別します。Excelなどのファイルは直接読めないので、テキスト（CSV）で書き出してください。

このビルドはローカル利用向けに証明書（PL9S9PXX96）で署名しています。Developer ID署名・公証・更新配信先は未設定です。ヘルプメニューの「note記事を開く」と設定の「情報」タブは紹介記事（SWNoteArticleURL）を開きます。

## 2026-10-25 Dock非表示時のメニュー修正（1.6.0 build 13）

Developer ID署名・アプリ/DMG公証Accepted。両配置先の内容・署名・公証チケットと、/Applications版の起動を確認。 各アプリの画面操作と実ログインの確認範囲は別途配布記録に記載。
