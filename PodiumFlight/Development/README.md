# PodiumFlight — セミナー・キャプチャ準備

セミナー講師やスクリーンキャプチャ向けの、メニューバー常駐Macアプリです。`PodiumFlight.app` を開き、メニューバーの「画面＋時計」アイコンから操作します。Dockには表示しません。

## 操作

- 時計：macOSのメニューバー時計をデジタル／アナログに変更。
- 外観：Mac全体をライト／ダークに変更。
- Dockを隠す：通常の自動非表示をオン／オフ。
- Dockを殺す：アイコンサイズを1、出現遅延を3000000秒に設定。オフでこの機能をオンにする直前のサイズ・遅延へ復元。Dockプロセスは設定反映のため再起動します。自動非表示とは独立しており、両方をオンにして使えます。
- デスクトップ非表示：デスクトップ上のファイルアイコンを隠す／表示する。ファイル自体は削除しません。反映時にFinderを再起動します。
- 通知オフ／オン：おやすみモードを有効／解除。例外として許可されている通知は届く場合があります。
- 終了：メニューバー常駐を終了。適用したシステム設定は残ります。

## タイマー：設定 → タイマー

「開始時間 ＋ 所要時間 ＝ 終了時間」で連動します。

- 開始時間を変更：所要時間を保ち、終了時間を更新。
- 所要時間を変更：開始時間を保ち、終了時間を更新。
- 終了時間を変更：開始時間を保ち、所要時間を更新。
- 所要時間は1〜10080分。日付も指定でき、日をまたぐ予約に対応。
- 「開始／予約」で実行。開始前は「開始まで」、開始後は残り時間をメニューバーに表示し、終了時は00:00で停止。
- 実行中に入力を編集した場合は「設定を反映して再開」で反映。
- 設定と実行中の終了時刻を保存。アプリの再起動後も復帰し、スリープ時間も経過時間に含めます。アプリ終了中はメニューバー表示は消えます。

## プリセット：設定 → プリセット

1. 名前を入力。
2. 変更したい項目にチェックを入れ、希望の値を選択。
3. 「新規保存」（保存済みのプリセットを編集中は「上書き保存」）。
4. メニューバーの「プリセットを適用」から実行。

チェックしない項目は変更しません。保存済みのプリセットを選ぶと編集・上書き保存・削除できます。アプリを再起動しても保存内容は残ります。

プリセットのタイマー項目は所要時間のみです。開始／予約は別操作なので、表示設定を切り替えるだけでタイマーが勝手に始まることはありません。

## 通知の連携

このMacの「ショートカット」に以下を作成済みです。名前を変更せずに使ってください。

- `Toki Notifications Off`：おやすみモードを、オフにするまでオン。
- `Toki Notifications On`：おやすみモードをオフ。

別のMacでも通知機能を使う場合は、この2本をショートカットで作成または同期する必要があります。「デバイス間で共有」が有効な場合、おやすみモードは他のAppleデバイスにも同期されます。

外観変更はSystem Eventsを使います。初回に許可を求められた場合は許可してください。アクセシビリティ権限は不要です。

## ビルドと検証

macOS 26.7.1（Apple Silicon）でビルド・実機確認。最低ビルド対象はmacOS 13ですが、他のOSでは未検証です。ローカル署名版で、配布用の公証はしていません。

```sh
bash build-app.sh
open ../PodiumFlight.app
```

SwiftUIとAppKitを使用。Xcodeでソースを編集する場合は `Package.swift` を開いてください。実機実行には権限説明を含む `.app` 形式を使います。

`Tests/LogicTests.swift` は、3時刻の連動・開始前・終了境界・1時間以上の表示・設定の直列化・プリセットの未選択値保持を検証します。

時計とDockの内部設定キーは、macOS更新で仕様が変わる可能性があります。

## 3.1の変更

- メニューバーのアイコンを「画面＋時計」の独自単色アイコンに変更。ライト／ダークの表示色はmacOSに追従。
- 設定画面をメニューバーに追従するポップオーバーから通常のウインドウへ変更。位置を保存し、編集中の再表示では既存ウインドウを前面に出します。

- 時計の日付の表示／非表示を追加。アナログ時計使用中は日付は表示されず、設定はデジタル時計に切り替えたときに使われます。

## 3.1.3の修正

- 環境設定への切り替え時にウインドウ幅が0になる問題を修正。同じウインドウと表示領域を維持して画面を切り替えます。
- 不正な保存済みウインドウサイズを起動時に復旧します。
- 実機で環境設定、タイマー／プリセットのタブ切り替え、設定一覧への復帰と環境設定の再表示を確認しました。

## 3.2.0 — 指定アプリの終了

設定の「アプリ終了」で対象アプリを追加・削除できます。初回は、インストール済みのClipEye・Dropboxを登録します。リストは自動保存され、登録だけでは終了しません。

「指定アプリを終了する」ボタンでリストの起動中アプリに通常の終了を要求します。未保存書類の確認には各アプリで応答してください。強制終了は行いません。プリセットの同名チェックを有効にすると、適用時に現在のリストを使います。

確認済み: アプリ追加・削除の実機操作、対象一覧表示、プリセット画面、旧プリセット互換性と新設定の直列化。ClipEye・Dropboxの実終了は検証時には行っていません。

## 3.2.1 — 起動するアプリ

「設定 → アプリ起動」でアプリを追加・削除します。登録は自動保存されます。「指定アプリを起動する」で起動できます。起動済みの場合は重複起動しません。

プリセットの「指定アプリを起動する」をチェックして保存すると、その保存時点の一覧をプリセットに記憶します。再保存時は現在の起動一覧に更新されます。プリセット適用時、終了リストにも含まれるアプリは起動を優先して終了対象から除外します。

検証: ビルド・署名、設定画面、旧プリセットの読込、新しい一覧の保存形式、存在しないアプリのエラー表示。

## 3.2.2 — プリセット別のアプリ一覧

プリセット内の「起動アプリを編集…」「終了アプリを編集…」で、それぞれ追加・削除して保存します。各一覧は独立して保持され、再保存時にも共通一覧で上書きしません。以前の終了オプションは移行時点の終了一覧を取り込んで固定します。アプリ起動・アプリ終了タブは手動操作用です。

## 3.2.3 — 共通仕様の適用

- メニューバー追加の初回案内、「起動時にメインウインドウを表示しない」、環境設定「起動・常駐」の共通UI、⌘,／⌘Wの共通操作を適用。

## 3.2.4 — 共通部品の修正と小さな不具合の修正

共通部品：

- 「ログイン時に起動」の文言を4言語に対応し、登録が見つからないときの誤解を招く表示を修正。
- アクセシビリティ権限・メニューバー設定の表示言語を、環境設定と同じ言語に統一。

PodiumFlight：

- メニューバーの「画面＋時計」アイコンが共通部品の汎用アイコンに置き換わる問題を修正。
- ログイン時の起動ではメインウインドウを開かず、メニューバーに静かに常駐。
- 英語などの表示で、時計・外観の変更メッセージやエラー、ヘルプメニュー、操作画面の補足説明に日本語が混ざる問題を修正。
- 編集メニューに「取り消す」（⌘Z）・「やり直す」（⇧⌘Z）を追加。
- システム設定の2秒ごとの再読み込みはウインドウ表示中だけ、1秒ごとの更新はタイマー実行中だけ動かし、待機中の負荷を削減。
