세미나와 화면 녹화를 위해 Mac의 표시 설정과 타이머를 한곳에서 조작하는 메뉴 막대 앱입니다. Dock에는 표시되지 않습니다.

## 사용 방법
메뉴 막대의 ‘화면+시계’ 아이콘을 클릭하면 조작 화면(세미나 및 캡처 준비)이 열립니다. 다음 항목을 전환할 수 있습니다.

### 표시
- **시계**: 메뉴 막대 시계를 디지털 또는 아날로그로 변경합니다. 날짜와 요일 표시도 전환할 수 있습니다(디지털 시계용).
- **모양**: Mac 전체를 라이트 또는 다크로 변경합니다.

### Dock과 데스크탑
- **Dock 가리기 (자동으로 가리기)**: Dock 자동으로 가리기를 켜거나 끕니다.
- **Dock 표시 억제 (최소 크기 및 표시 지연)**: Dock 크기를 1, 표시 지연을 3,000,000초로 설정합니다. 끄면 켜기 직전의 설정으로 되돌립니다.
- **데스크탑 아이콘 가리기**: 데스크탑에 있는 파일 아이콘을 가립니다. 파일은 삭제하지 않습니다.

### 알림, 앱, 프리셋
- **알림**: ‘OFF’를 누르면 방해금지 모드가 켜지고, ‘ON’을 누르면 해제됩니다. 허용된 알림은 계속 도착할 수 있습니다.
- **지정 앱 종료**: 설정의 ‘앱 종료’에 등록한 앱에 종료를 요청합니다.
- **프리셋 적용**: 저장한 프리셋의 설정을 한꺼번에 적용합니다.

※ 시스템 설정의 변경 사항은 PodiumFlight를 종료한 후에도 유지됩니다.

## 타이머
1. ‘설정’의 ‘타이머’ 탭에서 시작 시간, 소요 시간, 종료 시간을 지정합니다(시작 시간+소요 시간=종료 시간).
2. ‘시작 / 예약’을 클릭하면 실행됩니다.
3. ‘중지’를 클릭하면 멈춥니다.

- 시작 시간이나 소요 시간을 바꾸면 종료 시간이, 종료 시간을 바꾸면 소요 시간이 갱신됩니다. 소요 시간은 1~10,080분입니다.
- 시작 전에는 ‘시작까지’와 남은 시간을, 시작 후에는 남은 시간을 메뉴 막대에 표시하며, 종료되면 00:00에서 멈춥니다.
- 실행 중에 입력을 변경한 경우 ‘설정을 적용하고 다시 시작’을 클릭하세요.
- 앱을 다시 실행해도 타이머가 복원되며, 잠자기 중에도 시간은 계속 흐릅니다.
- ‘타이머 사용’을 끄면 타이머가 중지되고 메뉴 막대에는 아이콘만 표시됩니다.

## 프리셋
1. ‘설정’의 ‘프리셋’ 탭에서 프리셋 이름을 입력합니다.
2. 변경할 항목을 체크하고 값을 선택합니다. 체크하지 않은 항목은 변경하지 않습니다.
3. ‘새로 저장’(저장된 프리셋을 편집 중일 때는 ‘덮어쓰기’)을 클릭합니다.

- 프리셋의 타이머 항목은 소요 시간뿐입니다. 시작 또는 예약은 별도로 실행하므로 프리셋을 적용해도 타이머는 시작되지 않습니다.
- ‘실행 앱 편집…’과 ‘종료 앱 편집…’에서 프리셋 전용 앱 목록을 편집하고, ‘완료’를 클릭한 후 프리셋을 저장하세요. 다른 프리셋에는 영향을 주지 않습니다.
- ‘앱 실행’, ‘앱 종료’ 탭의 목록은 수동 실행용입니다.

## 설정
조작 화면의 ‘설정…’ 버튼을 클릭하거나 ⌘,를 누르면 열립니다. ‘설정 목록으로 돌아가기’를 클릭하면 조작 화면으로 돌아갑니다.
- **시작 및 백그라운드**: 로그인 시 실행, 시작 시 메인 윈도우 표시 안 함, 메뉴 막대에 표시
- **앱 실행**: ‘지정 앱 실행’으로 실행할 앱을 추가하거나 삭제합니다. 이미 실행 중인 앱은 중복으로 실행하지 않습니다.
- **앱 종료**: ‘지정 앱 종료’로 종료할 앱을 추가하거나 삭제합니다. 강제 종료하지 않습니다. 저장하지 않은 문서가 있으면 해당 앱의 확인 창에서 저장하세요.
- **타이머**, **프리셋**: 위 내용 참조

## 키보드 단축키
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: PodiumFlight 도움말
- **⌘Q**: PodiumFlight 종료(조작 화면의 ‘종료’)
- **⌘Z / ⇧⌘Z**: 실행 취소 / 실행 복귀(입력란 편집 시)

## 권한과 알림 연동
### 모양 변경(System Events)
모양 변경에는 System Events를 사용합니다. 처음에 권한을 요청하면 허용하세요. 허용하지 않은 경우 시스템 설정 → ‘개인정보 보호 및 보안’ → ‘자동화’에서 PodiumFlight가 System Events를 제어하도록 허용하세요. 손쉬운 사용 권한은 필요하지 않습니다.

### 알림 전환(단축어)
Mac의 ‘단축어’ 앱에 있는 다음 두 단축어를 사용합니다. 이름을 바꾸지 말고 그대로 만드세요.
- **Toki Notifications Off**: 방해금지 모드 켜기
- **Toki Notifications On**: 방해금지 모드 끄기

※ 다른 Mac에서 이 기능을 사용할 때도 이 두 단축어가 필요합니다.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않고 메뉴 막대에 상주합니다. 메뉴 막대 아이콘을 클릭하면 조작 화면을 다시 표시할 수 있습니다.
- 로그인 시 실행되었거나 ‘시작 시 메인 윈도우 표시 안 함’이 켜져 있으면 조작 화면을 열지 않고 시작합니다.
- ‘메뉴 막대에 표시’를 꺼도 앱은 종료되지 않습니다. PodiumFlight를 다시 열면 조작 화면이 표시됩니다.
- 종료하려면 조작 화면의 ‘종료’ 버튼(⌘Q)을 클릭합니다. 메뉴 막대의 표시는 사라지지만, 변경한 시스템 설정은 그대로 유지됩니다.

## 문제 해결
- Dock과 데스크탑 설정을 적용하기 위해 Dock이나 Finder를 다시 시작할 수 있습니다.
- 알림이 전환되지 않으면 ‘단축어’ 앱에 ‘Toki Notifications Off’와 ‘Toki Notifications On’이 있고 이름이 정확한지 확인하세요.
- 모양이 바뀌지 않으면 위의 ‘자동화’ 권한을 확인하세요.
- 시계와 Dock 설정은 macOS 내부 설정을 사용하므로 macOS 업데이트 후 동작이 바뀔 수 있습니다.

## 도움말과 note 글
- 조작 화면 아래쪽의 ‘도움말’에서 ‘PodiumFlight 도움말’을 선택하면 이 도움말이 열립니다(⌘?로도 열 수 있습니다).
- 같은 메뉴의 ‘note 글 열기’를 선택하면 note의 소개 글을 브라우저에서 엽니다.

## 앱 삭제
1. 필요하면 Dock 설정과 데스크탑 아이콘 표시를 원래대로 되돌립니다.
2. ‘로그인 시 실행’을 끕니다.
3. 조작 화면의 ‘종료’로 앱을 종료하고 PodiumFlight를 휴지통으로 이동합니다.
