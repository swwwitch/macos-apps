앱과 파일의 아이콘을 투명도를 유지한 PNG로 내보내는 메뉴 막대 앱입니다. Dock에는 표시되지 않습니다.

## 사용 방법
### 메인 윈도우에서 내보내기
1. 앱이나 파일을 메인 윈도우에 드롭하거나 ‘파일 선택…’(⌘O)으로 선택합니다. 여러 파일을 한 번에 내보낼 수 있습니다.
2. 내보낸 후 ‘Finder에서 보기’를 클릭하면 저장한 파일을 확인할 수 있습니다.

### 다른 내보내기 방법
- Finder에서 앱 아이콘에 드롭하거나 ‘다음으로 열기’를 사용하면 메인 윈도우를 표시하지 않고 내보냅니다.
- Finder 또는 Path Finder에서 파일을 선택하고 ⌃⌥⌘I를 누르면 메인 윈도우를 표시하지 않고 내보냅니다.
- Finder에서 파일을 선택한 후 오른쪽 클릭 → ‘서비스’ → ‘アイコンを書き出す（QuickIconExporter）’로도 내보낼 수 있습니다.
- 메뉴 막대 아이콘에서 ‘파일 선택…’을 선택해도 내보낼 수 있습니다.

## 저장 위치와 파일 이름
### 저장 위치
- 아이콘은 가능한 최대 픽셀 크기로 저장되며, 크기는 원본 앱이나 파일에 포함된 이미지에 따라 정해집니다.
- .icns 파일은 Finder의 파일 아이콘이 아니라 파일에 들어 있는 이미지 중 가장 큰 것을 내보냅니다. 읽을 수 없는 .icns는 파일 아이콘을 내보냅니다.
- 기본 저장 위치는 데스크탑입니다. 메인 윈도우 하단의 ‘변경…’ 또는 설정의 ‘내보내기’ 탭에서 변경할 수 있습니다.

### 파일 이름
- 기본 파일 이름은 ‘icon-파일명.png’이며, 공백은 하이픈으로 바꾸고 불필요한 기호는 제거합니다.
- 이름은 Finder에 표시되는 이름으로 만듭니다. 예를 들어 ‘Adobe Illustrator 2021’로 표시되는 ‘Adobe Illustrator.app’은 ‘icon-Adobe-Illustrator-2021.png’가 됩니다. macOS 앱은 현지화된 이름을 사용합니다. 실제 파일 이름을 사용하려면 설정에서 ‘Finder에 표시되는 이름 사용’을 끕니다.
- 같은 이름의 파일이 있으면 기존 파일을 덮어쓰지 않고 ‘-2’, ‘-3’처럼 번호를 붙여 저장합니다.

## 설정
메인 윈도우의 ‘설정’ 버튼(⌘,)으로 엽니다. 변경 사항은 즉시 적용되며, 앱 아이콘에 드롭한 파일이나 서비스에서 내보낼 때도 사용됩니다.
- **시작 및 백그라운드**: 로그인 시 실행, Dock 및 앱 전환기에 표시 안 함, 메뉴 막대에 표시
- **내보내기**: 저장 위치 변경(‘폴더 선택…’, ‘데스크탑으로 재설정’)
- **파일 이름**: ‘icon 부분’의 문자(비워 두면 파일명만 사용), 위치({icon}-파일명.png 또는 파일명-{icon}.png), 구분 문자(하이픈 또는 밑줄), 공백 처리, Finder에 표시되는 이름 사용(기본값 켬), 불필요한 기호 제거. ‘미리보기’에서 결과를 확인할 수 있으며, ‘파일 이름 기본값 복원’을 클릭하면 기본값으로 되돌립니다.
- **완료 시**: 내보낸 후 Finder에서 보기(기본값 켬), 내보낸 후 앱 가리기(기본값 끔), 알림 표시(기본값 끔), 효과음 재생(기본값 끔)
- **단축키**: 선택한 파일을 내보내는 단축키(기본값 ⌃⌥⌘I)의 사용 여부와 변경

‘설정 공유’ 탭에서는 파일 이름 규칙과 내보낸 뒤의 동작을 공유할 수 있습니다. **내보내기…**로 QuickIconExporter-Settings.plist에 저장하고 **가져오기…**로 다른 Mac에서 불러옵니다(확인 후 대치). ‘설정 동기화’에서 iCloud Drive나 Dropbox 등의 폴더를 선택하면 같은 폴더를 선택한 Mac끼리 설정이 자동으로 맞춰집니다. 저장 위치, 로그인 시 실행, 메뉴 막대는 Mac마다 설정합니다.

## 키보드 단축키
- **⌘O**: 파일 선택
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘Q**: QuickIconExporter 종료

※ 선택한 파일을 내보내는 단축키는 기본값이 ⌃⌥⌘I이며, 설정의 ‘단축키’ 탭에서 변경할 수 있습니다. 서비스에도 시스템 설정 → ‘키보드’ → ‘키보드 단축키’ → ‘서비스’에서 키보드 단축키를 지정할 수 있습니다.

## 권한
- 손쉬운 사용 권한은 필요하지 않습니다.
- 선택한 파일을 내보내는 단축키를 처음 사용할 때 Finder 또는 Path Finder 제어(자동화) 허용을 요청합니다.
- ‘알림 표시’를 켠 후 처음 내보낼 때 macOS에서 알림 권한을 요청합니다.
- 저장 위치에 쓸 수 없으면 쓸 수 있는 폴더를 다시 선택하세요.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않고 메뉴 막대에 상주합니다. 메뉴 막대 아이콘에서 ‘메인 윈도우 열기’를 선택하면 메인 윈도우를 다시 표시할 수 있습니다.
- 수동으로 실행하거나 다시 열면 메인 윈도우를 표시합니다. 로그인 시 자동 실행에서는 표시하지 않습니다. 파일을 명시적으로 열면 해당 작업을 우선합니다.
- ‘Dock 및 앱 전환기에 표시 안 함’을 켜면 메인·설정 윈도우가 있는 동안 Dock과 ⌘Tab에 표시하고 모두 닫으면 숨깁니다(기본값 끔). 메뉴 막대 아이콘이나 Finder에서 앱을 다시 열어 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 꺼도 앱은 종료되지 않습니다. QuickIconExporter를 다시 열면 메인 윈도우가 표시됩니다.
- 종료하려면 메뉴 막대 아이콘에서 ‘QuickIconExporter 종료’를 선택합니다.
- 앱 메뉴의 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다. 업데이트 배포 준비가 끝날 때까지는 ‘업데이트가 설정되지 않음’이 표시되며 통신하지 않습니다.

## 문제 해결
- 내보낼 수 없으면 저장 위치의 폴더가 있고 쓸 수 있는지 확인하세요. 설정의 ‘내보내기’ 탭에서 ‘데스크탑으로 재설정’을 클릭하면 기본 저장 위치로 되돌릴 수 있습니다.
- 아이콘의 해상도는 원본 앱이나 파일에 포함된 이미지에 따라 달라집니다.
- 서비스 메뉴에 항목이 표시되지 않으면 시스템 설정 → ‘키보드’ → ‘키보드 단축키’ → ‘서비스’에서 활성화되어 있는지 확인하세요.
- 알림이 표시되지 않으면 시스템 설정의 ‘알림’에서 QuickIconExporter가 허용되어 있는지 확인하세요.

## 도움말과 note 글
- 메뉴 막대 아이콘의 ‘도움말’에서 ‘QuickIconExporter 도움말’을 선택하면 이 도움말이 열립니다. 윈도우가 표시되어 있을 때는 도움말 메뉴의 ‘QuickIconExporter 도움말’(⌘?)로도 열 수 있습니다.
- 같은 ‘도움말’ 하위 메뉴의 ‘note 글 열기’를 선택하면 note의 소개 글을 브라우저에서 엽니다.

## 앱 삭제
1. ‘로그인 시 실행’을 끕니다.
2. 메뉴 막대 아이콘에서 ‘QuickIconExporter 종료’를 선택합니다.
3. QuickIconExporter를 휴지통으로 이동합니다.

- App Store 버전은 첫 내보내기 전에 표준 시스템 대화상자에서 저장 폴더를 선택합니다. 취소하면 내보내지 않습니다. 재시작 후에도 폴더를 기억하며 접근을 복원할 수 없으면 다시 선택합니다. PNG는 앱 컨테이너에 저장하지 않습니다.


알림
설정의 알림에서 알림을 켜거나 끄고 권한을 확인할 수 있습니다. 옵션을 켜거나 알림 허용 버튼을 누를 때 권한을 요청합니다. 알림 설정 열기에서 macOS의 표시 위치와 스타일을 변경할 수 있습니다. 거부된 경우 시스템 설정에서 변경하세요. 앱 시작이나 작업 완료 시에는 권한을 요청하지 않습니다. 집중 모드 등으로 알림이 표시되지 않으면 앱에서 결과와 상태를 확인하세요.


## Dock 표시와 앱 메뉴

Dock 및 앱 전환기에 표시 안 함을 켜도 메인 또는 설정 윈도우가 열려 있는 동안 앱 메뉴를 사용할 수 있도록 Dock과 ⌘Tab에 표시합니다. 최소화 중에도 유지하며 해당 윈도우를 모두 닫으면 숨깁니다. 팔레트만 열려 있으면 표시하지 않습니다. 저장된 설정은 유지됩니다.

⌘Tab 앱 전환기에서 앱을 선택하면 메인 윈도우를 표시하고 최소화된 경우 복원합니다. 로그인 시 자동 실행은 조용히 유지됩니다.
