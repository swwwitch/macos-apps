# QuickIconExporter

macOS上のアプリやファイルをドロップすると、Finderで表示されるアイコンを取得できる最大サイズの透過PNGとして保存するネイティブアプリです。

## ビルド

```sh
chmod +x build-app.sh
./build-app.sh
```

完成したアプリは `outputs/QuickIconExporter.app`、配布用ZIPは `outputs/QuickIconExporter.zip` に作成されます。ZIPは署名の検証（`codesign --verify --deep --strict`）に通った場合だけ作成します。

App Store版（`build-app-store.sh`）は `outputs/AppStore/` に書き出し、通常版のアプリとZIPは上書きしません。

## 使い方

1. `QuickIconExporter.app` を起動します。
2. アプリまたはファイルをウインドウ中央へドラッグ＆ドロップします。
3. 初期状態ではデスクトップへ `icon-ファイル名.png` が保存されます。
4. 保存先はアプリ内の「設定」から変更できます。

設定では `icon` の部分を変更し、`icon-ファイル名.png` または `ファイル名-icon.png` の配置を選べます。区切り文字はハイフン（`-`）とアンダースコア（`_`）から選択できます。元ファイル名に含まれる空白をそのまま残す・ハイフンへ変更する・アンダースコアへ変更する処理と、記号類を削除するオプションも選べます。

空白処理の初期値は「ハイフンに変更」です。
「不要な記号を削除」の初期値はオンです。

書き出し完了時の通知と効果音は、それぞれ個別にオン・オフできます。初期値はどちらもオフです。

同名のPNGがすでにある場合は、既存ファイルを上書きせず `-2`、`-3` のような番号を付けます。
