## 기본 사용법
1. 다음 중 하나로 프레젠테이션을 지정하세요.
- .key 파일을 KeynoteSweeper 윈도우(또는 Dock 아이콘)에 드롭하거나 "파일 열기…"(⌘O)로 선택합니다. 파일을 Keynote에서 열고 그 프레젠테이션만 대상으로 하므로 다른 프레젠테이션이 맨 앞에 있어도 헷갈리지 않습니다.
- 아무것도 드롭하지 않으면 Keynote 맨 앞의 프레젠테이션이 대상입니다.
2. 프레젠테이션 이름과 사용하지 않는 마스터, 숨긴 슬라이드의 수가 표시됩니다. 표시가 오래되었으면 "다시 불러오기"(⌘R)를 누르세요. "맨 앞 프레젠테이션 사용"을 누르면 드롭한 파일에서 돌아갑니다.
3. "삭제할 항목"에서 다음을 선택하세요.
- 사용하지 않는 마스터 삭제
- 숨긴 슬라이드 삭제
- 모든 전환 효과 삭제
- 모든 객체 애니메이션 삭제
4. "삭제"(⌘Return)를 누르고 확인 대화상자에서 "삭제"를 선택하세요.
5. 완료되면 삭제한 수와 삭제하지 못한 항목이 표시됩니다.

## Keynote의 서비스 메뉴에서 사용
Keynote가 맨 앞에 있을 때 Keynote › 서비스에 다음 항목이 표시됩니다.
- 사용하지 않는 마스터 삭제
- 숨긴 슬라이드 삭제
- 전환 효과 삭제
- 객체 애니메이션 삭제
- 모든 애니메이션 삭제(전환 효과와 객체 애니메이션)
Keynote 맨 앞의 프레젠테이션이 대상입니다. 선택하면 확인 대화상자 없이 바로 삭제하며 Keynote는 맨 앞에 그대로 있습니다. 삭제하지 못한 항목이 있거나 실패했을 때만 KeynoteSweeper 윈도우에 결과를 표시합니다. Keynote의 실행 취소로 되돌릴 수 있습니다. 윈도우의 체크상자 선택은 바뀌지 않습니다. 시스템 설정 › 키보드 › 키보드 단축키 › 서비스에서 단축키를 지정할 수 있으며, 항목이 보이지 않으면 같은 곳에서 켜져 있는지 확인하세요.

## 작동 방식
- **숨긴 슬라이드**: Apple Events로 Keynote가 직접 삭제합니다. 모든 슬라이드가 숨겨져 있으면 삭제하지 않습니다.
- **사용하지 않는 마스터**: Keynote는 AppleScript로 마스터를 삭제할 수 없으므로 보기 › 슬라이드 레이아웃 편집을 열고 탐색기에서 대상을 선택한 후 Delete 키로 삭제합니다. 삭제 전에 선택한 마스터 이름이 일치하는지 확인하고 일치하지 않으면 삭제하지 않습니다. 끝나면 편집 모드를 닫습니다.
- **전환 효과**: Apple Events로 각 슬라이드의 효과를 '없음'으로 합니다. 자동 진행, 지연, 지속 시간은 유지됩니다.
- **객체 애니메이션(빌드 인, 빌드 아웃, 동작)**: AppleScript로 다룰 수 없으므로 보기 › 빌드 순서 보기를 열고 슬라이드를 하나씩 표시하여 목록을 모두 선택한 후 Delete 키로 삭제합니다. 끝나면 보던 슬라이드로 돌아가고 직접 연 패널은 닫습니다. 슬라이드를 돌아봐야 셀 수 있으므로 개수는 실행 후에 표시합니다.
- 처리 순서: 숨긴 슬라이드 → 전환 효과 → 객체 애니메이션 → 마스터. 숨긴 슬라이드도 선택하면 그 슬라이드만 사용하던 마스터도 함께 삭제합니다.
- 마스터는 이름으로 판단합니다. 같은 이름의 마스터가 여러 개이고 그중 하나가 사용 중이면 모두 유지합니다. 마지막 마스터는 삭제하지 않습니다.

## 삭제 중 주의 사항
마스터와 객체 애니메이션 삭제 중에는 Keynote가 맨 앞에 오고 키 입력으로 선택을 이동합니다. 끝날 때까지 마우스나 키보드를 만지지 마세요. 다른 앱으로 전환하거나 맨 앞 프레젠테이션이 바뀌면 즉시 중지합니다.

## 되돌리기
Keynote의 편집 › 실행 취소(⌘Z)로 하나씩 되돌릴 수 있습니다. 저장하기 전에는 파일이 바뀌지 않으므로 저장하지 않고 닫아도 됩니다. 이 앱 자체에는 실행 취소 기능이 없습니다.

## 설정과 단축키
설정(⌘,) › 시작 및 백그라운드:
- 로그인 시 실행(기본 끔)
- 시작 시 메인 윈도우 표시 안 함
- 창을 닫아도 계속 실행
- 메뉴 막대에 표시
- 앱 실행 키보드 단축키
같은 탭에 손쉬운 사용과 Keynote 제어 권한 상태를 표시합니다. 체크상자 선택은 다음 실행 때도 유지됩니다.
계속 실행 중에는 Dock 또는 메뉴 막대 아이콘에서 다시 열 수 있습니다.
### 키보드 단축키
- **⌘Return**: 삭제
- **⌘O**: 파일 열기
- **⌘R**: 다시 불러오기
- **Esc**: 취소
- **⌘0**: 메인 윈도우 열기(닫은 후에도 다시 표시)
- **⌘W**: 윈도우 닫기
- **⌘,**: 설정
- **⌘?**: 도움말
- **⌘Q**: 종료
※ 삭제 중에는 종료할 수 없으니 완료를 기다리거나 먼저 취소하세요.

## 권한
- **자동화(Keynote)**: 프레젠테이션을 읽고 숨긴 슬라이드를 삭제하는 데 사용합니다. 처음 물을 때 "허용"을 선택하세요. 거부했다면 시스템 설정 › 개인정보 보호 및 보안 › 자동화에서 KeynoteSweeper의 Keynote를 켜세요.
- **손쉬운 사용**: 마스터와 객체 애니메이션을 삭제할 때 Keynote 창을 조작하는 데 사용합니다. 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 KeynoteSweeper를 켜세요. 권한이 없어도 숨긴 슬라이드와 전환 효과는 삭제할 수 있습니다.
설정과 오류 메시지에 각 설정을 여는 버튼이 있습니다. 전체 디스크 접근 권한은 필요 없습니다.

## 개인정보
모든 처리는 이 Mac에서 이루어지며 프레젠테이션 내용을 업로드하지 않고 앱 자체는 네트워크에 연결하지 않으며("note 글 열기"는 브라우저로 엽니다) 진단 로그를 저장하지 않습니다. Keynote만 조작하며 다른 앱에는 영향을 주지 않습니다.

## 문제 해결
- **Keynote가 실행 중이 아님**: Keynote에서 프레젠테이션을 연 후 "다시 불러오기"를 누르세요. KeynoteSweeper는 Keynote를 실행하지 않습니다.
- **슬라이드 레이아웃 편집을 열 수 없음**: Keynote의 대화상자나 시트를 닫고 다시 시도하세요.
- **서비스에 항목이 보이지 않음**: 다음 순서로 시도하세요.
1. KeynoteSweeper를 응용 프로그램 폴더에 넣고 한 번 실행합니다(실행할 때 서비스를 등록합니다).
2. 시스템 설정 › 키보드 › 키보드 단축키 › 서비스에서 KeynoteSweeper 항목이 켜져 있는지 확인합니다.
3. 로그아웃 후 다시 로그인합니다. 터미널에서 /System/Library/CoreServices/pbs -update를 실행해도 다시 등록됩니다.
항목은 Keynote가 맨 앞에 있을 때만 표시됩니다.
- **삭제하지 못한 마스터가 있음**: "삭제"를 다시 누르면 남은 항목만 다시 삭제합니다.
- **손쉬운 사용을 허용했는데 작동하지 않음**: 앱을 다시 시작하세요. 앱을 업데이트한 후에는 권한을 껐다가 다시 켜야 할 수 있습니다.
- 앱 메뉴의 "업데이트 확인…"과 "업데이트 자동 확인"은 업데이트 주소와 서명 키가 설정되지 않아 준비 중으로 표시되며 네트워크에 연결하지 않습니다. 공증도 설정되지 않았습니다. Apple Silicon, macOS 13 이상.
- 도움말 메뉴의 "note 글 열기"에서 지원 정보를 볼 수 있습니다.

## 삭제
로그인 시 실행을 끄고 종료한 후 앱을 휴지통으로 옮기세요. 시스템 설정의 손쉬운 사용과 자동화 목록에서도 제거할 수 있습니다. 설정 식별자: jp.local.KeynoteSweeper.
