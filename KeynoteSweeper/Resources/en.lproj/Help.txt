## Basics
1. Choose the presentation:
- Drop a .key file on the KeynoteSweeper window (or its Dock icon), or use Open File… (Command-O). The file opens in Keynote and only that presentation is used, even if another one is in front.
- With nothing dropped, Keynote's front presentation is used.
2. The presentation's name and how many masters are unused and slides are hidden are shown. Click Reload (Command-R) if it looks out of date. Use Front Presentation switches back from a dropped file.
3. Under Delete, choose:
- Delete unused masters
- Delete hidden slides
- Remove all transitions
- Remove all object animations
4. Click Delete (Command-Return), then confirm.
5. The result lists what was deleted and anything that could not be.

## From Keynote's Services menu
Keynote › Services shows these items while Keynote is active:
- Delete Unused Masters
- Delete Hidden Slides
- Remove Transitions
- Remove Object Animations
- Remove All Animations (transitions and object animations)
They work on Keynote's front presentation. They delete right away without a confirmation dialog, and Keynote stays in front. KeynoteSweeper's window appears only if something could not be deleted or failed. Keynote's Undo restores the deletions. The checkboxes in the window are not changed. Assign keys in System Settings › Keyboard › Keyboard Shortcuts › Services, and turn the items on there if they are missing.

## How it works
- **Hidden slides** are deleted by Keynote through Apple Events. If every slide is hidden, nothing is deleted.
- **Unused masters** cannot be deleted with AppleScript, so KeynoteSweeper opens View › Edit Slide Layouts, selects each one in the navigator and presses Delete. It checks the selected master's name before deleting and skips it if it does not match. The editor is closed afterwards.
- **Transitions** are set to None through Apple Events. Auto-advance, delay and duration are kept.
- **Object animations (build in, build out, actions)** are not scriptable, so KeynoteSweeper opens View › Show Build Order, shows each slide, selects the whole list and presses Delete. It returns to the slide you were on and closes the panel if it opened it. They can only be counted by visiting the slides, so the count appears afterwards.
- Order: hidden slides, transitions, object animations, then masters. With hidden slides on, masters used only by them are deleted too.
- Masters are matched by name. If several share a name and one is used, all are kept. The last master is never deleted.

## While deleting
Keynote comes to the front while masters or object animations are deleted and the selection is moved with key presses. Don't touch the mouse or keyboard until it finishes. Switching apps or changing the front presentation stops it.

## Undo
Keynote's Edit › Undo (Command-Z) restores deletions one at a time. The file is unchanged until you save, so you can also close without saving. KeynoteSweeper itself has no Undo.

## Settings and shortcuts
Settings (Command-comma) › Startup & Background:
- Open at login (off by default)
- Hide main window at startup
- Keep running after closing
- Show in menu bar
- App launch keyboard shortcut
The same tab shows the Accessibility and Keynote control permissions. Your checkbox choices are kept between launches.
While it keeps running, reopen it from the Dock or the menu bar icon.
### Keyboard shortcuts
- **Command-Return**: delete
- **Command-O**: open a file
- **Command-R**: reload
- **Escape**: cancel
- **Command-0**: open the main window (also after closing it)
- **Command-W**: close the window
- **Command-comma**: Settings
- **Command-?**: Help
- **Command-Q**: quit
※ Quitting is blocked while deleting; wait or cancel first.

## Permissions
- **Automation (Keynote)**: reads the presentation and deletes hidden slides. Choose Allow when asked. If you declined, turn on Keynote for KeynoteSweeper in System Settings › Privacy & Security › Automation.
- **Accessibility**: operates Keynote's window to delete masters and object animations. Turn on KeynoteSweeper in System Settings › Privacy & Security › Accessibility. Hidden slides and transitions can be removed without it.
Settings and the error messages have buttons to open these. Full Disk Access is not needed.

## Privacy
Everything runs on this Mac. Presentation contents are not uploaded, the app makes no network connections (Open the note Article opens your browser), and no diagnostic log is saved. Only Keynote is operated; other apps are not affected.

## Troubleshooting
- **Keynote is not running**: open a presentation in Keynote, then click Reload. KeynoteSweeper never launches Keynote.
- **Could not open Edit Slide Layouts**: close any dialog or sheet in Keynote and try again.
- **No items in the Services menu**: try these in order.
1. Put KeynoteSweeper in the Applications folder and open it once (it registers the services at launch).
2. In System Settings › Keyboard › Keyboard Shortcuts › Services, make sure the KeynoteSweeper items are on.
3. Log out and back in. In Terminal, /System/Library/CoreServices/pbs -update also re-registers them.
The items appear only while Keynote is active.
- **Some masters were not deleted**: click Delete again to retry the remaining ones.
- **Accessibility allowed but not working**: restart the app. After an update you may need to turn the permission off and on again.
- Check for Updates… and Automatically Check for Updates in the app menu say updates are not configured yet (no update feed or signing key) and make no network access. Notarization is not configured either. Apple Silicon, macOS 13 or later.
- Help › Open the note Article opens support information.

## Removing
Turn off Open at login, quit, then move the app to the Trash. You can also remove it from the Accessibility and Automation lists in System Settings. Preferences identifier: jp.local.KeynoteSweeper.
