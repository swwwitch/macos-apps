## 基本操作
VectorKeys 在 Illustrator 位于前台时，用键盘快捷键运行已登记的脚本（.jsx）。
- 选择“文件”>“添加脚本…”（⌘O），或将 .jsx 文件拖到窗口中。可一次添加多个。
- 在列表中选择脚本，右侧会显示文件位置和快捷键栏。点按快捷键栏后按下按键即可分配。
- 列表中的复选框可逐个开关脚本的快捷键。
- 点按“运行”会先将 Illustrator 置于前台再运行。
- 关闭右上角的“使用快捷键”可暂停所有快捷键（也可从菜单栏图标切换）。
- “最近运行”显示最近的结果。因错误停止时，会显示 Illustrator 返回的信息。不会保存，退出应用时清除。

## 运行脚本
只能添加脚本文件作为步骤。多个脚本依次运行，遇到错误即停止。
- 用“运行脚本”添加文件，通过各行的 … 菜单移动或删除。
- 保留以前保存的菜单步骤。只要包含菜单步骤，整个项目就不会运行，也不会注册快捷键。明确删除这些步骤后即可运行其余脚本。

## 管理脚本
- 可添加 .jsx、.js 和 .jsxbin。同一文件不会重复登记。
- 可在名称栏中更改名称，文件名不变。
- 可拖移列表以重新排序（搜索时除外）。
- 文件被移动或重命名后会显示“文件丢失”。用“重新选择文件…”重新指定后，快捷键仍可使用。
- 只记录文件的位置。修改脚本内容后，下次运行即使用新内容。
- 列表右侧和详细栏会显示运行次数和最近运行时间。统计通过快捷键和“运行”按钮无错误完成的运行。关闭“显示”>“显示使用次数”即可隐藏（仍会继续计数）。

## 从 Keyboard Maestro 导入
将从 Keyboard Maestro 导出的宏（.kmmacros）拖到窗口中，或选择“文件”>“从 Keyboard Maestro 导入…”（⌘I）。
- 只导入全部有效步骤都是脚本文件或内嵌 JSX 的宏。含菜单操作或其他不支持动作的宏会整体跳过，不会只提取脚本部分。保留名称、快捷键和开关状态。
- 宏中写入的代码会存储为 .jsx 文件，位于 ~/Library/Application Support/VectorKeys/Imported。
- 含其他步骤或使用变量的宏不会导入，并显示原因。
- 请在 Keyboard Maestro 中关闭相同的宏，否则脚本会运行两次。可用导入后对话框中的按钮，或“工具”>“关闭所选脚本的 KM 宏”关闭（也有重新打开的项目）。首次使用时会请求控制 Keyboard Maestro 的许可。

## 类别
左栏可将脚本分到各个类别。
- 点按下方的 + 新建类别。右键点按可重命名或删除。删除后其中的脚本不会被删除，而是移到“未分类”。
- 可在右侧的“类别”中选择，或将列表中的行拖到左侧类别，或用右键菜单中的“类别”更改脚本的类别。用 ⌘点按或⇧点按选择多个后，可一并拖移、更改或删除。
- 选中某个类别时添加的脚本会进入该类别。“全部”会按类别分标题显示。
- 从 Keyboard Maestro 导入时，宏的组名会成为类别。

## 工具
- “工具”>“统计…”：按使用次数从多到少显示所有脚本，并附上类别、最近运行时间和快捷键。双击某行可在主窗口中选中该脚本。
- “工具”>“在名称中查找和替换…”：在所选脚本（可多选）的名称中查找和替换。确认替换前→替换后后点按“替换”。可使用正则表达式（用 $1 等引用）和区分大小写。文件名不变。
- “工具”>“删除 KM 宏编号”：从所选脚本（可多选）名称开头删除“11)”“21）”“11)1 ”之类的编号。文件名不变。

## 排序
可在搜索栏右侧选择手动、按名称或按快捷键。在“手动”且未搜索时可拖移重新排序。多个脚本使用同一按键时，手动顺序中靠上的脚本会响应。

## 快捷键
- 按法：可选择“按一次”或“按两次”。同一按键同时分配两者时，“按一次”的脚本会等待第二次按下（约 0.3 秒）后再运行。列表中按两次的按键带有“×2”。
- 点按按键栏即开始录制。再次点按或按 Esc 取消。
- 脚本快捷键：仅在 Illustrator 位于前台时注册，因此在其他应用中按键保持原有功能。若与 Illustrator 自身的快捷键相同，则优先运行脚本。
- 调出应用的快捷键：在设置的“启动与常驻”中分配后，可从任何应用显示 VectorKeys 窗口（默认未设置）。
- ⌘O：添加脚本
- ⌘I：从 Keyboard Maestro 导入
- ⌘F：在名称中查找和替换（在列表中选中脚本时）
- ⌘0：打开主窗口
- ⌘,：设置
- ⌘W：关闭窗口
- ⌘?：本帮助
两个脚本使用同一按键时，只有列表中靠上的脚本会响应，按键以红色显示。

## 权限与隐私
- 自动化（Adobe Illustrator）：用于运行脚本。首次运行时会请求许可。
- 自动化（Keyboard Maestro）：用于关闭或打开已导入的原始宏。
- 无需辅助功能权限。在 Illustrator 中运行脚本使用自动化权限。
列表存储在 ~/Library/Application Support/VectorKeys/Scripts.json。脚本文件只读取，不会修改。不会向外部发送任何内容。

## 退出与常驻
关闭窗口后应用仍会常驻，快捷键继续有效。可从 Dock 或菜单栏图标再次打开。选择“VectorKeys”>“退出 VectorKeys”（⌘Q）退出。

## 疑难解答
- 快捷键无效：请确认 Illustrator 位于前台、“使用快捷键”已打开、脚本的复选框已勾选。按键显示为红色时，表示重复或被其他应用占用。
- “没有控制 Illustrator 的权限”：请在“系统设置”>“隐私与安全性”>“自动化”中为 VectorKeys 打开 Adobe Illustrator。
- “找不到文件”：请用“重新选择文件…”重新指定。
- 之前的运行未结束：显示对话框的脚本会让下一次运行等待到对话框关闭。最多等待 3 次，超出的会被跳过。

## 删除与恢复
在列表中选择后点按 −（或按 Delete 键）删除。文件本身不会被删除（仅从 Keyboard Maestro 代码保存的 .jsx 在没有其他用途时移到废纸篓）。删除、用工具重命名、更改类别和导入可用“编辑”>“撤销”（⌘Z）还原。若要全部清除，请退出应用后删除 Scripts.json。


共享设置标签页提供导出、导入及 iCloud Drive 或 Dropbox 文件夹同步。确认后导入会替换共享设置。所有同步的 Mac 均须更新至 1.5.1 或更高版本。 共享全局快捷键启用状态、使用次数显示和排序。 不共享脚本列表、文件、各项目快捷键、启动与常驻设置、应用启动快捷键及窗口位置。


## JavaScript
选择文件 > 添加 JavaScript 代码，在编辑框中输入代码。文件和代码步骤可混合并按顺序运行。空代码无法运行。代码会保存，重启后可继续编辑。


## Palette
选择分类，点按分类下方的面板按钮，或选择显示 > 显示为面板。也可从分类右键菜单打开。支持同时显示多个分类面板，点按脚本即可在 Illustrator 中运行。面板保持浮动并记住位置和大小。关闭后可再次打开。已停用或无法运行的项目不可执行。退出应用会关闭面板，重启后不会自动打开。


## Layout / Hotkeys / SCRIPTMETA
拖动列间边界调整宽度，保存在本机。在选择分类后的右侧面板中可为每个分类指定打开快捷键，其他应用中也有效。关闭全局快捷键开关可暂停。快捷键随列表保存，并跟随分类重命名与删除。文件和代码中的 SCRIPTMETA 注释若含 Script-ID 和 Version，将显示版本。标签缺失、不可读或二进制则不显示。读取前256KiB，应用激活时刷新。


## Script Information
详情下方显示脚本信息。概述、版本、URL、作者读取 SCRIPTMETA 的 Description、Version、Meta-URL、Author。点击展开概述。README依次查找脚本同名.md、同目录README.md、README.txt，点击打开。备注随项目保存，不修改原脚本。多个步骤分别显示信息。缺失信息显示未提供。


## Source Code
文件步骤提供在访达中显示和打开源代码按钮。源代码使用文件关联的应用打开。文件缺失时禁用两个按钮，.jsxbin禁用源代码按钮。直接输入代码原地编辑。


## SCRIPT Metadata
也支持从 SCRIPT_NAME、SCRIPT_VERSION、SCRIPT_AUTHOR、SCRIPT_RELEASED、SCRIPT_UPDATED、SCRIPT_README_JA、SCRIPT_README_EN、SCRIPT_ARTICLE_URL 字符串常量读取信息。首次发布和更新日期分别显示。日语环境优先JA，否则优先EN，缺失时使用另一种。SCRIPTMETA优先。不执行表达式。快捷键设置、解除和按键次数排在同一行。


## Quick Look
点击文件步骤的快速查看打开macOS标准预览。关闭后返回。支持格式和显示内容取决于快速查看，不修改原文件。


项目（第二列）排序旁的显示按钮可分别显示版本、次数和文件名，默认均关闭。多选后右键排序：名称和快捷键升序，次数降序。仅调整各分类内所选位置，可撤销。在分类右侧面板设置面板开关、快捷键及行为。禁用快捷键模式在关闭时仍生效。自动关闭模式在接受执行时关闭，允许项目快捷键。


在项目列选中项目后按Command-Delete打开删除确认，文字编辑保留标准删除操作。右侧可直接编辑分类面板名称，Return或移出焦点确认；不接受空名或重名。详情和右键菜单提供Finder式七色及无颜色。列表和面板为项目整体背景着色，不更改文件标签。工具＞更新脚本信息重新读取元数据，解说页面与代码URL分开显示。代码URL来自Code-URL/Source-URL、SCRIPT_CODE_URL/SCRIPT_GITHUB_URL或README内唯一的同名脚本链接。仅此命令获取在线README，失败在最近执行中显示。保留名称、备注、快捷键和脚本代码。


面板仅在Illustrator位于前台时显示。切换应用自动隐藏，返回时恢复已打开的面板。手动关闭或执行后关闭的面板不会恢复。在VectorKeys中打开时，也会隐藏等待Illustrator成为前台。


在项目详情输入逗号分隔的标签，按Return或保存标签。保存空值删除手动标签。列表上方标签菜单可筛选。设置中的监视文件夹添加后立即读取，每15秒检查一次。各层子文件夹名成为单独的来源标签。停止监视保留项目；原本移动或删除不会自动删除已有项目和标签。从列表删除的文件不会重新添加。跳过隐藏项和符号链接。监视路径仅保存在本机。


自动分组默认关闭。开启后，各层子目录（含空目录）成为分类，新项目及未分类的单文件项目归入对应分类。父/子形式命名，各根目录同名相对路径合并。已有分类保持。排除名称每行一个并保存，默认single-function及backup。任意层级忽略大小写完全匹配后排除所有下层，不导入标签或分组。不会自动删除已有项目、标签或分类。


通过加号或右键添加分隔线，置于所选项目后，可拖动、删除及在详情改名。分隔线不执行、不计入统计，排序限于分隔线之间。统计可选择显示列，点击表头切换升降序。脚本名使用Name元数据或文件名，路径汇总各步骤。新文件若有SCRIPT_DESCRIPTION_JA则据此命名，用户修改及旧名称不被信息更新覆盖。源代码由文件关联应用打开。

更新信息时，主窗口显示进度条和处理数量。


工具＞更新脚本信息可选所选项目（支持多选）、所选分组或全部。无目标时禁用。进度按目标文件计数，名称更新限于指定范围。旧文件名来源的项目可采用SCRIPT_DESCRIPTION_JA，不同的已有名称及明确的手动改名保持，即使手动名与文件名相同。


右侧详情采用紧凑行布局，标签以Return或勾选按钮保存，路径始终显示，脚本信息点击展开。已删除快捷键说明开闭项。面板上方可搜索项目名及文件名，搜索时隐藏分隔线，清空后恢复。添加文件名默认关闭，所有面板共享保存；代码项不生成文件名。搜索时面板接受键盘输入，执行时操作返回Illustrator。


概述与脚本信息独立展开。文件路径始终显示。脚本信息开闭动画为0.12秒，减少动态效果开启时禁用动画。
