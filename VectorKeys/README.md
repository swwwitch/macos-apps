# VectorKeys

登録したIllustratorのスクリプト（.jsx・.js・.jsxbin）を、Illustratorが前面のときにキーボードショートカットで実行するAppKit/SwiftUIアプリ。Apple Silicon / macOS 13以降。

- 登録：［スクリプトを追加…］（⌘O）でファイルを選ぶか、ウインドウへドラッグ。同じパスは二重に登録しない。名前は変えられる（初期値はファイル名）。並べ替えはドラッグ。
- ショートカット：スクリプトごとに割り当て。Illustratorが前面のときだけ登録する（Carbon `RegisterEventHotKey`）。同じキーは一覧で上のものだけ。押した瞬間にもIllustratorが前面か確かめる。
- 実行：`do javascript (POSIX file … as alias)` を osascript 経由で。前面のIllustratorをパスで指定する（複数バージョン起動時の取り違えを避ける）。ダイアログボックスを出すスクリプトのため timeout は3600秒。直列で、待ちは3件まで。
- ファイルを移動したら「ファイルなし」と表示。［ファイルを選び直す…］でショートカットを保ったまま指定し直せる。
- アプリ呼び出しのショートカットは既定なし（⌃⌥＋英字はKeyboard Maestroで全部使用済み、2026-10-26）。設定で割り当てる。
- KMのマクロを取り込んで手順ごと再現したいときは VectorMaestro を使う。

## スクリプト専用版（1.5.0／build 7）

- メニューコマンドの追加・選択・実行と、そのためのアクセシビリティ設定を削除。スクリプトファイルだけを呼び出す。複数のスクリプトは順番に実行する。
- 1.4.0で保存したメニュー手順は互換性のためデータを保持する。メニュー手順を含む項目は全体を実行せず、ホットキーも登録しない。手順の削除を利用者が選ぶまで、スクリプト部分だけを実行しない。
- KMの取り込みも有効な手順がすべてスクリプト実行であるマクロだけを対象とし、メニュー操作との混在マクロは全体をスキップする。
- 今回はユーザーの明示指示により公証Macで1.5.0（7）に確定。ビルド・公証・両配置先への更新結果はリリース記録を参照。

## しくみ

- `Source/Scripts.swift`：登録内容（Foundationのみ、テスト対象）・AppleScriptの組み立て・osascript
- `Source/Runner.swift`：Illustratorの判定と直列実行
- `Source/AppModel.swift`：ショートカットの登録、追加・削除・指定し直し、実行結果
- `Source/Views.swift`：主画面・設定
- `Source/main.swift`：メニュー・起動
- 一覧は `~/Library/Application Support/VectorKeys/Scripts.json`。スクリプトのファイルは読むだけ。
- 外部通信なし（更新確認を除く。配信先は未設定）。権限：オートメーション（Illustrator）。アクセシビリティは使わない。

## ビルド・テスト

```
./test.sh            # 単体テスト＋4言語の翻訳キー・プレースホルダー検証
./build.sh           # build/VectorKeys.app
./build.sh --deploy  # 検証後、/Applications と Latest Builds へ配置
Assets/make-icon.sh  # アイコンを作り直す
```

## 設定の共有（1.5.1）
「情報」の前に「設定の共有」を追加。設定の「設定の共有」で書き出し・読み込み・iCloud DriveやDropboxなどのフォルダー同期ができます。読み込みは確認後に共有設定を置き換えます。同期する全Macを1.5.1以降へ更新してください。ホットキー全体の有効状態・使用回数表示・並び順を共有します。スクリプト一覧・実ファイル・項目別ホットキー、起動・常駐・呼び出しホットキー・ウインドウ位置は共有しません。

### JavaScriptコードの直書き
［ファイル］＞［JavaScriptコードを追加］または一覧の＋メニューで作成し、コードを入力します。ファイル指定と直書きは手順として混在でき、上から順にIllustratorで実行します。コードは一覧とともに保存されます。空のコードを含む項目は実行できません。

### 1.6.0 (11) 画面整理
詳細欄を縦配置にしてコード欄を拡幅。名前と実行ボタンを上段に配置し、手順追加をメニューに集約。ホットキーの説明と実行履歴は開閉でき、エラー時は履歴を自動展開します。ヘッダーを小さくし、一覧と詳細欄の幅を調整しました。

### カテゴリパレット（1.7.0）
カテゴリを選び、カテゴリ欄下部のパレットボタンまたは［表示］＞［パレットとして表示］から開きます。カテゴリの右クリックにも対応。複数カテゴリを同時に表示でき、ボタンからファイル・JavaScriptの各項目をIllustratorで実行できます。パレットは選択を奪わず前面に残り、位置とサイズを保持。オフ・実行不可の項目は実行できません。終了時は閉じ、次回は手動で再表示します。

### 1.8.0 (13)
3カラムの境界ドラッグと幅保存、設定＞パレットのカテゴリ別表示ホットキー、アプリ版のアイコン下表示を追加。SCRIPTMETA v1.4のローカルコメントからScript-IDとVersionを読み、ファイル/直書きの版を表示します（説明ブロックは解析除外、タグがなければ非表示）。ファイルは先頭256KiB、アプリ再アクティブ化時に再取得。仕様: https://github.com/Yamonov/SCRIPTMETA/blob/main/SCRIPTMETA.md 。

### スクリプト情報（1.8.1）
詳細下部に概要・版・URL・README・作者・メモを表示。SCRIPTMETAのDescription/Version/Meta-URL/Authorを読み、概要は開閉式。READMEは同名.md、同フォルダーREADME.md/README.txtの順に探します。メモは登録項目へ保存し原本を変更しません。複数手順は各手順の情報を分けて表示します。

### 1.8.2 (15)
ファイル手順に［Finderで表示］［ソースコードを開く］を追加。ソースは実行用のファイル関連付けを使わずテキストエディタに開きます。不在ファイル・バイナリは適切に無効化します。

### 1.8.3 (16)

### SCRIPT変数（1.9.0 / 17）
SCRIPT_NAME/VERSION/AUTHOR/RELEASED/UPDATED/README_JA/README_EN/ARTICLE_URLの文字列定数から情報を取得。SCRIPTMETA優先で不足を補完します。READMEは言語に応じJA/ENを選択。初回公開と更新日を区別し、変数の式を実行・評価しません。Finder・ソースボタンとホットキー一行化も含みます。

### Quick Look（1.9.1 / 18）
ファイル手順の［Quick Lookで見る］からmacOS標準のプレビューを開きます。表示可能な形式はQuick Lookに従います。
