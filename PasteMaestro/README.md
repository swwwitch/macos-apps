# PasteMaestro

通常版 1.1.0（build 3）、macOS 13以降。IncrementPaste、PasteInARow、PasteMatchStyleの貼り付け機能を、新しいBundle ID `jp.dtp-transit.pastemaestro` に統合。

- 連番：数字・日付・英字、増加量、コピー後の初回をそのまま、直前のクリップボード値へ戻す。
- 1行ずつ：選択文字をスロットへ追加、行頭の整形、順番／選択行／全行の貼り付け、★で保持、改行付き、最初からやり直す。スロットはメモリ内のみ。
- 書式を合わせる：対象アプリのメニュー優先、プレーンテキストへのフォールバック、検索メニュー名編集、クリップボード復元。

主画面の3モード、共通の起動・常駐／対象外アプリ／設定共有／情報、4言語ヘルプを用意。機能ホットキーは初期OFF。候補は⌥V、⌃⌥V、⌃⌘C、⇧⌘V。保存済みの割り当ては保持する。呼び出しキーは初期未設定で、常駐中のみ使用可能（未起動時の起動は非対応）。ログイン起動は初期OFF。

既存3アプリの設定・ソース・配布物を変更しない。設定の自動移行は行わず独立した設定領域を使用する。旧アプリが1つでも起動中なら機能を停止し、主画面に理由を表示する。対象外アプリの初期値は3アプリの除外リストの和集合。任意の他アプリとの競合は保証しない。

クリップボード操作はコピー待ち・貼り付け後の復元まで排他制御する。連番と行貼り付けの排他は0.15秒、行の復元は0.10秒。対象アプリが混雑している場合の読取遅延には実機での確認が必要。復元待ち中の別操作は理由を表示して拒否し、終了も復元完了まで保留する。新しいコピーを遅延復元で上書きしない。キー送信完了は対象アプリの貼り付け成功の保証ではない。

## 開発・検証

`NO_DEPLOY=1 SKIP_PUBLISH=1 ./build.sh` でワークスペース内の `PasteMaestro.app` を作成し、チーム証明書で署名する。配置は既定で無効。開発Macから配布先に書かない。`./test.sh` で増加規則、行整形、メニュー名、クリップボード排他、4言語のキー・書式指定子を検証。

共通UI部品は既存3アプリとSharedの実装を再利用。ビルド時に他アプリのソースを変更する一括syncは実行しない。更新配信URL・鍵は未設定で、更新確認の入口は準備中として機能する。

現時点はarm64の開発用ビルド。実際の他アプリへの貼り付け、ログイン、権限変更、設定同期往復、Universal、公証・配置・公開は未確認／未実施。詳しくはTests/BUILD-NOTES-20261101.mdを参照。

## 1.1.0の画面構成

主画面の最上部は現行アイコン＋共通機能見出し。その下にラベルなしの3機能切替、選択機能のホットキー有効化／割り当て／初期化、プレビュー・結果・操作を置く。機能ホットキーは設定から除去した。保存済みの割り当てを読み込み、スロット追加の新規／初期化値だけを⌃⌘Cとする。

行一覧は独立したNSPanel。非アクティブ・フローティング、位置保存、閉じる・再表示、最小サイズ、画面外復帰に対応。「選択文字を追加」ボタン、全行貼り付け、クリア、やり直しを置く。行本文の単クリックは選択、ダブルクリックは貼り付け。★ボタンは別のヒット領域で保持だけを切り替える。Return／⌥Return／⌘Returnはこのパレットだけで処理。手動貼り付けはホットキー無効でも使えるが、一時停止・対象外・権限不足時には実行しない。パレットを閉じてもスロットは終了まで保持する。

設定は「起動・常駐」（ログイン・Dock・常駐・呼び出しキー・メニューバー・権限）、「貼り付けの動作」（行・連番・書式の詳細を3つの開閉グループへ）、「対象外アプリ」、「設定の共有」、「情報」の5分類。行の整形、空になった際のパレット、結果表示、増加量・日付・英字・初回動作、メニュー名・クリップボード復元はここで設定する。長い補足説明は閉じた状態から開く。

起動と画面・設定・空パレットは確認。外部アプリへのパレット追加・ダブルクリック貼り付け・フォーカス保持の実機合格は未確認。詳しくはTests/BUILD-NOTES-build3-20261101.md。
