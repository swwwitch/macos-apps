# DocklessLauncher

macOS 13以降 / Apple Silicon。1.10.3 (build 23)。紹介記事：https://note.com/swwwitch/n/n3bce910ced54

旧名 AppLauncher（2026-10-13 に改名。Bundle ID と設定の保存先 jp.dtp-transit.applauncher は据え置き）。

アプリごとにキーボードショートカットを登録し、押すだけでそのアプリを起動・前面化するメニューバー常駐アプリです。Keyboard Maestroの「起動（アプリ）」グループを置き換える目的で作りました。

## 使い方

- 「アプリを追加…」またはウインドウへの .app のドラッグ＆ドロップ（複数可）で登録し、行のキーのボタンで記録します（Escで取消）。
- 一覧の行へ .app をドロップすると、その行のアプリを入れ替えます（キー・条件・オプションはそのまま、⌘Zで取り消し）。同じアプリの別バージョンなら「このパスのアプリ」に切り替えます。
- キーを押すとアプリを起動、起動中なら前面にします。すでに前面なら何もしません。
- アイコンかアプリ名のダブルクリック、行の右クリック／…メニューの「今すぐ起動」でも起動できます（行のチェックや一時停止に関係なし）。
- 一覧の上の検索欄でアプリ名・Bundle ID・キー（⌃⌥I、I、×2）を絞り込み、「アプリ名」「キー」で並べ替えます。選択中をもう一度クリックすると昇順・降順が切り替わります。

## キーボード表示

- 「一覧／キーボード」で切り替え。接続中のキーボード（JIS／US、手動切り替え可）の図に、修飾キーの組み合わせごとにアプリのアイコンを表示（アプリ名はマウスを重ねたときだけ）。「すべて」は色分けで重ねる。
- キーのダブルクリックで起動、右クリックで行と同じメニュー、空いたキーのクリック、または修飾キーを選んだ状態でキーへ .app をドロップしてアプリを割り当て。修飾キーを選んだ状態でアイコンを別のキーへドラッグすると移動・入れ替え（そのキーの行をまとめて、⌘Zで取り消し）。macOSのショートカットは斜線、×2はダブルタップ、漏斗は条件付き。

## 行のオプション（…メニュー／右クリック）

- すべてのウインドウを前面へ（初期値オン）／ウインドウがなければ開き直す／ほかのアプリを隠す
- 起動後に入力ソースを「ABC」にする（すでに前面のときも切り替え）
- ダブルタップで実行：同じキーにシングルとダブルの2行を登録できる。両方あるキーはシングルが約0.3秒遅れる
- バージョンの選び方：標準（macOS）／最新版を優先（Launch Services の一覧と、登録パスの親フォルダーと同じ階層を探してバージョン比較）／このパスのアプリ。標準以外は、別バージョンが起動中でも選んだ方を使う
- 開く項目：起動後にそのアプリでフォルダーやファイルを開く
- URLによる条件：ブラウザー（Chrome・Safari・Firefoxなど）が指定URLで始まるページを表示中なら、キーをブラウザーへ渡す。押した時点でアクセシビリティAPI（AXWebAreaのAXURL）でURLを読む。要アクセシビリティ、未許可なら条件なしで起動
- 最前面のアプリによる条件：次のアプリでは使わない／次のアプリでだけ使う。条件の違う行どうしは同じキーを共有でき、そのとき使える行のうち登録順で先の行が優先

## 設定

- 起動・常駐：ログイン時に起動、起動時にメインウインドウを表示しない、Dockとアプリケーションスイッチャーに表示しない、閉じても常駐、メニューバーに表示
- ホットキー：全体の有効・無効、一時停止。動作：Path Finderが起動中ならFinderよりPath Finderを優先（初期値オン、Setapp版も対象）
- 対象外アプリ：共通部品 Shared/ExcludedApps（キー excludedBundleIDs、1.10 までの excluded を引き継ぐ）。前面のあいだは全キーを解除。アクセシビリティは「起動・常駐」の共通のグループ（URLによる条件だけで使う）
- macOSのショートカット（CopySymbolicHotKeys、システム設定の変更も反映）と同じキーは、記録時と一覧で警告（登録は可能）
- 設定の共有：共通部品 Shared/SettingsSync。「書き出す…／読み込む…」で DocklessLauncher-Settings.plist を書き出し・読み込み（「追加する」は無いアプリの行だけ加える／「置き換える」。以前の .docklesslauncher・旧 .applauncher も読める）、「設定の同期」で iCloud Drive・Dropbox などのフォルダーと同期。共有するのは登録したアプリ（entries）・ホットキー全体の有効・無効・Path Finder優先・一覧の表示方法と並び順。ログイン起動・常駐・メニューバー・対象外アプリ・ウインドウ・キーボード配列はMacごと

## 仕組み

- アプリは Bundle ID で特定し、見つからないときは登録時のパスを使う（「このパスのアプリ」はパスのみ）。
- ホットキーは Carbon の RegisterEventHotKey。同じキーは1回だけ登録し、押されたあとでシングル／ダブルを判定する。同じキー（同じタップ数）が複数あるときは登録順で先の行だけが有効。
- 起動・前面化は NSRunningApplication.activate と NSWorkspace.openApplication／open(_:withApplicationAt:)。前面化が拒否されたら Launch Services で開き直す。入力ソースは TISSelectInputSource。起動・切り替えに権限は不要。アクセシビリティはURLによる条件（URLの読み取りとキーの受け渡し）だけで使う。
- 設定は jp.dtp-transit.applauncher の UserDefaults（entries はJSON。後から足した項目は省略可能で、古い版の保存データも読める）。

## ビルドと検証

`./build.sh` でビルド・署名し、`/Applications` と `Latest Builds` に配置します。`./test.sh` は一覧の規則（重複・ダブルタップ・検索・並べ替え・Path Finder・バージョン比較・保存データ・書き出しファイル）、起動ポリシー、ショートカット、4言語の文言を検証します。

2026-10-13：1.7.0 (11) キーボード表示とURLによる条件を追加。キーボード表示は実画面で確認（US配列、33件）。URLの読み取りはChrome・Safari・Firefoxで実測（docs.google.com）。キー押下からの受け渡しは未確認。

2026-10-13：1.5.0 (8) 設定の「ホットキー」タブで落ちる不具合を修正（%@ に数値を渡していた。1.0.0から。check_resources.py に再発防止の検査を追加）。全5タブを開いて落ちないことを確認。

2026-10-13：1.4.0 (6) ビルド・自動テスト合格、両配置先一致、起動と登録32件の読み込みを確認。バージョン選択は実在の InDesign 2025/2026・Illustrator 8本で確認。ホットキー（ダブルタップ含む）での実機動作は未確認。
