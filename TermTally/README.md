## 元スクリプトとの対応

- そのまま：語句欄5つ・統一先の◉・件数・合計、ほかの語句に含まれる分は数えない、大文字と小文字を区別、単語単位、前後の文字数、除外、［すべてを統一］、1か所の置換、選択文字を取り込む、［検索］で読み取る方式、条件を変えたら検索し直すまで置き換え不可。
- 変更：「対象」はストーリー／ドキュメントのラジオをやめ、最後に使った文書を表示。ページ列は段落番号。チェック列を直接押せる。ユーザー指定で語句の呼び名を「キーワード」から「語句」、［置換文字列］を「個別に書き替え」、「行頭・行末のものは表示しない」を「段落内に限る」（行は隠さず、前後の文字を段落の中で切る。¶とその先は出さない）に変更。
- 追加：［揺れ候補を拾う］（ユーザー要望「語句を入れるのではなく、文章内で揺れ候補を自動でピックアップしたい」）。語句なしで全文を読み、`VariantFinder`（Matching.swift）で語を切り出して同じ語の表記違いを組にする。切り出すのはカタカナの連続・英数字の語・漢字＋送り仮名。大文字小文字・全角半角・長音・中黒・小さいかな・ヴ・送り仮名の違いを無視する。短いカタカナ語は語尾の長音だけ無視する（ビルとビールを分ける）。語中の仮名は連用形の1文字だけ認める（「入力する場合」と「入力した場合」を分ける）。組を選ぶと語句欄へ入り、読み取り済みの本文で検索する（Docsを読み直さない）。組を選ぶと単語単位を自動でオンにする（「仕事」の「事」に当てない）。
- 追加（ユーザー指示「1から5」）：
  - 定番の表記ゆれ辞書（`Source/VariantDictionary.swift`、先頭がかな書きの推奨）と自分の辞書（設定の「辞書」、UserDefaults `userDictionary`）。短いかなは語の中にあるので、置換の向きが漢字→かなになるよう先頭を推奨にしている。
  - 統一先の記憶（`variantRules`）と組の無視（`ignoredGroups`）。統一先の優先順は前回の統一先・辞書の推奨・最多の表記。
  - ［一覧をコピー］：組・表記・件数・統一先のタブ区切り。
  - Docsの一括置換：`GoogleDocsTarget.bulkKeywords` で「すべて置換」の結果と1件ずつの結果が一致するときだけ、検索と置換のダイアログを使う（大文字小文字を区別オン・正規表現オフ・発音区別符号を無視オフ、終わったら元に戻す）。前に検索バーの件数を確かめ、後に本文を読み戻して照合する。文書タブの選択肢が出るダイアログや、構造が異なるときは1件ずつに戻す。
  - 種類（カタカナ・漢字・英数字・辞書）と並び順の絞り込み。
- 「調整する／調整をする」の組（ユーザー指示）：漢字語・カタカナ語のあとの する 形を を の有無で比べる。統一は文字列の置き換えなので、する・します・した・して などの形ごとに別の組にする。
- 辞書の形式（`Source/DictionaryData.swift`、ユーザー提供のリストを整理）：「誤 → 正」は誤記だけで候補に出す。「? 誤 → 正」は要確認で統一先を選ばない。「A、B」は2つ以上が使われているときに候補に出す。自分の辞書も同じ形式（タブ区切りも可）。
- ［対象アプリを固定］（ユーザー指示）：`isTargetPinned`。固定中は対象の更新と操作前の引き直しをせず、控えたAX要素をそのまま使う。保存はしない（ウインドウを次回の起動で特定できないため）。
- 対象はウェブの内容（AXWebArea の下）を除く。VS Code や Electron のブラウザーは入力欄に見えている部分しか読めず、件数が黙って少なくなるため。
- 外した：親ページ・目次（InDesign固有）、表示倍率、該当文字を【】で囲む（ユーザー指定。代わりに一覧の該当文字を赤い太字にし、色を付けるかは設定の「表示」の `matchInRed`、色は `matchColor`（標準のカラーピッカー、空なら system red）。初期値オン）。

## しくみ

- `Source/Matching.swift`：検索・長い語句の除外・前後の文字・段落番号・置換の順序・除外の控え（Foundationのみ、テスト対象）。位置はUTF-16。
- `Source/VariantDictionary.swift`：表記ゆれ辞書と書き出し（Foundationのみ、テスト対象）。
- `Source/Targets.swift`：対象文書の判定と読み書き。
  - `AccessibilityTextTarget`：AXValueで読み、AXSelectedTextRange＋AXSelectedTextで書く。背面のまま動く。テキストエディットは選択でスクロールし、書式を保ち、連続の書き込みが⌘Z 1回で戻る（2026-11-06実測）。
  - `GoogleDocsTarget`：本文はcanvasでAXに出ない（AXWebAreaにあるのはメニューなど約700字）。判定はAXWebAreaのAXURL。読み取りは ⌘A→⌘C→←。位置の指定はDocsの検索バー（⌘F、欄へ貼り付け、件数表示「2 / 5」をAXで読み、return／⇧returnで移動、Esc）。そのあと⌘Cで選択を読み、見つけたときの文字と一致したら⌘V。貼り付け後は⇧←で読み戻して確かめる。後ろから置換するので前の順番は変わらない。キーはpostToPidで、1打ごとに前面と窓のタイトルを確かめ、変われば止まる。検索バーの件数が読み取った本文と異なれば何も変えない（ヘッダー・脚注に同じ語があるとき・［大文字と小文字の区別］がオンのとき）。
  - `ClipboardKeeper`：作業の前に控え、最後に戻す。途中でほかのアプリがコピーしたら戻さない。自分が書く分には org.nspasteboard.TransientType を付ける。
- `Source/AppModel.swift`：状態と操作。検索した文書を `searchedTarget` に控え、対象が変わったら結果を古い扱いにして、置換・表示は同じ文書でなければ実行しない。
- `Source/Views.swift`：主画面・設定。`Source/main.swift`：メニュー・起動・直前のアプリの追跡。
- 権限：アクセシビリティのみ。AppleScript（オートメーション）は使わない。読み取った文字は保存も送信もしない。外部通信なし（更新確認を除く。配信先は未設定）。
- アプリ呼び出しのホットキーは既定なし。
