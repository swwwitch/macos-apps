# KeynoteMaestro

![macOS](https://img.shields.io/badge/macOS-13%2B-lightgrey) ![version](https://img.shields.io/badge/version-1.2.2-blue) ![license](https://img.shields.io/badge/license-private-lightgrey)

Keynoteが前面のときだけ、102の操作をホットキーで実行するメニューバー常駐アプリ。Keyboard Maestro のマクログループ「Keynote」（`Keynote Macros.kmmacros`）の移植。メニュー項目への割り当てに加え、Keynoteでは設定できない操作（不透明度10〜100%、隠す・再表示、拡大縮小・幅±1pt・幅／高さいっぱい・同じ幅／高さ、トランジションの設定、スライド大の図形・中央の十字線・背景の図形、その場に複製、まとめて中央へ、表示中のスライドのPNG書き出し、アニメーションのプレビュー）を持つ。KeynoteSweeperの掃除6項目も、Keynoteの［サービス］の項目をAXで押してホットキーから呼べる（処理はKeynoteSweeper側、確認なしで削除するため⌃⌥0以外は初期値オフ）。キーと操作ごとのオン・オフは設定で変更できる。

- ビルド：`./build.sh`（署名後に /Applications と Latest Builds へ配置。配置しないときは `NO_DEPLOY=1`）
- テスト：`./test.sh`（起動判定、103操作のキー・手順・AppleScriptのコンパイル・PNGの命名、4言語の文字列、KMマクロのトリガーとの照合）
- 文字列：`Localization/` の `own.py`（画面・ヘルプ）と `commands.tsv`（操作名）を編集し、`python3 Localization/own.py && python3 Localization/make_strings.py` で `Resources/*.lproj` を作り直す（共通の文言は SpreadsheetHelper から取る）
- アイコン：`Assets/draw-icon.swift`

設定のホットキー一覧は操作名・カテゴリ・現在のキーで検索できます。「スライド大の図形」は初期値⌃0で、スライドと同じ幅・高さの図形を左上に作成します。既存のキー変更は保持します。

## 移植の差分

- ホットキーはKeynote（`com.apple.Keynote`・`com.apple.iWork.Keynote`）が前面のときだけ登録し、ほかのアプリではキーを奪わない。
- メニュー項目が使えないとき（選択がないときなど）は、押したキーをそのままKeynoteへ渡す。⌘・⌃を含まないキー（⌥L、⇧1など）は、テキスト入力中は文字として渡す（テキストの操作を除く）。
- 1つのマクロに複数あったトリガーは、1操作1キーにした（最初のトリガーを初期値に）。値ごとにトリガーを分けていたマクロ（±1pt、90/110/50/200%、幅・高さいっぱい、不透明度）は値ごとの操作に分けた。ただし不透明度100%は ⇧0 と ⇧` の両方を残し、⇧` を「不透明度100%（もう1つのキー）」として別の行にした（1.2.0で一時的に0%にしたのを1.2.1で戻した）。素の Home／End は登録しない。
- 操作名がメニューと食い違っていたマクロ「26)【重ね順】背面へ」（実体は最背面へ）は、名前どおり［背面へ］にした。
- 「中央に十字線を引く」の線は白・2ptを指定できない（Keynoteの線に色・太さのプロパティが無い。元のマクロの指定も効いていなかった）ためテーマの線スタイルになる。
- 「配置したPDFに白バックを追加」は、すべてを選択してグループ化する代わりに、選択したオブジェクトと追加した図形の2つだけをグループ化する。
- 「プレビュー（アニメーション）」は画像検索のクリックをやめ、アニメーションインスペクタの［プレビュー］をAXで押す。
- PNG書き出しは書き出しダイアログボックスのキー操作をやめ、AppleScriptで一時フォルダーに全スライドを書き出して表示中のスライドだけを書類の隣へ移す。同名ファイルは上書きしない。
- 「スライドショーを再生」は［フルスクリーン表示］を選んでから、「ウインドウで再生」は［ウインドウ表示］を選んでから再生する（Keynote 15のメニュー構成）。
- 「37)【トランジション】なし（すべてのスライド）」（⌃⌥⌘0）は KeynoteSweeper の「すべてのトランジションを削除」と重なるため移植しない（1.0.1で削除）。「37)【トランジション】なし（Magic Move以外のすべてのスライド）」（⌃⌥0）は1.1.0でKeynoteSweeperの「マジックムーブ以外のトランジションを削除」に移し、Helperからはそのサービスを呼ぶ。
- 確認用のKeyboard Maestroのウインドウは画面上部の短い表示に置き換えた。

## 配布

旧名KeynoteHelper 1.2.2（build 7）のDeveloper ID署名・Apple公証済みDMGを[個人noteの記事](https://note.com/swwwitch/n/n7b7e549f7379)で公開しています。

⌃⌥⌘0：選択した1つのオブジェクトと同じ位置・幅・高さの白い長方形を追加し、最背面へ送ります。グループ化はしません。塗りつぶしはKeynoteのスタイルインスペクタで設定します（日本語・英語Keynote）。途中で失敗した場合はエラーを表示し、作成された図形はKeynoteの⌘Zで取り消せます。

## Keynote標準ショートカットとの比較（build 10）

設定のホットキー一覧を「操作／Keynote標準／KeynoteMaestro」の3列に変更。提供された日本語資料の全341項目を14カテゴリの順で収録し、同等の34操作は現在の割り当てと同じ行に表示します。KeynoteMaestroのみの操作も対応するカテゴリに配置し、原典にないトランジション・アニメーション・書き出し・KeynoteSweeperは追加カテゴリにまとめます。

「すべて／KeynoteMaestroの操作／Keynote標準の操作」、カテゴリ、検索で絞り込めます。検索は操作名・カテゴリ・標準キー・現在の割り当てに対応し、Command等の名前と⌘等の記号の両方を受け付けます。カテゴリの一括オン・オフは表示中のKeynoteMaestroの操作だけに適用します。保存キー・既存設定・実行手順は変更しません。

標準欄はいただいた日本語資料の参照表示です。マウス操作や利用状況ごとの重複行も省略せず、記載の文脈を保持します。システム設定等で変更されたキーや実際の競合は取得しません。設定UIとカテゴリは4言語、資料本文は日本語原文で表示します。標準キーのない追加操作には「標準キーの記載なし」と表示します。

原文は `Reference/KeynoteShortcuts-ja.txt`、対応表と取込処理は `Localization/import_native_shortcuts.py`。`python3 Localization/import_native_shortcuts.py` で `Resources/NativeShortcuts.json` を再生成できます。

## build 11：重複の整理

標準と同じ⌥⌘Pの再生割り当てをKeynoteMaestroから削除し、キーをKeynoteに渡します。別キーによる追加割り当ては保持します。内部の旧play IDと保存値は互換性のため残しますが、登録・実行・一覧・宣言には含めません（追加操作102件）。標準資料341件は原本を保持し、カラーウインドウ・オブジェクトリストの完全重複2組は一覧で各1行にまとめます。表示する標準操作は339件、同等操作33件を結合した比較一覧は408行です。

## build 12：同じ座標にオブジェクトの複製

⌥Dは「同じ座標にオブジェクトの複製」と表示し、Keynote標準の「オブジェクトを複製する」（⌘D）とは別行にします。複製後に⇧←・⇧↑を送り、右下への10ポイントのずれを戻します。既存duplicate IDとキー設定は保持します。原典との結合は32件、比較一覧は409行です。

## build 14：標準セットとスペシャルの分離

設定タブは「起動・常駐／標準ショートカット／スペシャル／設定共有／情報」。標準資料339行と、標準欄を持たない追加70操作を分離。標準に対応する32操作は「カスタム」「カスタム 2」で別々のキー・オンオフを保存し、「デフォルト」は標準操作の追加キーを一切登録せずKeynote本来のキーを使用。残りの標準資料は参照のみです。メイン画面にも標準セット選択とスペシャルの独立スイッチ、各タブへのボタンを設置。

更新時は旧設定の標準32操作をカスタムへ移行し、カスタムを選択して既存動作を保持します。スペシャルのキーとオンオフは旧保存値を保持。新規利用時はデフォルトとスペシャルON。各タブの検索・カテゴリ・キーのリセットは独立。2つのカスタムを切り替えてもスペシャルは変わりません。セットデータ（shortcutProfilesV1）は共通設定共有の対象に追加しています。

## build 15：標準キーのカスタム割り当て

「参照のみ」だった255項目のキー操作をカスタム／カスタム 2で編集可能に拡張。方向と数字別に展開した305のキー欄を追加（既存32操作とは別）。割り当てたキーは元の標準キーを前面のKeynoteへ送信し、登録を一時解除することで再帰を防止します。選択・表示モードなどは元の標準操作と同じ条件が必要です。52項目のマウス操作・個別スタイル指定はキー単独の実行対象外として理由を表示。新しい割り当ては初期値未設定で、解除すると標準動作へ戻ります。旧セットデータの互換読み込みに対応。メイン画面の一括スイッチを削除し、旧一括OFFの場合は初回のみデフォルト＋スペシャルOFFに引き継ぎます。
