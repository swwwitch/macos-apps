# TextLens Help
## Basic use
Choose Recognize Text in Area and drag a screen area. The default shortcut is Command-Shift-1. Escape cancels area selection. Drop an image file into the main window to recognize it without changing its name, contents or Finder comment. Only the first file is processed if several are dropped. Supported images are those ImageIO can read, including PNG and JPEG.
## Results and formatting
Apple Vision recognizes Japanese and English locally. The result replaces the clipboard and remains in the main window until quitting. Copy again with Copy. Clipboard replacement cannot be undone. Choose Japanese spacing and full-width parentheses in formatting settings; line breaks are preserved. Recognition can make mistakes: check important text against the image. Results and recent activity are not saved.
## Settings and shortcuts
Command-comma opens settings; Command-W closes the current window. Settings cover startup, processing, excluded apps, settings sharing and information. Change, disable or restore the recognition shortcut. Registration failures appear beside the shortcut field; not every other-app conflict can be detected. While an excluded app is frontmost, the global shortcut is unregistered and the target is checked again before recognition. Use Open App in Shortcuts to launch TextLens when it is not running. Login launch and notifications default to off. Manual launch and reopening show the main window; login launch stays quiet. Hide from Dock defaults to off. While main or settings windows are open, including minimized windows, the app remains in Dock and App Switcher. Only formatting and result display preferences are shared or synced.
## Permissions and troubleshooting
Area selection requires Screen Recording permission. Request it explicitly in settings, or open system settings and allow TextLens. Permission status refreshes when settings appear and when the app becomes active. Recognizing an image file needs no screen permission. Accessibility and Finder Automation permissions are not required. Try a clearer, larger image if no text is found. Errors and results remain available in Recent Activity even when notifications are off or blocked. macOS controls notification appearance. Duplicate recognition is blocked. Wait for recognition to finish before quitting; Escape cancels screen area selection.
## Residency, quitting and migration
With Keep Running enabled, closing the main window leaves TextLens waiting for its shortcut. It does not watch folders or rename files. Reopen from the menu bar, Finder or Command-0. Command-Q quits. With Keep Running off, closing the main window quits. First launch copies only formatting and result display choices from the retired ShotSorter without modifying the old preferences. Permissions, hotkeys and login launch are not imported. OCR sends no images or text to external servers. Update delivery shows unavailable when not configured. To remove the app, quit and move TextLens.app to Trash. See the bundled README and Information tab for support.
