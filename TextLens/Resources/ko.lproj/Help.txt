# TextLens 도움말
## 기본 사용
영역을 선택해 문자 인식을 누르고 화면 영역을 드래그합니다. 기본 단축키는⌘⇧1이며 Esc로 선택을 취소합니다. PNG, JPEG 등 ImageIO가 지원하는 이미지를 창에 놓아 인식할 수도 있습니다. 여러 파일은 첫 파일만 처리합니다. 원본 이름, 내용, Finder 메모는 바꾸지 않습니다.
## 결과 및 서식
VisionKit(Live Text) 공개 API로 일본어와 영어를 로컬에서 인식합니다. 미지원 하드웨어에서는 기존 Vision을 사용합니다. 일본어 세로쓰기 두 열의 오른쪽에서 왼쪽 순서를 확인했으며 루비와 복잡한 레이아웃은 미확인입니다. 결과는 클립보드를 바꾸고 메인 창에 표시합니다. 복사 버튼으로 다시 복사할 수 있습니다. 클립보드 교체는 실행 취소할 수 없습니다. 일본어 사이 공백 제거와 전각 괄호 변환을 선택할 수 있으며 줄바꿈은 유지합니다. 인식 오류가 있을 수 있으므로 원본과 확인하세요. 결과와 활동 기록은 종료 시 지워집니다.
## 설정과 단축키
⌘,로 설정을 열고 ⌘W로 현재 창을 닫습니다. 단축키 변경, 비활성화, 기본값 복원을 지원하며 등록 실패는 입력란 옆에 표시합니다. 모든 앱의 충돌을 감지하지는 못합니다. 제외 앱이 앞에 있으면 전역 단축키를 해제하며 실행 직전에도 확인합니다. 앱이 꺼져 있을 때는 단축어의 앱 열기로 실행할 수 있습니다. 로그인 실행과 알림의 초기값은 꺼짐입니다. 수동 실행과 다시 열기는 창을 표시하며 로그인 실행은 조용히 시작합니다. Dock 숨김의 초기값은 꺼짐이며 메인 또는 설정 창이 열려 있거나 최소화된 동안은 Dock과 앱 전환기에 표시합니다. 서식과 결과 표시만 공유하거나 동기화합니다.
## 권한과 문제 해결
영역 선택은 화면 기록 권한이 필요합니다. 설정에서 직접 요청하거나 시스템 설정에서 TextLens를 허용하세요. 설정 표시 및 앱 복귀 때 상태를 갱신합니다. 이미지 파일 인식에는 화면 기록, 손쉬운 사용, Finder 자동화 권한이 필요 없습니다. 텍스트가 없으면 더 선명한 이미지로 시도하세요. 알림이 차단되거나 꺼져 있어도 앱의 결과와 최근 활동에서 확인할 수 있습니다. 알림 모양은 macOS에서 관리합니다. 중복 실행은 차단하며 처리가 끝난 뒤 종료하세요. Esc로 영역 선택을 취소할 수 있습니다.
## 상주, 종료 및 이전
상주가 켜져 있으면 창을 닫은 뒤에도 단축키를 기다립니다. 폴더 감시나 이름 변경은 하지 않습니다. 메뉴 막대, Finder 또는⌘0으로 다시 표시합니다. ⌘Q로 종료합니다. 상주를 끄면 메인 창을 닫을 때 종료합니다. 처음에는 이전 ShotSorter의 서식과 결과 표시만 복사하며 이전 설정은 변경하지 않습니다. 권한, 단축키, 로그인 설정은 이전하지 않습니다. 이미지나 텍스트를 외부 서버로 보내지 않습니다. 업데이트가 미설정이면 사용할 수 없다고 표시합니다. 종료 후 TextLens.app을 휴지통으로 옮겨 제거하세요. 지원은 README와 정보 탭을 참조하세요.
