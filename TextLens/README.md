# TextLens

画面の範囲や画像から日本語・英語を読み取り、整形してコピーするmacOSアプリ。macOS 13以降、現在の検証ビルドはApple Silicon用。

- 範囲選択：⌘⇧1（変更・無効化可能）。Escで取消。画面収録の許可が必要。
- 画像をドロップ：最初の1件を認識。原本の名前・内容・コメントは変更しない。
- 日本語間の空白除去、全角括弧、結果コピーと一時表示。
- 設定⌘,、閉じる⌘W、メインウインドウ⌘0、終了⌘Q。同梱ヘルプを参照。
- VisionKit（Live Text公開API）でローカル処理。非対応ハードウェアでは従来Visionへフォールバック。認識結果・履歴は保存しない。コピーはクリップボードを置換する。
- ShotSorterの廃止を維持し、保全ソースから文字認識を独立。初回は整形・結果表示設定のみ読み取り移行し、元設定を変更しない。
- ホットキー・権限・ログイン起動は別管理。更新配信・専用note記事は未設定。

## 開発

`NO_DEPLOY=1 zsh build.sh`、`zsh test.sh`。共通部品は親のSharedからコンパイル。開発Macから配布先へ配置しない。
