App Store 版 FolderHopper 移动、复制所选文件，或创建符号链接。
## 使用方法
1. 使用“选择文件…”选择项目。
2. 选择移动、复制或符号链接模式。
3. 使用“选择文件夹…”选择目标后执行。收藏位置用 Return 或双击执行。
- 如需授权，请选择显示的源父文件夹和目标文件夹。取消不会执行操作。
- 移动会从原位置移除文件。同名冲突按设置添加编号保留两者或停止，不覆盖文件。
- 不读取 Finder 或 Path Finder 的选择、窗口或历史。不需要自动化权限。
## 设置和权限
- ⌘, 打开设置。可设置登录启动、启动时隐藏窗口、菜单栏图标、路径显示及同名处理。
- 在“设置共享”标签页中，可将设置导出或导入为 FolderHopper-Settings.plist，并通过 iCloud 云盘、Dropbox 等文件夹与其他 Mac 同步。共享的内容：路径显示、目标位置的显示项目、同名文件的处理、处理后关闭、最近使用的窗口数量，以及复制到“应用程序”的快捷键。登录时启动、启动时的显示、菜单栏图标、显示应用快捷键、收藏的文件夹和已隐藏的历史记录在每台 Mac 上分别设置。
- 所选文件夹权限通过书签保存。失去权限时重新选择。
- 无通知权限时也可在主窗口查看结果。
## 快捷键和退出
- ⌘0 重新打开主窗口，也可使用文件菜单。
- ⌘W 关闭当前窗口并保持运行。⌘Q 退出。
- Return 执行，⌥Return 复制，⌃Return 创建链接，⌘? 打开帮助。
## 故障排除
- 失败时检查结果和两个文件夹。已处理文件保留在目标位置。
- 不能移动到同一位置、源文件夹自身或其内部。
- 帮助菜单打开 note 文章。通过 App Store 更新。
