App Store용 FolderHopper는 선택한 파일을 이동, 복사하거나 심볼릭 링크를 만듭니다.
## 사용 방법
1. 파일 선택…으로 항목을 선택합니다.
2. 이동, 복사 또는 심볼릭 링크 모드를 선택합니다.
3. 폴더 선택…에서 대상을 선택하면 실행합니다. 즐겨찾기는 Return 또는 더블 클릭으로 실행합니다.
- 권한을 요청하면 표시된 원본 부모 폴더와 대상 폴더를 선택하세요. 취소하면 실행하지 않습니다.
- 이동하면 원래 위치에서 파일이 제거됩니다. 같은 이름은 설정에 따라 번호를 추가하거나 중단하며 파일을 덮어쓰지 않습니다.
- Finder나 Path Finder의 선택, 창, 기록을 읽지 않습니다. 자동화 권한은 필요 없습니다.
## 설정과 권한
- ⌘,로 설정을 엽니다. 로그인 시작, 시작 시 창 숨기기, 메뉴 막대, 경로 표시 및 충돌 처리를 설정합니다.
- 선택한 폴더의 권한은 북마크로 저장합니다. 권한이 사라지면 다시 선택하세요.
- 알림 권한 없이도 주 창에서 결과를 확인할 수 있습니다.
## 키와 종료
- ⌘0 또는 파일 메뉴로 주 창을 다시 엽니다.
- ⌘W는 현재 창을 닫고 상주를 유지합니다. ⌘Q로 종료합니다.
- Return 실행, ⌥Return 복사, ⌃Return 링크 생성, ⌘? 도움말입니다.
## 문제 해결
- 실패하면 결과와 두 폴더를 확인하세요. 완료한 파일은 대상에 남습니다.
- 같은 위치, 원본 폴더 자체나 하위 폴더로 이동할 수 없습니다.
- 도움말 메뉴에서 note 기사를 엽니다. App Store에서 업데이트합니다.
