Moves or duplicates the files and folders selected in the Finder or Path Finder to another folder, or creates symbolic links to them.

## Basic Use
1. Select files or folders in the Finder or Path Finder.
2. Bring up FolderHopper (⌃⌥⌘F by default). The number of selected items appears at the top.
3. Select a destination folder in the list and press Return, or double-click it. A single click only selects.

- To copy, turn on **Duplicate**; to create links, turn on **Create symbolic links** before running. You can also press ⌥Return to duplicate or ⌃Return to create symbolic links.
- Hold ⌘ while running to bring the destination to the front with the processed items selected when it finishes.
- Places that cannot be used as a destination, such as the folder containing the selected files, are dimmed with the reason shown.
- Right-click an item in the Finder or Path Finder and choose FolderHopper from **Open With** to use it as Received files.

## Destinations
- **Finder Windows**: The locations of windows open in the Finder or Path Finder.
- **Choose / Desktop**: On the left, Choose Folder…: click the folder icon and select a destination folder to run the current mode (move, duplicate, or create links) right away. ⌘-click to bring the destination to the front with the processed items selected when it finishes. The next time, the panel opens at the last folder you chose. Click Desktop on the right (or press Return) to move (duplicate, or link) the selection straight to the Desktop.
- **Favorites**: Applications and two folders of your choice. Use Choose… or Change… to set a folder, and right-click and choose Remove from Favorites to clear it. Double-click or press Return to run. When sending to Applications, apps in Setapp (/Applications/Setapp) are linked with a symbolic link instead of being moved or duplicated. When you send items to Applications from the window, FolderHopper asks whether to Move, Duplicate or Create links (the operation chosen with the checkboxes or keys is the default button). Move is unavailable when any item is on a different volume.
- **Recent Folders**: The recent-folder history saved by the Finder and Path Finder.

## Settings
Open **Settings…** from the app menu (⌘,) or with the **Settings…** button in the window.

### Startup & Background Tab
- **Open at login** (the status is shown below it; Open Login Items appears when System Settings needs approval)
- Opening or reopening the app manually shows the main window. Automatic login launch does not show it. Explicitly opening files takes precedence.
- **Hide from Dock and App Switcher**: when on, the app appears in the Dock and ⌘Tab while main/settings windows exist, including minimized windows, and hides after all such windows close. Show it from the menu bar icon, the app shortcut, or by opening the app again in Finder.
- **Show in menu bar**
- **Show app shortcut**: turn on Enable hotkey, click Change… and press the keys to assign (include ⌘ or ⌃; Esc cancels, Reset to Default returns to ⌃⌥⌘F). A registration failure is shown under the field.

### Display Tab
- **Shorten Dropbox paths**
- **Show the “Choose / Desktop” section**
- **Show Favorites section**
- **With multiple displays, show the window on**: Choose Last position, Screen with the pointer or Screen with the selected items’ window. With the last two, the window moves to the center of that screen when it is on another screen. If the selected items’ window can’t be found (for example, items selected on the desktop), the window appears on the screen with the pointer.

### File Operations Tab
- **When a file with the same name exists**: choose Keep both by adding a number or Stop without overwriting. When creating symbolic links in the Applications folder, an existing symbolic link with the same name is replaced without adding a number (apps and files with the same name are never replaced).
- You can also set **Close window after completion (keep running)**. The Duplicate Selection to Applications hotkey is set in the same kind of field with Change… (default ⌃⌥⌘⇧A).

### History Tab
- Set **Number of recent folders** (0 = all).
- Tidy the list with **Clear Recent Folders** and **Restore**. Clearing affects only this app’s list; the Finder and Path Finder history is not changed.

### Sharing Tab
- **Export & Import**: “Export…” saves the settings to FolderHopper-Settings.plist, and “Import…” replaces the settings with the file’s after asking.
- **Settings Sync**: “Set Sync Folder…” shares the settings with your other Macs through a folder you choose (iCloud Drive, Dropbox, etc.). If several Macs change settings, the most recent save wins.
- Shared: path display, which destinations are shown, same-name file handling, closing after an operation, the number of recent windows and the copy-to-Applications shortcut. Login launch, startup display, the menu bar icon, the show app shortcut, favorite folders, hidden history items and the screen for the window are set per Mac.

## Keyboard Shortcuts
Show the app with ⌃⌥⌘F by default. Available while the app is running and Finder/Path Finder is in front; in other apps the keys pass through to that app.

- **Return**: Execute
- **⌥Return**: Duplicate
- **⌃Return**: Create symbolic links
- **⌃⌥⌘⇧A** (default): Duplicates the items selected in Finder/Path Finder to the Applications folder without showing the window (never moves them; while running, with Finder/Path Finder in front; creates links when **Create symbolic links** is on; turn it on or off and change the key in the File Operations tab of Settings)
- **Add ⌘**: Bring the destination to the front with the processed items selected
- **Tab**: Switch between Finder Windows and Recent Folders
- **←→**: Select a favorite
- **Esc**: Close window
- **⌘0**: Open Main Window (also after closing it)
- **⌘W**: Close window (or Settings)
- **⌘,**: Settings
- **⌘?**: Help
- **⌘Q**: Quit

## Running in the Background and Quitting
- Closing the window does not quit the app. Show it again with the shortcut, the Dock icon, or Open With.
- When **Show in menu bar** is on, the menu bar icon offers **Open Main Window**, **Settings…**, **Help** (**FolderHopper Help** / **Open the note Article**), **Menu Bar Settings…**, and **Quit FolderHopper**.
- To quit, press ⌘Q or choose **Quit FolderHopper** from the app menu. You cannot quit while files are being moved or duplicated.

## Permissions
- The first time, the app needs Automation permission to control the Finder and Path Finder. Check it in System Settings → Privacy & Security → Automation.
- To see completion notifications, allow notifications. Accessibility permission is not required.
- In the App Store version, you allow access to folders the first time you use them.

## Troubleshooting
- If the selection or list is out of date, select the items again in the Finder or Path Finder and return to FolderHopper. The app reloads when you return to it.
- If “Permission to control … was denied” appears, allow FolderHopper to control the Finder or Path Finder under Automation.
- Items cannot be moved to the same location, or into the folder itself or a folder inside it. Existing items are never overwritten or merged.
- If an operation stops partway, check the number of processed items and the error. Processed items stay in the destination.
- Virtual folders such as search results, background tabs, and inactive Path Finder panes do not appear in the destination list.
- Choose **Open the note Article** from the Help menu to open the guide article on note in your browser.

## Uninstalling
1. Turn off **Open at login**.
2. Quit the app.
3. Move the app to the Trash.


Notifications
Use Notifications in Settings to enable notifications and check permission. Enabling the option or clicking Allow Notifications requests permission. Open Notification Settings lets you choose placement and style in macOS. If denied, change permission in System Settings. Launching or completing an operation never requests permission. If Focus or other settings hide notifications, check results and status in the app.


## Dock visibility and application menus

Even with Hide from Dock and App Switcher on, a main or settings window keeps the app in the Dock and ⌘Tab so its application menus remain available. Minimized windows stay listed. Close all such windows to hide the app; palettes alone do not show it. Your saved setting is preserved.

Selecting the app in the ⌘Tab application switcher shows its main window and restores it if minimized. Automatic login launch stays quiet.
