Finder/Path Finder에서 선택한 파일과 폴더를 다른 폴더로 이동하거나 복제하고, 심볼릭 링크를 만듭니다.

## 기본 사용법
1. Finder/Path Finder에서 파일이나 폴더를 선택합니다.
2. FolderHopper를 불러옵니다(기본값 ⌃⌥⌘F). 위쪽에 선택한 항목 수가 표시됩니다.
3. 목록에서 대상 폴더를 선택하고 Return을 누르거나 이중 클릭하여 실행합니다. 한 번 클릭하면 선택만 합니다.

- 복제하려면 **복제**를, 링크를 만들려면 **심볼릭 링크 생성**을 켠 다음 실행합니다. ⌥Return으로 복제하고 ⌃Return으로 심볼릭 링크를 만들 수도 있습니다.
- ⌘를 누른 채 실행하면 완료 후 대상 폴더를 앞으로 가져오고 처리한 항목을 선택합니다.
- 선택한 파일이 있는 폴더처럼 대상으로 사용할 수 없는 위치는 흐리게 표시되며 이유가 나타납니다.
- Finder/Path Finder에서 항목을 오른쪽 클릭하고 **다음으로 열기**에서 FolderHopper를 선택하면 그 항목을 ‘전달받은 파일’로 처리합니다.

## 대상 폴더
- **Finder 윈도우**: Finder/Path Finder에서 열려 있는 윈도우의 위치입니다.
- **지정 · 데스크탑**: 왼쪽의 ‘폴더 선택…’에서 폴더 아이콘을 클릭하고 대상 폴더를 선택하면 현재 모드(이동, 복제, 링크 생성)로 바로 실행합니다. ⌘-클릭하면 완료 후 대상 폴더를 앞으로 가져오고 처리한 항목을 선택합니다. 다음에는 마지막으로 선택한 폴더에서 열립니다. 오른쪽의 ‘데스크탑’을 클릭하거나 Return을 누르면 선택 항목을 바로 데스크탑으로 이동(복제, 링크 생성)합니다.
- **즐겨찾기**: ‘응용 프로그램’과 직접 선택한 폴더 두 개입니다. ‘선택…’ 또는 ‘변경…’으로 폴더를 지정하고, 오른쪽 클릭 후 ‘즐겨찾기에서 제거’로 해제합니다. 이중 클릭하거나 Return을 눌러 실행합니다. ‘응용 프로그램’으로 보낼 때 Setapp(/Applications/Setapp)의 앱은 이동하거나 복제하지 않고 심볼릭 링크를 생성합니다. 윈도우에서 ‘응용 프로그램’으로 보낼 때는 ‘이동’, ‘복제’, ‘링크 생성’ 중 무엇을 할지 확인합니다(체크박스나 키로 선택한 작업이 기본 버튼). 다른 볼륨에 있는 항목이 포함되어 있으면 ‘이동’을 선택할 수 없습니다.
- **최근 폴더**: Finder/Path Finder에 저장된 최근 사용한 폴더 기록입니다.

## 설정
앱 메뉴의 **설정…**(⌘,) 또는 윈도우의 **설정…** 버튼으로 엽니다.

### ‘시작 및 백그라운드’ 탭
- **로그인 시 실행**(아래에 상태를 표시하며, 시스템 설정에서 허용이 필요하면 ‘로그인 항목 열기’를 표시)
- **시작 시 메인 윈도우 표시 안 함**
- **로그인 시 백그라운드에서 실행**
- **메뉴 막대에 표시**
- **앱 표시 단축키**: ‘단축키 사용’을 켜고 ‘변경…’을 누른 다음 지정할 키를 누릅니다(⌘ 또는 ⌃ 포함, Esc로 취소, ‘기본값으로 되돌리기’로 ⌃⌥⌘F). 등록하지 못하면 필드 아래에 표시합니다.

### ‘표시’ 탭
- **Dropbox 경로 간략히 표시**
- **‘지정 · 데스크탑’ 섹션 표시**
- **즐겨찾기 섹션 표시**
- **디스플레이가 여러 개일 때 윈도우를 표시할 화면**: ‘마지막 위치’, ‘포인터가 있는 화면’, ‘선택 항목의 윈도우가 있는 화면’ 중에서 선택합니다. 뒤의 두 가지는 윈도우가 다른 화면에 있으면 그 화면의 가운데로 옮깁니다. 선택 항목의 윈도우를 찾을 수 없을 때(데스크탑에서 선택한 경우 등)는 포인터가 있는 화면에 표시합니다.

### ‘파일 작업’ 탭
- **대상에 같은 이름의 파일이 있는 경우**: ‘번호를 붙여 둘 다 유지’ 또는 ‘덮어쓰지 않고 중단’을 선택합니다. 단, ‘응용 프로그램’ 폴더에 심볼릭 링크를 만들 때 같은 이름의 심볼릭 링크가 있으면 번호를 붙이지 않고 바꿉니다(같은 이름의 앱이나 파일은 바꾸지 않습니다).
- **작업 완료 후 윈도우 닫기(앱은 계속 실행)**도 설정할 수 있습니다. ‘선택 항목을 응용 프로그램으로 복제’ 단축키도 같은 필드에서 ‘변경…’으로 설정합니다(기본값 ⌃⌥⌘⇧A).

### ‘기록’ 탭
- **최근 폴더 수**(0은 모두)를 설정합니다.
- **최근 폴더 지우기**, **다시 표시**로 목록을 정리합니다. 지우기는 이 앱의 목록에만 적용되며 Finder/Path Finder의 기록은 바뀌지 않습니다.

### ‘설정 공유’ 탭
- **내보내기 및 가져오기**: ‘내보내기…’로 설정을 FolderHopper-Settings.plist에 저장하고, ‘가져오기…’는 확인 후 파일의 설정으로 바꿉니다.
- **설정 동기화**: ‘동기화 폴더 설정…’으로 선택한 폴더(iCloud Drive, Dropbox 등)로 다른 Mac과 공유합니다. 여러 Mac에서 변경하면 나중에 저장한 내용이 우선합니다.
- 공유하는 항목: 경로 표시, 이동 위치 표시 항목, 같은 이름 파일 처리, 처리 후 닫기, 최근 윈도우 수, ‘응용 프로그램’으로 복제하는 단축키. 로그인 시 실행, 시작 시 표시, 메뉴 막대 아이콘, 앱 표시 단축키, 즐겨찾는 폴더, 숨긴 기록, 윈도우를 표시할 화면은 Mac마다 설정합니다.

## 키보드 단축키
앱 불러오기의 기본값은 ⌃⌥⌘F입니다. 앱이 실행 중이고 Finder/Path Finder가 맨 앞에 있을 때 사용할 수 있습니다. 다른 앱에서는 키가 그 앱으로 전달됩니다.

- **Return**: 실행
- **⌥Return**: 복제
- **⌃Return**: 심볼릭 링크 생성
- **⌃⌥⌘⇧A**(기본값): 윈도우를 표시하지 않고 Finder/Path Finder에서 선택한 항목을 ‘응용 프로그램’ 폴더에 복제합니다(이동하지 않음, 앱이 실행 중이고 Finder/Path Finder가 맨 앞에 있을 때 사용 가능, **심볼릭 링크 생성**이 켜져 있으면 링크 생성, 설정의 ‘파일 작업’에서 켜거나 끄고 키 변경)
- **⌘ 추가**: 완료 후 대상 폴더를 앞으로 가져오고 처리한 항목 선택
- **Tab**: ‘Finder 윈도우’와 ‘최근 폴더’ 전환
- **←→**: 즐겨찾기 선택
- **Esc**: 윈도우 닫기
- **⌘0**: 메인 윈도우 열기(닫은 후에도 다시 표시)
- **⌘W**: 윈도우(또는 설정) 닫기
- **⌘,**: 설정
- **⌘?**: 도움말
- **⌘Q**: 종료

## 백그라운드 실행 및 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. 단축키, Dock 아이콘, ‘다음으로 열기’로 다시 표시할 수 있습니다.
- **메뉴 막대에 표시**를 켜면 메뉴 막대 아이콘에서 **메인 윈도우 열기**, **설정…**, **도움말**(**FolderHopper 도움말** / **note 글 열기**), **메뉴 막대 설정…**, **FolderHopper 종료**를 선택할 수 있습니다.
- 종료하려면 ⌘Q를 누르거나 앱 메뉴에서 **FolderHopper 종료**를 선택합니다. 이동이나 복제를 처리하는 동안에는 종료할 수 없습니다.

## 권한
- 처음 사용할 때 Finder/Path Finder를 제어하기 위한 자동화 권한이 필요합니다. 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 확인할 수 있습니다.
- 완료 알림을 표시하려면 알림을 허용하십시오. 손쉬운 사용 권한은 필요하지 않습니다.
- App Store 버전에서는 폴더를 처음 사용할 때 폴더 접근을 허용합니다.

## 문제 해결
- 선택 항목이나 목록이 최신이 아니면 Finder/Path Finder에서 다시 선택한 후 FolderHopper로 돌아오십시오. 앱으로 돌아오면 다시 읽습니다.
- ‘… 제어 권한이 없습니다’가 표시되면 자동화에서 FolderHopper가 Finder/Path Finder를 제어하도록 허용하십시오.
- 같은 위치로 이동하거나 폴더 자체 또는 그 내부로 이동할 수는 없습니다. 기존 항목을 덮어쓰거나 병합하지 않습니다.
- 작업이 도중에 실패하면 처리된 항목 수와 오류를 확인하십시오. 처리된 항목은 대상 폴더에 남습니다.
- 검색 결과 같은 가상 폴더, 뒤쪽 탭, Path Finder의 비활성 패널은 대상 폴더 목록에 표시되지 않습니다.
- 도움말 메뉴에서 **note 글 열기**를 선택하면 note의 사용 안내 글을 브라우저에서 열 수 있습니다.

## 삭제
1. **로그인 시 실행**을 끕니다.
2. 앱을 종료합니다.
3. 앱을 휴지통으로 옮깁니다.
