# FolderHopper

Finder／Path Finderで選択したファイルを、一覧で選んだフォルダへ移動・複製・シンボリックリンク作成するmacOSアプリです。Apple Silicon用です。旧称はFolder Moverで、Bundle IDと実行ファイル名は互換性のため`jp.local.FolderMover`／`FolderMover`のままです。

## 使い方

1. `FolderHopper.app`をアプリケーションフォルダへ置きます。
2. FinderまたはPath Finderで、移動するファイル・フォルダを選択します。
3. FolderHopperを起動します。初回はFinder／Path Finderへのオートメーション許可が必要になる場合があります。
4. 「現在開いているウインドウ」または区切り線の下の「最近使ったウインドウ」から移動先をクリックします。上下キー＋Returnでも移動できます。

両方のファイル管理アプリで選択がある場合など、選択元を判定できないときは上部の「選択元」で指定します。ファイル選択を変更した場合は「更新」を押すか、アプリをもう一度起動してください。選択中の項目数・名前を上部で確認できます。

## 履歴の取得元

独自の移動先履歴は作成しません。このMacに保存されている以下の履歴を読み込みます。

- Finder: `com.apple.finder`の`FXRecentFolders`
- Path Finder（通常版／Setapp版）: `PFFileHistoryManager`のフォルダ履歴

各項目のブックマークを解決し、実在するフォルダだけを表示します。重複する場所は一度だけ表示し、現在開いている場所を優先します。アプリケーション等のパッケージは移動先から除きます。各取得元の並び順を維持し、Finder、Path Finderの順に表示します。両者を横断した時刻順ではありません。

macOS上のすべてのアプリの操作を網羅する共通履歴ではありません。各アプリの保存タイミングにより、直近の操作がすぐには反映されない場合があります。履歴の保存形式は非公開のため、OS／Path Finderの更新で追従が必要になる可能性があります。履歴は読み取り専用で参照し、書き換えません。

現在のウインドウ一覧は各ウインドウの表示先を取得します。検索結果等の仮想フォルダ、背面タブ、Path Finderの非アクティブペインは対象外です。

## 移動の動作

同名項目、同じ場所への移動、フォルダ自身やその内部への移動、親子を含む選択は事前に検査します。同名項目を自動で上書き・統合しません。複数項目の途中で失敗した場合は移動済み件数を表示し、処理済みの項目は移動先に残ります。通常のファイル移動なので、Dropbox等の同期フォルダでは同期先にも反映されます。

## ビルド

Command Line ToolsとSwiftを使い、`./build.sh`を実行します。生成物は`FolderHopper.app`で、`../FolderHopper.app`と`Latest Builds/FolderHopper.app`へ配置します（ZIPは作りません）。ローカルのアドホック署名を使用します。Developer ID署名・公証は行っていません。

`APP_STORE_BUILD=1 ./build.sh`ではSparkleを含めず、`APP_STORE`条件で`Source/FolderAccess.swift`を含めてコンパイルします。

移動処理のテストは`Source/MoveEngine.swift`と`Source/MoveTests.swift`を一緒に`swiftc`でコンパイルして実行できます。テストは一時ディレクトリだけを操作します。

## 0.1.1の修正

選択中のファイルがあるフォルダはディム表示になり、クリック・Returnのどちらでも移動先として選べません。移動後は選択元の件数を更新し、選択が空になった場合は移動先一覧を無効化します。別のファイルを選択した場合は「更新」を押してください。

## 0.1.2の修正

アプリ起動時などにmacOSの「書類を開く」イベントでファイルが渡された場合、そのファイルを移動対象として受け取ります。選択元には「受け取ったファイル」と表示します。内容をIllustrator書類として解析することはなく、通常のファイル移動として扱います。ファイルの既定アプリや関連付けは変更しません。

## 0.1.3：常駐して「このアプリケーションで開く」から使用

Folder Moverを一度起動しておき、Finder／Path Finderで対象ファイルを右クリックし、「このアプリケーションで開く」からFolder Moverを選びます。受け取ったファイルを移動対象にして、ウインドウを前面に表示します。赤い閉じるボタンやEscでウインドウを閉じてもアプリは終了しません。終了するときは⌘Qを使います。（ログイン時の自動起動は0.1.21で環境設定に追加しました。）

macOSへの候補登録はAlternateランクを使用します。検証時、.aiのOpen With候補への登録と、既定アプリがAdobe Illustratorのままであることを確認しました。登録直後のメニューに反映されない場合は、一度メニューを閉じて開き直してください。

実装参考：[AppleのLSHandlerRank仕様](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundledocumenttypes/lshandlerrank)

## 0.1.4：Dropboxのパスを簡易表示

検索欄の下に「Dropboxのパスを簡易表示」チェックボックスを追加しました。オンの場合、一覧・ツールチップに表示するパスを `/Dropbox-shared/…` に短縮します。Dropbox-shared以外のパスは従来通り表示し、実際の移動先は変更しません。設定は保存され、次回起動時に復元されます。

## 0.1.21：操作と環境設定の追加

- Finderが選択なしのときに結果を返さないケースを処理し、`selectedItems`エラーを修正しました。
- 環境設定の「ログイン時に自動起動」でmacOSへの自動起動登録を切り替えます。OSが許可を要求した場合は設定内に案内します。
- 「同名の項目がある場合は別名で移動」は初期値オンです。`名前 2.ai`のように拡張子を保持して連番を付けます。オフの場合は同名衝突で中止します。
- 「最近使ったウインドウをクリア」は現在の履歴のパスをこのアプリ内で非表示にします。再起動後も保持されます。Finder／Path Finderの履歴は変更しません。「再表示」で戻せます。クリア後、新たに履歴に現れたパスは表示します。クリア済みの同じパスは再訪しても非表示のままです。

## 0.1.74（build 88）：選択なしのときの表示

## 0.1.75（build 89）：←→で「指定」にも移動
