# PodiumAssist — セミナー・キャプチャ準備

セミナー講師やスクリーンキャプチャ向けの、メニューバー常駐Macアプリです。`PodiumAssist.app` を開き、メニューバーの「画面＋時計」アイコンから操作します。Dockには表示しません。

## 操作

メインウインドウは「プリセット」（大きいボタンで一括適用）「基本設定」「その他の設定」の3タブ。「基本設定」には時計・日付・曜日・外観とタイマー、「その他の設定」にはそれ以外（ディスプレイ・見やすさ・ズーム機能・集中を妨げるもの・プライバシー・Dockに分類）があります。

- 時計：macOSのメニューバー時計をデジタル／アナログに変更。
- 外観：Mac全体をライト／ダークに変更。
- Dockを隠す：通常の自動非表示をオン／オフ。
- Dockを完全非表示：アイコンサイズを1、出現遅延を3000000秒に設定。オフでこの機能をオンにする直前のサイズ・遅延へ復元。Dockプロセスは設定反映のため再起動します。自動非表示とは独立しており、両方をオンにして使えます。
- デスクトップ非表示：デスクトップ上のファイルアイコンを隠す／表示する。ファイル自体は削除しません。反映時にFinderを再起動します。
- 通知オフ／オン：おやすみモードを有効／解除。例外として許可されている通知は届く場合があります。
- PodiumAssistを終了：メニューバー常駐を終了。適用したシステム設定は残ります。メニューバーのアイコンを右クリック（Control＋クリック）したメニューからも終了できます。

## タイマー：メインウインドウ → 基本設定

「開始時間 ＋ 所要時間 ＝ 終了時間」で連動します。

- 開始時間を変更：所要時間を保ち、終了時間を更新。
- 所要時間を変更：開始時間を保ち、終了時間を更新。
- 終了時間を変更：開始時間を保ち、所要時間を更新。
- 所要時間は1〜10080分。日付も指定でき、日をまたぐ予約に対応。
- 「開始／予約」で実行。開始前は「開始まで」、開始後は残り時間をメニューバーに表示し、終了時は00:00で停止。
- 実行中に入力を編集した場合は「設定を反映して再開」で反映。
- 設定と実行中の終了時刻を保存。アプリの再起動後も復帰し、スリープ時間も経過時間に含めます。アプリ終了中はメニューバー表示は消えます。

## プリセット：設定 → プリセット

1. 名前を入力。
2. 変更したい項目にチェックを入れ、希望の値を選択。
3. 「新規保存」（保存済みのプリセットを編集中は「上書き保存」）。
4. メニューバーの「プリセットを適用」から実行。

チェックしない項目は変更しません。保存済みのプリセットを選ぶと編集・上書き保存・削除できます。アプリを再起動しても保存内容は残ります。

プリセットのタイマー項目は所要時間のみです。開始／予約は別操作なので、表示設定を切り替えるだけでタイマーが勝手に始まることはありません。

## 通知の連携

このMacの「ショートカット」に以下を作成済みです。名前を変更せずに使ってください。

- `Toki Notifications Off`：おやすみモードを、オフにするまでオン。
- `Toki Notifications On`：おやすみモードをオフ。

別のMacでも通知機能を使う場合は、この2本をショートカットで作成または同期する必要があります。「デバイス間で共有」が有効な場合、おやすみモードは他のAppleデバイスにも同期されます。

外観変更はSystem Eventsを使います。初回に許可を求められた場合は許可してください。アクセシビリティ権限は不要です。

## ビルドと検証

macOS 26.7.1（Apple Silicon）でビルド・実機確認。最低ビルド対象はmacOS 13ですが、他のOSでは未検証です。ローカル署名版で、配布用の公証はしていません。

```sh
bash build-app.sh
open ../PodiumAssist.app
```

SwiftUIとAppKitを使用。Xcodeでソースを編集する場合は `Package.swift` を開いてください。実機実行には権限説明を含む `.app` 形式を使います。

`Tests/LogicTests.swift` は、3時刻の連動・開始前・終了境界・1時間以上の表示・設定の直列化・プリセットの未選択値保持を検証します。

時計とDockの内部設定キーは、macOS更新で仕様が変わる可能性があります。

## 3.2.1 — 起動するアプリ

プリセットの「指定アプリを起動する」をチェックして保存すると、その保存時点の一覧をプリセットに記憶します。再保存時は現在の起動一覧に更新されます。プリセット適用時、終了リストにも含まれるアプリは起動を優先して終了対象から除外します。

検証: ビルド・署名、設定画面、旧プリセットの読込、新しい一覧の保存形式、存在しないアプリのエラー表示。

## 3.2.2 — プリセット別のアプリ一覧

## 3.2.34 — ネットワーク速度（build 57、2026-10-12）

- 「プリセット」タブのプリセット一覧の下に「ネットワーク」を追加（設定ではなく本番前の確認なので、プリセットには保存しない。一覧はスクロールし、ネットワーク欄は常に見える）。
- 接続中のネットワーク（IPv4 がリンクローカル以外）を、システム設定のサービス順にサービス名で並べ、［速度を測定］で1つずつ `networkQuality -I <BSD名> -c -M 10` を実行して下り・上りを表示する（`dl_throughput`／`ul_throughput` は bit/s、実測）。
- Wi-Fi は SSID を添える（CoreWLAN）。macOS 14 以降は位置情報サービスの許可が要るため、初回の測定時に許可を求める。許可が無ければサービス名だけ。
- fast.com は非公式 API（ページの JS からトークンを読む）で壊れやすいため、Apple 公式の networkQuality を採用した。
- 「プリセットに保存…」の行に操作結果のメッセージを並べ、ボタン上の空白を詰めた。
