A menu bar app that controls your Mac’s display settings and a timer, for seminars and screen recordings. It does not appear in the Dock.

## How to Use
The main window has five tabs: Presets, Basic, Display, Zoom, and Timer. Display contains appearance, display, and visibility settings. Basic contains the clock, date, weekday, distractions, privacy, and Dock settings. Zoom is divided into Keyboard Shortcuts and Options. Timer contains start time, duration, and end time. Scroll to see all settings.
- Auto Set uses the current screen’s logical height divided by 500 for minimum zoom and twice that value for maximum zoom (945 → 1.89 / 3.78). Zoom factors stay within 1–40.

### Display
- **Clock**: switch the menu bar clock between Digital and Analog. You can also show or hide the Date and Day of Week (for the digital clock).
- **Appearance**: switch the whole Mac between Light and Dark.
- **Pointer Size**: change the mouse pointer size at once, from 1 (default) to 4. Reset to Default returns it to 1. The value in System Settings › Accessibility › Display does not change, so the pointer returns to that size when you log in again.
- **External Display**: switch external displays between Mirror (the same screen as the main display) and Extend (a wider desktop). This is the same setting as “Use as” in System Settings › Displays. It is unavailable when no external display is connected.
- **Network**: at the bottom of the Presets tab (not saved in presets). Click Measure Speed to measure the download (↓) and upload (↑) speed of each connected network (Wi-Fi, Ethernet, and so on). It uses macOS’s own networkQuality (Apple’s servers) and takes about 10 seconds per network. Showing the Wi-Fi network name requires Location Services permission (otherwise only “Wi-Fi” is shown).
- **Resolution**: change the resolution of the main display (the one with the menu bar). The list shows the same “looks like” sizes as System Settings. If a preset’s resolution is not available on the connected display, a message appears. Turn on Show all resolutions to also list the low-resolution modes. Choose Reset to Display Default to return to the display’s own default. Presets can save it as “Display default”, which works on any display.
- **Reduce transparency**: reduce the transparency of windows and menus across the Mac. PodiumAssist operates System Settings for this, so System Settings opens briefly (requires the Accessibility permission).
- **Reduce motion**: reduce on-screen motion such as zoom and parallax effects. Like Reduce transparency, PodiumAssist operates System Settings for this (requires the Accessibility permission).
- **Zoom**: the same settings as System Settings › Accessibility › Zoom. Use keyboard shortcuts to zoom, Zoom style (Full Screen, Split Screen, Picture-in-Picture), and Maximum zoom (1 to 40) are changed by operating System Settings (requires the Accessibility permission). Maximum zoom moves the slider in Advanced…, so the pointer moves for a moment while it changes. Shortcut: Turn zoom on or off and Shortcut: Zoom in take effect at once.
- **Play feedback when volume is changed**: turn the sound played when you change the volume on or off. This is the same setting as in System Settings › Sound.

### Dock and Desktop
- **Dock: Auto-hide**: turn Dock auto-hide on or off.
- **Dock: Hide completely**: sets the Dock to size 1 with a 3,000,000-second appearance delay. Turning it off restores the settings from just before you turned it on.
- **Hide Desktop Icons**: hides the file icons on the desktop. Files are not deleted.

### Notifications and Presets
- **Browser History**: Delete… removes all browsing history of the default browser (asks first; cannot be undone). Bookmarks, cookies, and sign-ins are kept. Works with Firefox and Chrome-based browsers (Chrome, Edge, Brave, Vivaldi, Arc). An open browser quits and opens again afterwards. Safari is not supported; use its History menu.
- **Silence Notifications (Do Not Disturb)**: turn it on to turn on Do Not Disturb, and off to turn it off. Allowed notifications may still arrive. The checkbox shows the state PodiumAssist set last; changes made elsewhere, such as in Control Center, are not reflected.
- **Presets**: in the Presets tab of the main window, apply a saved preset’s settings all at once. The preset you applied last shows a checkmark. The checkmark disappears when you change a setting in the Basic, Display, or Zoom tab.

※ Changes to system settings remain after you quit PodiumAssist.

## Timer
1. In the Basic tab of the main window, set the Start Time, Duration, and End Time (Start Time + Duration = End Time).
2. Click Start / Schedule to run it.
3. Click Stop to stop it.

- Changing the start time or duration updates the end time; changing the end time updates the duration. The duration can be 1 to 10,080 minutes.
- Set the date and the time in separate fields. Set to Today changes the start date to today, and Set to Current Time changes the start time to now.
- Before the start, the menu bar shows “Starts in” and the time until the start; after the start, it shows the remaining time and stops at 00:00 when the timer ends.
- If you change the values while the timer is running, click Apply Settings and Restart.
- The timer resumes after the app restarts, and time keeps counting while the Mac is asleep.
- Use Start / Schedule and Stop to control the timer. Option-click Set to Today or Set to Current Time to apply both. Set to Next Hour sets the next hour after now (17:47 → 18:00, 18:00 → 19:00), including the next day at midnight.

## Presets
1. In the Basic, Display, and Zoom tabs, set up the Mac the way you want to save it.
2. Option-click Save to Preset (or just click it when there is no preset yet), and choose where to save it (a new preset or an existing one) and its name.
3. Tick the items to include and click Save. Unticked items stay unchanged when the preset is applied.

- When you save to an existing preset, the items it already had start ticked. Its name, position, and app lists stay the same.
- Click Save to Preset to overwrite the preset you applied (or saved) last without opening the sheet. The preset keeps its items; only the values change to the current state.
- Right-click a button in the Presets tab of the main window to rename, move up or down, edit the launch or quit apps, or delete it.
- Launch and quit apps are lists of each preset and do not affect other presets. Apps that are already running are not opened again, and apps are not force quit; if there are unsaved documents, save them when the app asks.
- The timer is independent of every preset. Saving or applying a preset does not change its enabled state, start/end times, duration, or running state. Timer values in older presets are ignored.
- Right-click a preset and choose Edit Launch Apps or Edit Quit Apps to configure its own lists. Assigned apps appear in small text and icons inside the preset button.

## Settings
Open Settings in a separate window with the Settings… button in the main window or with ⌘,.
- **Startup & Background**: Open at login, Hide from Dock and App Switcher, Show in menu bar
- **Sharing**: “Export…” writes the presets and app-switch hiding settings to PodiumAssist-Settings.plist; “Import…” on another Mac reads it (Add appends only presets you do not have, Replace uses the file’s settings). In Settings Sync, choose a folder in iCloud Drive, Dropbox or similar to keep your other Macs in sync automatically. Login launch, background, menu bar, the timer’s start time and duration, and the last applied preset stay per Mac

## Keyboard Shortcuts
- **⌘0**: Open Main Window
- **⌘,**: Settings
- **⌘W**: Close Window
- **⌘?**: PodiumAssist Help
- **⌘Q**: Quit PodiumAssist (the Quit PodiumAssist button in the main window)
- **⌘Z / ⇧⌘Z**: Undo / Redo (when editing text fields)

## Permissions and Notifications
### Changing the Appearance (System Events)
Changing the appearance uses System Events. Allow it when you are asked the first time. If you didn’t, allow PodiumAssist to control System Events in System Settings → Privacy & Security → Automation. PodiumAssist does not need Accessibility permission.

### Reduce Transparency (Accessibility)
Reduce transparency and Reduce motion are switched by operating the switches in System Settings automatically (macOS does not apply a direct change to the setting). Allow it in Settings… › Startup & Background › Accessibility in the main window. Other features do not need this permission.

### Switching Notifications (Shortcuts)
PodiumAssist uses these two shortcuts in the Shortcuts app on your Mac. Create them with exactly these names.
- **Toki Notifications Off**: turns Do Not Disturb on
- **Toki Notifications On**: turns Do Not Disturb off

※ You need these two shortcuts on every Mac where you use this feature.

## Opening and Quitting
- Closing the window does not quit the app; it stays in the menu bar. Click the menu bar icon to show the main window again. Right-click (or Control-click) the icon for a menu with Open Main Window, Settings…, Help, Menu Bar Settings…, and Quit PodiumAssist.
- Opening or reopening the app manually shows the main window. Automatic login launch does not show it. Explicitly opening files takes precedence.
- When Hide from Dock and App Switcher is on, the app appears in the Dock and ⌘Tab while main/settings windows exist, including minimized windows, and hides after all such windows close. Show it from the menu bar icon or by opening the app again in Finder.
- Turning off Show in menu bar does not quit the app. Open PodiumAssist again to show the main window.
- To quit, click the Quit PodiumAssist button in the main window (⌘Q), or choose Quit PodiumAssist from the icon’s right-click menu. The menu bar display disappears, but the system settings you changed stay as they are.

## Troubleshooting
- PodiumAssist may restart the Dock or Finder to apply Dock and desktop settings.
- If notifications don’t switch, make sure the Shortcuts app contains “Toki Notifications Off” and “Toki Notifications On” with exactly these names.
- If the appearance doesn’t change, check the Automation permission described above.
- The clock and Dock settings use internal macOS settings, so their behavior may change with macOS updates.

## Help and the note Article
- To open this help, choose PodiumAssist Help from the Help menu at the bottom of the main window (or press ⌘?).
- Choose Open the note Article in the same menu to read the article on note in your browser.

## Removing the App
1. If needed, restore your Dock settings and desktop icons.
2. Turn off Open at login.
3. Quit with the Quit PodiumAssist button in the main window, and then move PodiumAssist to the Trash.

- When switching a preset with app lists, review the launch and quit apps, select each checkbox for this run, then click Switch Preset. Selections are not saved. Cancel leaves all settings unchanged.

- In Settings > Preset Apps, choose a preset to review and edit its launch and quit app lists.

- macOS Defaults and Full Set are added once. macOS Defaults uses light appearance, visible Dock and desktop, standard pointer, display default resolution, and notifications on; it does not reset all OS settings. Full Set uses an analog clock without date/weekday, auto-hidden Dock, hidden desktop, 2x pointer, reduced transparency/motion, F1/F2 zoom, and notifications off. Neither changes the timer. Both start with empty app lists and can be edited or deleted.

Enable Hide other apps when switching apps in Basic Settings to hide other apps after the specified delay. Defaults: off and 0 seconds (immediate). Delay range: 0–86400 seconds. Switching again restarts the wait; turning off or editing the delay cancels it. Reopen hidden windows from the Dock. Excluded Apps in Settings protects both the switched-to app and apps that would be hidden. Save the enabled state and delay together with Save to Preset.

Select one zoom style using the radio buttons. Drag an edge or corner to resize the Settings window.

The Apps tab in Settings contains Excluded Apps and the apps to launch or quit for each preset.

Right-click or Control-click a preset button to open its editing menu. Save buttons in Basic, Display, and Zoom show the target preset name.


Open Accessibility Settings opens the pane and selects this app when existing permissions allow. If unavailable, it only opens Settings. Change the permission switch manually.


## Dock visibility and application menus

Even with Hide from Dock and App Switcher on, a main or settings window keeps the app in the Dock and ⌘Tab so its application menus remain available. Minimized windows stay listed. Close all such windows to hide the app; palettes alone do not show it. Your saved setting is preserved.

Selecting the app in the ⌘Tab application switcher shows its main window and restores it if minimized. Automatic login launch stays quiet.

- Basic includes automatic keyboard brightness and a 0–100% brightness slider for supported keyboards. Menu bar clock, date, and weekday controls are in Display.

- Select F3 for Shortcut: Zoom out. The Full Set preset uses F1 to toggle zoom, F2 to zoom in, and F3 to zoom out.
