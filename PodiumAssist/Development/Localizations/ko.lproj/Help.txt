세미나와 화면 녹화를 위해 Mac의 표시 설정과 타이머를 한곳에서 조작하는 메뉴 막대 앱입니다. Dock에는 표시되지 않습니다.

## 사용 방법
메인 윈도우: 프리셋 / 기본 / 디스플레이 / 확대/축소 / 타이머. 디스플레이 탭: 모양, 디스플레이, 가독성. 기본 탭: 시계, 날짜, 요일, 방해 요소, 개인정보 보호, Dock. 확대/축소 탭: 키보드 단축키, 옵션. 타이머 탭: 시작 시간, 소요 시간, 종료 시간.

### 표시
- **시계**: 메뉴 막대 시계를 디지털 또는 아날로그로 변경합니다. 날짜와 요일 표시도 전환할 수 있습니다(디지털 시계용).
- **모양**: Mac 전체를 라이트 또는 다크로 변경합니다.
- **포인터 크기**: 마우스 포인터 크기를 1(기본)~4로 바로 변경합니다. ‘기본값으로 복원’은 1로 되돌립니다. 시스템 설정의 ‘손쉬운 사용’ → ‘디스플레이’ 값은 바뀌지 않으므로, 다시 로그인하면 시스템 설정의 크기로 돌아갑니다.
- **외장 디스플레이**: 외장 디스플레이를 ‘미러링’(주 디스플레이와 같은 화면) 또는 ‘확장 디스플레이’(화면 확장)로 전환합니다. 시스템 설정 ‘디스플레이’의 ‘다음으로 사용’과 같은 설정입니다. 외장 디스플레이가 연결되어 있지 않으면 선택할 수 없습니다.
- **네트워크**: ‘프리셋’ 탭 아래에 있습니다(프리셋에는 저장하지 않음). ‘속도 측정’을 클릭하면 연결된 네트워크(Wi-Fi, 이더넷 등)마다 다운로드(↓)와 업로드(↑) 속도를 측정합니다. macOS 기본 networkQuality(Apple 서버)를 사용하며, 하나에 약 10초 걸립니다. Wi-Fi 네트워크 이름을 표시하려면 위치 서비스 권한이 필요합니다(허용하지 않으면 ‘Wi-Fi’만 표시).
- **해상도**: 주 디스플레이(메뉴 막대가 있는 디스플레이)의 해상도를 변경합니다. 목록은 시스템 설정과 같은 보기 크기입니다. 프리셋에 저장한 해상도를 연결된 디스플레이에서 사용할 수 없으면 메시지를 표시합니다. ‘모든 해상도 보기’를 켜면 저해상도 모드도 목록에 표시됩니다. ‘디스플레이 기본값으로 복원’을 선택하면 해당 디스플레이 본래의 해상도로 돌아갑니다. 프리셋에도 ‘디스플레이 기본값’으로 저장할 수 있으며, 어떤 디스플레이에서도 그 디스플레이의 기본값으로 돌아갑니다.
- **투명도 줄이기**: Mac 전체의 윈도우와 메뉴의 투명도를 줄입니다. 시스템 설정을 자동으로 조작하므로 실행 중에 시스템 설정이 잠시 열립니다(손쉬운 사용 권한 필요).
- **동작 줄이기**: 화면 전환 시의 확대·시차 효과 같은 움직임을 줄입니다. ‘투명도 줄이기’와 마찬가지로 시스템 설정을 자동으로 조작합니다(손쉬운 사용 권한 필요).
- **확대/축소**: 시스템 설정 ‘손쉬운 사용’ › ‘확대/축소’와 같은 설정입니다. ‘키보드 단축키를 사용하여 확대/축소’ 켜기/끄기, ‘확대/축소 스타일’(전체 화면·화면 분할·PIP), ‘최대 확대/축소’(1~40)는 시스템 설정을 자동으로 조작합니다(손쉬운 사용 권한 필요). 최대 확대/축소는 ‘고급…’의 슬라이더를 움직이므로 변경하는 동안 포인터가 잠시 움직입니다. ‘단축키: 확대/축소 켜기/끄기’와 ‘단축키: 확대’는 즉시 적용됩니다.
- **음량 변경 시 피드백 재생**: 음량을 바꿀 때 나는 소리를 켜거나 끕니다. 시스템 설정 ‘사운드’와 같은 설정입니다.

### Dock과 데스크탑
- **Dock: 자동 숨기기**: Dock 자동으로 가리기를 켜거나 끕니다.
- **Dock: 완전히 숨기기**: Dock 크기를 1, 표시 지연을 3,000,000초로 설정합니다. 끄면 켜기 직전의 설정으로 되돌립니다.
- **데스크탑 아이콘 가리기**: 데스크탑에 있는 파일 아이콘을 가립니다. 파일은 삭제하지 않습니다.

### 알림과 프리셋
- **브라우저 방문 기록**: ‘삭제…’를 클릭하면 기본 브라우저의 방문 기록을 모두 삭제합니다(확인 후 실행, 되돌릴 수 없음). 북마크, 쿠키, 로그인 상태는 유지됩니다. Firefox와 Chrome 계열(Chrome, Edge, Brave, Vivaldi, Arc)에 대응합니다. 브라우저가 실행 중이면 종료한 후 삭제가 끝나면 다시 엽니다. Safari는 지원하지 않으므로 ‘방문 기록’ 메뉴에서 삭제하세요.
- **알림 끄기(방해금지 모드)**: 켜면 방해금지 모드가 켜지고, 끄면 해제됩니다. 허용된 알림은 계속 도착할 수 있습니다. 체크 상태는 PodiumAssist에서 마지막으로 전환한 상태이며, 제어 센터 등에서 바꾼 경우에는 반영되지 않습니다.
- **프리셋**: 메인 윈도우의 ‘프리셋’ 탭에서 저장한 프리셋의 설정을 한꺼번에 적용합니다. 마지막으로 적용한 프리셋에는 ✓가 표시됩니다. ‘기본’, ‘확대/축소’ 또는 ‘타이머’ 탭에서 설정을 바꾸면 ✓는 사라집니다.

※ 시스템 설정의 변경 사항은 PodiumAssist를 종료한 후에도 유지됩니다.

## 타이머
1. 메인 윈도우의 ‘기본’ 탭에서 시작 시간, 소요 시간, 종료 시간을 지정합니다(시작 시간+소요 시간=종료 시간).
2. ‘시작 / 예약’을 클릭하면 실행됩니다.
3. ‘중지’를 클릭하면 멈춥니다.

- 시작 시간이나 소요 시간을 바꾸면 종료 시간이, 종료 시간을 바꾸면 소요 시간이 갱신됩니다. 소요 시간은 1~10,080분입니다.
- 날짜와 시각은 별도의 칸에서 지정합니다. ‘오늘 날짜로 설정’은 시작 날짜를 오늘로, ‘현재 시각으로 설정’은 시작 시각을 현재로 맞춥니다.
- 시작 전에는 ‘시작까지’와 남은 시간을, 시작 후에는 남은 시간을 메뉴 막대에 표시하며, 종료되면 00:00에서 멈춥니다.
- 실행 중에 입력을 변경한 경우 ‘설정을 적용하고 다시 시작’을 클릭하세요.
- 앱을 다시 실행해도 타이머가 복원되며, 잠자기 중에도 시간은 계속 흐릅니다.
- ‘타이머 사용’을 끄면 타이머가 중지되고 메뉴 막대에는 아이콘만 표시됩니다.

## 프리셋
1. ‘기본’, ‘확대/축소’, ‘타이머’ 탭에서 Mac을 저장할 상태로 설정합니다.
2. option 키를 누른 채 ‘프리셋에 저장’을 클릭하고(프리셋이 아직 없으면 그냥 클릭) 저장 위치(새 프리셋 또는 기존 프리셋)와 이름을 지정합니다.
3. 포함할 항목을 체크하고 ‘저장’을 클릭합니다. 체크하지 않은 항목은 적용해도 바뀌지 않습니다.

- 기존 프리셋에 저장하면 그 프리셋에 포함되어 있던 항목이 처음부터 체크됩니다. 이름, 순서, 앱 목록은 그대로입니다.
- ‘프리셋에 저장’을 클릭하면 창을 열지 않고 마지막으로 적용(또는 저장)한 프리셋에 덮어씁니다. 포함 항목은 그대로이고 값만 현재 상태로 바뀝니다.
- 메인 윈도우의 ‘프리셋’ 탭에서 버튼을 오른쪽 클릭하면 이름 변경, 위로/아래로 이동, 실행/종료 앱 편집, 삭제를 할 수 있습니다.
- 실행 앱과 종료 앱은 프리셋마다의 목록이며 다른 프리셋에는 영향을 주지 않습니다. 이미 실행 중인 앱은 중복으로 실행하지 않으며, 강제 종료하지 않습니다. 저장하지 않은 문서가 있으면 해당 앱의 확인 창에서 저장하세요.
- 프리셋의 타이머 항목은 ‘타이머 사용’과 소요 시간입니다. 시작/예약은 별도로 조작하므로 프리셋을 적용해도 타이머는 시작되지 않습니다.

## 설정
메인 윈도우의 ‘설정…’ 버튼을 클릭하거나 ⌘,를 누르면 별도의 윈도우로 열립니다.
- **시작 및 백그라운드**: 로그인 시 실행, 시작 시 메인 윈도우 표시 안 함, Dock 및 앱 전환기에 표시 안 함, 메뉴 막대에 표시
- **설정 공유**: ‘내보내기…’로 프리셋과 ‘타이머 사용’을 PodiumAssist-Settings.plist에 쓰고, 다른 Mac에서 ‘가져오기…’로 읽어 옵니다(‘추가’는 없는 프리셋만 더하고, ‘대치’는 파일의 설정을 사용). ‘설정 동기화’에서 iCloud Drive, Dropbox 등의 폴더를 선택하면 다른 Mac과 자동으로 동기화됩니다. 로그인 시 실행, 백그라운드, 메뉴 막대, 타이머 시작 시간과 소요 시간, 마지막으로 적용한 프리셋은 Mac마다 유지합니다

## 키보드 단축키
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: PodiumAssist 도움말
- **⌘Q**: PodiumAssist 종료(메인 윈도우의 ‘PodiumAssist 종료’)
- **⌘Z / ⇧⌘Z**: 실행 취소 / 실행 복귀(입력란 편집 시)

## 권한과 알림 연동
### 모양 변경(System Events)
모양 변경에는 System Events를 사용합니다. 처음에 권한을 요청하면 허용하세요. 허용하지 않은 경우 시스템 설정 → ‘개인정보 보호 및 보안’ → ‘자동화’에서 PodiumAssist가 System Events를 제어하도록 허용하세요. 손쉬운 사용 권한은 필요하지 않습니다.

### 투명도 줄이기(손쉬운 사용)
‘투명도 줄이기’와 ‘동작 줄이기’는 시스템 설정의 스위치를 자동으로 조작하여 전환합니다(macOS의 제한으로 설정 값을 직접 바꾸면 반영되지 않기 때문). 메인 윈도우의 ‘설정…’ → ‘시작 및 백그라운드’ → ‘손쉬운 사용’에서 허용하세요. 다른 기능에는 이 권한이 필요하지 않습니다.

### 알림 전환(단축어)
Mac의 ‘단축어’ 앱에 있는 다음 두 단축어를 사용합니다. 이름을 바꾸지 말고 그대로 만드세요.
- **Toki Notifications Off**: 방해금지 모드 켜기
- **Toki Notifications On**: 방해금지 모드 끄기

※ 다른 Mac에서 이 기능을 사용할 때도 이 두 단축어가 필요합니다.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않고 메뉴 막대에 상주합니다. 메뉴 막대 아이콘을 클릭하면 메인 윈도우를 다시 표시할 수 있습니다. 아이콘을 오른쪽 클릭(또는 Control 키를 누른 채 클릭)하면 ‘메인 윈도우 열기’, ‘설정…’, ‘도움말’, ‘메뉴 막대 설정…’, ‘PodiumAssist 종료’ 메뉴가 열립니다.
- 로그인 시 실행되었거나 ‘시작 시 메인 윈도우 표시 안 함’이 켜져 있으면 메인 윈도우를 열지 않고 시작합니다.
- ‘Dock 및 앱 전환기에 표시 안 함’을 켜면 메인 윈도우가 열려 있어도 Dock과 ⌘Tab 전환기에 아이콘을 표시하지 않습니다. 메뉴 막대 아이콘 또는 Finder에서 앱을 다시 열어 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 꺼도 앱은 종료되지 않습니다. PodiumAssist를 다시 열면 메인 윈도우가 표시됩니다.
- 종료하려면 메인 윈도우의 ‘PodiumAssist 종료’ 버튼(⌘Q)을 클릭하거나, 아이콘의 오른쪽 클릭 메뉴에서 ‘PodiumAssist 종료’를 선택합니다. 메뉴 막대의 표시는 사라지지만, 변경한 시스템 설정은 그대로 유지됩니다.

## 문제 해결
- Dock과 데스크탑 설정을 적용하기 위해 Dock이나 Finder를 다시 시작할 수 있습니다.
- 알림이 전환되지 않으면 ‘단축어’ 앱에 ‘Toki Notifications Off’와 ‘Toki Notifications On’이 있고 이름이 정확한지 확인하세요.
- 모양이 바뀌지 않으면 위의 ‘자동화’ 권한을 확인하세요.
- 시계와 Dock 설정은 macOS 내부 설정을 사용하므로 macOS 업데이트 후 동작이 바뀔 수 있습니다.

## 도움말과 note 글
- 메인 윈도우 아래쪽의 ‘도움말’에서 ‘PodiumAssist 도움말’을 선택하면 이 도움말이 열립니다(⌘?로도 열 수 있습니다).
- 같은 메뉴의 ‘note 글 열기’를 선택하면 note의 소개 글을 브라우저에서 엽니다.

## 앱 삭제
1. 필요하면 Dock 설정과 데스크탑 아이콘 표시를 원래대로 되돌립니다.
2. ‘로그인 시 실행’을 끕니다.
3. 메인 윈도우의 ‘PodiumAssist 종료’로 앱을 종료하고 PodiumAssist를 휴지통으로 이동합니다.
