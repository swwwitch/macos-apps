SiteMirror는 입력한 URL의 웹사이트 페이지를 따라가며 HTML, CSS, JavaScript, 이미지, 서체를 저장하는 앱입니다. 저장한 파일의 링크는 상대 경로로 바꾸므로 네트워크에 연결되어 있지 않아도 브라우저에서 열어 볼 수 있습니다.

## 사용 방법
### 다운로드하기
1. ‘URL:’에 다운로드할 사이트의 URL을 입력합니다(예: https://example.com/). ‘https://’는 생략할 수 있습니다. 브라우저의 주소 막대나 링크를 윈도우로 드롭해도 입력됩니다.
2. ‘저장 위치:’ 옆의 ‘변경…’으로 저장 폴더를 선택합니다. 처음에는 다운로드 폴더입니다.
3. ‘다운로드’(Return 또는 ⌘R)를 클릭합니다. 목록에 저장한 파일과 저장 위치, 실패하거나 제외한 URL과 이유가 표시됩니다.
4. 끝나면 ‘브라우저에서 열기’로 시작 페이지를 열거나, ‘Finder에서 보기’로 저장한 폴더를 표시합니다.
- 다운로드 폴더에 ‘SiteMirror-log.txt’를 만들어 일시, 개수와 실패·제외한 URL, 이유, 참조 위치(그 URL에 링크한 파일)를 탭으로 구분해 남깁니다. ‘기록 열기’로 열 수 있습니다. 덮어써서 다운로드하면 바뀝니다.
- 목록 위의 ‘실패’, ‘제외됨’을 선택하면 저장하지 못한 URL과 이유만 표시합니다. 행을 선택하고 ⌘C를 누르거나, 오른쪽 클릭 후 ‘URL 복사’, ‘URL과 이유 복사’로 복사할 수 있습니다(여러 행은 줄바꿈으로 구분). 저장한 행은 오른쪽 클릭의 ‘Finder에서 보기’로 그 파일을 표시합니다.

### 따라가는 범위
- 시작 URL과 같은 호스트의 페이지를 따라갑니다. ‘www.’ 유무와 http·https의 차이는 같은 사이트로 봅니다. 시작 URL이 리디렉션되면 리디렉션된 호스트도 같은 사이트로 취급합니다.
- 페이지 표시에 필요한 파일(CSS, JavaScript, 이미지, 서체, 동영상 등)은 다른 도메인(CDN 등)에 있어도 저장합니다. 설정의 ‘다운로드’에서 끌 수 있습니다. 다른 도메인의 페이지는 따라가지 않습니다.
- 같은 사이트의 링크가 PDF나 ZIP 등의 파일이면 그 파일도 저장합니다.
- 기본적으로 robots.txt로 제외된 페이지는 따라가지 않습니다.

### 저장되는 폴더
- 저장 폴더 안에 사이트의 호스트 이름으로 된 폴더(예: example.com)를 만듭니다.
- 같은 사이트의 폴더가 이미 있으면(그 폴더 자체를 저장 위치로 선택한 경우 포함) ‘덮어쓰기’, ‘새 폴더에 저장’, ‘취소’ 중에서 선택합니다. 덮어쓰면 이번에 다운로드한 파일로 바꾸며, 이번에 다운로드하지 않은 이전 파일은 지우지 않고 남깁니다. ‘새 폴더에 저장’은 ‘example.com 2’처럼 번호를 붙인 폴더에 저장합니다.
- 사이트의 파일은 그 폴더 바로 아래에 원래 경로와 같은 구성으로 둡니다. 다른 도메인의 파일은 ‘_hosts/<호스트 이름>’에 둡니다.
- ‘/about’처럼 확장자가 없는 페이지는 ‘about.html’, ‘/blog/’처럼 폴더로 끝나는 페이지는 ‘blog/index.html’로 저장합니다. ‘?id=1’ 등이 붙은 URL은 파일 이름에 짧은 표시를 붙여 별도의 파일로 저장합니다.

### 링크 바꾸기
- 다운로드가 끝나면 저장한 HTML과 CSS의 링크를 저장한 파일에 대한 상대 경로로 바꿉니다.
- 저장하지 않은 파일에 대한 링크(다른 사이트의 페이지, 실패한 파일 등)는 원래의 절대 URL로 바꿉니다.
- <base> 태그는 제거합니다. 바꾼 CSS가 로드되지 않는 것을 막기 위해 integrity·crossorigin 속성도 제거합니다.
- 중간에 중단해도 그때까지 저장한 파일의 링크는 바꿉니다.

## 설정
메인 윈도우의 ‘설정’ 버튼(⌘,)으로 엽니다.
- **시작 및 백그라운드**: 로그인 시 실행, 시작 시 메인 윈도우 표시 안 함, Dock 및 앱 전환기에 표시 안 함, 메뉴 막대에 표시. ‘Dock 및 앱 전환기에 표시 안 함’를 켜면 Dock과 ⌘Tab 전환에 아이콘을 표시하지 않습니다. 메뉴 막대 아이콘(표시 중일 때)이나 Finder에서 앱을 다시 열면 표시할 수 있습니다
- **다운로드**: 다른 도메인의 파일을 저장할지, 하위 도메인의 페이지를 따라갈지, 시작 URL의 폴더보다 위로 따라가지 않을지, robots.txt를 따를지. 링크 깊이(기본 무제한), 파일 수 상한(기본 10,000), 동시 연결 수(기본 4). 변경 사항은 다음 다운로드부터 적용됩니다.
- **설정 공유**: ‘다운로드’ 설정을 내보내고 가져오며, iCloud Drive·Dropbox 등의 폴더로 다른 Mac과 동기화합니다. 저장 폴더는 Mac마다 설정합니다.
- **정보**: 버전과 링크.

## 단축키
- **Return / ⌘R**: 다운로드
- **⌘.**: 중단
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: SiteMirror 도움말
- **⌘Q**: SiteMirror 종료

## 접근 권한과 개인정보
- 손쉬운 사용 권한은 필요하지 않습니다.
- 입력한 사이트와 그 페이지가 로드하는 파일이 있는 곳에만 연결합니다(‘업데이트 확인…’ 제외). SiteMirror임을 나타내는 User-Agent를 보냅니다. 쿠키나 로그인 정보는 보내지 않으므로 로그인이 필요한 페이지는 저장할 수 없습니다.
- 다운로드 폴더 등을 저장 위치로 선택하면 macOS가 접근 허가를 확인할 수 있습니다.
- 다운로드한 내용은 해당 사이트의 이용 약관과 저작권에 따라 사용하십시오. 동시 연결 수를 너무 늘리면 상대 서버에 부담이 됩니다.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하거나 ⌘0으로 메인 윈도우를 다시 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 켜면 메뉴 막대 아이콘에서도 ‘메인 윈도우 열기’, ‘설정…’, ‘도움말’을 선택할 수 있습니다.
- 종료하려면 앱 메뉴에서 ‘SiteMirror 종료’(⌘Q)를 선택합니다. 다운로드 중에는 먼저 확인하며, 중단을 선택하면 저장한 파일까지 링크를 바꾼 뒤 종료합니다.
- 앱 메뉴의 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다. 배포 준비가 끝날 때까지는 준비 중으로 표시되며 통신하지 않습니다.

## 문제 해결
- JavaScript가 나중에 로드하는 이미지와 페이지, JavaScript 안에 적힌 URL은 저장할 수 없습니다. HTML과 CSS에 적힌 링크만 따라갑니다.
- 브라우저에서 열었을 때 표시가 깨지면 브라우저가 로컬 파일에서의 로드를 제한하고 있을 수 있습니다. 저장한 폴더에서 ‘python3 -m http.server’ 같은 간단한 서버를 실행해 열면 표시될 수 있습니다.
- 중간에 멈춘 것처럼 보이면 파일 수 상한에 도달했거나 상대 서버가 응답하지 않는 것입니다. 목록에서 실패 이유를 확인하십시오.
- ‘HTTP 403’ 등의 실패가 계속되면 사이트가 자동 다운로드를 거부하고 있는 것입니다. 동시 연결 수를 줄이거나 다운로드를 중단하십시오.

## 도움말과 note 글
- 이 도움말은 도움말 메뉴의 ‘SiteMirror 도움말’(⌘?)로 엽니다.
- 도움말 메뉴의 ‘note 글 열기’로 note의 해설 글을 브라우저에서 엽니다.

## 앱 삭제
1. ‘로그인 시 실행’을 끕니다.
2. ‘SiteMirror 종료’를 선택합니다.
3. SiteMirror를 휴지통으로 옮깁니다. 다운로드한 사이트 폴더는 저장 위치에 남습니다.
