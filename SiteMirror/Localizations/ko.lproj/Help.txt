SiteMirror는 입력한 URL의 웹사이트 페이지를 따라가며 HTML, CSS, JavaScript, 이미지, 서체를 저장하는 앱입니다. 저장한 파일의 링크는 상대 경로로 바꾸므로 네트워크에 연결되어 있지 않아도 브라우저에서 열어 볼 수 있습니다.

## 사용 방법
링크 확인 또는 다운로드를 선택한 다음 ‘시작’ 또는 Return으로 실행합니다. 모드 선택만으로는 시작하지 않습니다. ⌘R은 다운로드를, ⇧⌘R은 링크 확인을 바로 시작합니다。
### 다운로드하기
1. ‘URL:’에 다운로드할 사이트의 URL을 입력합니다(예: https://example.com/). ‘https://’는 생략할 수 있습니다. 브라우저의 주소 막대나 링크를 윈도우로 드롭해도 입력됩니다.
2. ‘저장 위치:’ 옆의 ‘변경…’으로 저장 폴더를 선택합니다. 처음에는 다운로드 폴더입니다.
3. ‘다운로드’를 선택한 뒤 ‘시작’(Return)를 클릭합니다. 목록에 저장한 파일과 저장 위치, 실패하거나 제외한 URL과 이유가 표시됩니다.
4. 끝나면 ‘브라우저에서 열기’로 시작 페이지를 열거나, ‘Finder에서 보기’로 저장한 폴더를 표시합니다.
- 다운로드 폴더에 ‘SiteMirror-log.txt’를 만들어 일시, 개수와 실패·제외한 URL, 이유, 참조 위치(그 URL에 링크한 파일)를 탭으로 구분해 남깁니다. ‘기록 열기’로 열 수 있습니다. 덮어써서 다운로드하면 바뀝니다.
- 목록 위의 ‘실패’, ‘제외됨’을 선택하면 저장하지 못한 URL과 이유만 표시합니다. 행을 선택하고 ⌘C를 누르거나, 오른쪽 클릭 후 ‘URL 복사’, ‘URL과 이유 복사’로 복사할 수 있습니다(여러 행은 줄바꿈으로 구분). 저장한 행은 오른쪽 클릭의 ‘Finder에서 보기’로 그 파일을 표시합니다.

### 로그인이 필요한 사이트
1. URL을 입력하고 ‘로그인…’을 클릭하면 앱 안의 브라우저에서 그 사이트가 열립니다.
2. 평소처럼 로그인하고 ‘완료’를 클릭합니다. 로그인한 사이트는 버튼 아이콘에 체크 표시가 붙습니다.
3. ‘다운로드’를 하면 그 로그인 상태(쿠키)를 사용합니다. 이름과 암호를 묻는 사이트(Basic 인증)는 그 이름과 암호도 사용합니다(SiteMirror를 종료할 때까지).
- 로그인 중에는 URL에 logout, sign-out 등이 포함된 페이지를 따라가지 않습니다(따라가면 로그아웃되기 때문).
- 로그인 상태는 앱 안의 브라우저에 남습니다. ‘로그인…’ 윈도우의 ‘로그인 정보 지우기…’로 모든 사이트의 정보를 지울 수 있습니다.

### 끊어진 링크 확인
- ‘링크 확인’(⇧⌘R)은 다운로드할 때와 같은 범위의 페이지를 따라가되 아무것도 저장하지 않고 링크 대상이 있는지만 확인합니다. 다른 사이트로의 링크도 따라가지 않고 있는지만 확인합니다.
- 결과는 저장 폴더에 ‘<호스트 이름>-linkcheck-<일시>.txt’로 쓰며 ‘기록 열기’로 열 수 있습니다. 끊어진 URL, 이유, 참조 페이지 목록입니다.

### 따라가는 범위
- 시작 URL과 같은 호스트의 페이지를 따라갑니다. ‘www.’ 유무와 http·https의 차이는 같은 사이트로 봅니다. 시작 URL이 리디렉션되면 리디렉션된 호스트도 같은 사이트로 취급합니다.
- 페이지 표시에 필요한 파일(CSS, JavaScript, 이미지, 서체, 동영상 등)은 다른 도메인(CDN 등)에 있어도 저장합니다. 설정의 ‘다운로드’에서 끌 수 있습니다. 다른 도메인의 페이지는 따라가지 않습니다.
- 같은 사이트의 링크가 PDF나 ZIP 등의 파일이면 그 파일도 저장합니다.
- 기본적으로 robots.txt로 제외된 페이지는 따라가지 않습니다.

### 저장되는 폴더
- 저장 폴더 안에 사이트의 호스트 이름으로 된 폴더(예: example.com)를 만듭니다.
- 같은 사이트의 폴더가 이미 있으면(그 폴더 자체를 저장 위치로 선택한 경우 포함) ‘덮어쓰기’, ‘새 폴더에 저장’, ‘취소’ 중에서 선택합니다. 덮어쓰면 이번에 다운로드한 파일로 바꾸고, 변경되지 않은 이미지 등은 서버에 확인만 하고 다시 다운로드하지 않으며(이를 위한 목록을 ‘.sitemirror.json’으로 둡니다), 이번에 다운로드하지 않은 이전 파일은 지우지 않고 남깁니다. ‘새 폴더에 저장’은 ‘example.com 2’처럼 번호를 붙인 폴더에 저장합니다.
- 중간에 중단한 다운로드는 같은 폴더에 다운로드하면 ‘이어서 다운로드’를 선택할 수 있습니다. 저장한 파일은 다시 다운로드하지 않고 나머지만 다운로드합니다.
- 설정에서 ‘사이트에서 사라진 파일을 휴지통으로 옮기기’를 켜면, 덮어쓰기 다운로드를 끝까지 마쳤을 때 지난번에 저장했지만 이번에 어디에서도 링크되지 않는 파일과 서버가 404·410을 반환한 파일을 휴지통으로 옮기고 기록 파일에 목록을 남깁니다.
- 사이트의 파일은 그 폴더 바로 아래에 원래 경로와 같은 구성으로 둡니다. 다른 도메인의 파일은 ‘_hosts/<호스트 이름>’에 둡니다.
- ‘/about’처럼 확장자가 없는 페이지는 ‘about.html’, ‘/blog/’처럼 폴더로 끝나는 페이지는 ‘blog/index.html’로 저장합니다. ‘?id=1’ 등이 붙은 URL은 파일 이름에 짧은 표시를 붙여 별도의 파일로 저장합니다.

### 링크 바꾸기
- 다운로드가 끝나면 저장한 HTML과 CSS의 링크를 저장한 파일에 대한 상대 경로로 바꿉니다.
- 저장하지 않은 파일에 대한 링크(다른 사이트의 페이지, 실패한 파일 등)는 원래의 절대 URL로 바꿉니다.
- <base> 태그는 제거합니다. 바꾼 CSS가 로드되지 않는 것을 막기 위해 integrity·crossorigin 속성도 제거합니다.
- 중간에 중단해도 그때까지 저장한 파일의 링크는 바꿉니다.

## 설정
메인 윈도우의 ‘설정’ 버튼(⌘,)으로 엽니다.
- **시작 및 백그라운드**: 로그인 시 실행, Dock 및 앱 전환기에 표시 안 함, 메뉴 막대에 표시. ‘Dock 및 앱 전환기에 표시 안 함’를 켜면 Dock과 ⌘Tab 전환에 아이콘을 표시하지 않습니다. 메뉴 막대 아이콘(표시 중일 때)이나 Finder에서 앱을 다시 열면 표시할 수 있습니다
- **다운로드**: 다른 도메인의 파일을 저장할지, 하위 도메인의 페이지를 따라갈지, 시작 URL의 폴더보다 위로 따라가지 않을지, robots.txt를 따를지, 포함할 URL(지정하면 해당 페이지만), 제외할 URL(한 줄에 하나, 예: ?page=, /tag/), sitemap.xml의 페이지도 따라갈지, JavaScript 안의 URL도 가져올지(추측). 건너뛸 파일 종류(확장자, 예: mp4, zip), 파일당 상한, 합계 상한(MB). 링크 깊이(기본 무제한), 파일 수 상한(기본 10,000). 동시 연결 수(기본 4), 요청 간격(기본 없음), 실패 시 재시도(기본 2회, 타임아웃과 일시적인 오류일 때만). 덮어쓸 때 변경되지 않은 이미지 등을 다시 다운로드하지 않을지(기본 켬, HTML과 CSS는 매번 다시 다운로드), 사이트에서 사라진 파일을 휴지통으로 옮길지(기본 끔). 변경 사항은 다음 다운로드부터 적용됩니다.
- **설정 공유**: ‘다운로드’ 설정을 내보내고 가져오며, iCloud Drive·Dropbox 등의 폴더로 다른 Mac과 동기화합니다. 저장 폴더는 Mac마다 설정합니다.
- **정보**: 버전과 링크.

## 단축키
- **⌘R**: 다운로드
- **⇧⌘R**: 링크 확인
- **⌘.**: 중단
- **⌘0**: 메인 윈도우 열기
- **⌘,**: 설정
- **⌘W**: 윈도우 닫기
- **⌘?**: SiteMirror 도움말
- **⌘Q**: SiteMirror 종료

## 접근 권한과 개인정보
- 손쉬운 사용 권한은 필요하지 않습니다.
- 입력한 사이트와 그 페이지가 로드하는 파일이 있는 곳에만 연결합니다(‘업데이트 확인…’ 제외). SiteMirror임을 나타내는 User-Agent를 보냅니다. ‘로그인…’으로 로그인한 사이트에만 그 쿠키와 인증 정보를 보냅니다. 로그인 상태는 앱 안 브라우저의 저장 위치(~/Library/WebKit 안)에 남습니다.
- 다운로드 폴더 등을 저장 위치로 선택하면 macOS가 접근 허가를 확인할 수 있습니다.
- 다운로드한 내용은 해당 사이트의 이용 약관과 저작권에 따라 사용하십시오. 동시 연결 수를 너무 늘리면 상대 서버에 부담이 됩니다.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하거나 ⌘0으로 메인 윈도우를 다시 표시할 수 있습니다.
- ‘메뉴 막대에 표시’를 켜면 메뉴 막대 아이콘에서도 ‘메인 윈도우 열기’, ‘설정…’, ‘도움말’을 선택할 수 있습니다.
- 종료하려면 앱 메뉴에서 ‘SiteMirror 종료’(⌘Q)를 선택합니다. 다운로드 중에는 먼저 확인하며, 중단을 선택하면 저장한 파일까지 링크를 바꾼 뒤 종료합니다.
- 앱 메뉴의 ‘업데이트 확인…’으로 새 버전을 확인할 수 있습니다. 배포 준비가 끝날 때까지는 준비 중으로 표시되며 통신하지 않습니다.

## 문제 해결
- JavaScript가 나중에 로드하는 이미지와 페이지는 저장할 수 없습니다. HTML과 CSS에 적힌 링크를 따라갑니다. JavaScript 안에 적힌 이미지 등의 URL은 설정에서 ‘JavaScript 안에 적힌 URL도 가져오기’를 켜면 가져올 수 있습니다.
- 브라우저에서 열었을 때 표시가 깨지면 브라우저가 로컬 파일에서의 로드를 제한하고 있을 수 있습니다. 저장한 폴더에서 ‘python3 -m http.server’ 같은 간단한 서버를 실행해 열면 표시될 수 있습니다.
- 중간에 멈춘 것처럼 보이면 파일 수 상한에 도달했거나 상대 서버가 응답하지 않는 것입니다. 목록에서 실패 이유를 확인하십시오.
- ‘HTTP 403’ 등의 실패가 계속되면 사이트가 자동 다운로드를 거부하고 있는 것입니다. 동시 연결 수를 줄이고 요청 간격을 두거나 다운로드를 중단하십시오.
- 로그인했는데도 ‘HTTP 401’, ‘HTTP 403’이 되면 ‘로그인…’으로 다시 로그인하십시오. 로그인이 만료되었을 수 있습니다.

## 도움말과 note 글
- 이 도움말은 도움말 메뉴의 ‘SiteMirror 도움말’(⌘?)로 엽니다.
- 도움말 메뉴의 ‘note 글 열기’로 note의 해설 글을 브라우저에서 엽니다.

## 앱 삭제
1. ‘로그인 시 실행’을 끕니다.
2. ‘SiteMirror 종료’를 선택합니다.
3. SiteMirror를 휴지통으로 옮깁니다. 다운로드한 사이트 폴더는 저장 위치에 남습니다.

수동으로 실행하거나 다시 열면 메인 윈도우를 표시합니다. 로그인 시 자동 실행에서는 표시하지 않습니다. 파일을 명시적으로 열면 해당 작업을 우선합니다.

## 알림
- 설정의 알림에서 완료 시 알림을 켜면 다운로드와 링크 검사의 완료 또는 실패 결과를 알립니다. 기본값은 꺼짐입니다. 취소하거나 앱이 전면에 있으면 알림을 표시하지 않습니다. 알림을 클릭하면 결과 화면을 엽니다. URL과 인증 정보는 포함하지 않습니다. 알림을 켤 때만 권한을 요청합니다. 알림이 없어도 앱에서 결과와 실패 이유를 확인할 수 있습니다. 알림 설정 열기에서 macOS 표시 방식과 사운드를 설정하세요.

## URL 기록
- URL 입력란 오른쪽의 기록 메뉴에서 최근 URL을 선택할 수 있습니다. 다운로드나 링크 검사를 시작한 URL을 최신순으로 최대 20개까지 이 Mac에 저장합니다. 다시 사용하면 맨 위로 이동합니다. 선택하면 입력란만 채워지며 다운로드를 눌러야 시작합니다. URL 기록 지우기는 기록만 삭제합니다. 업데이트 전에 입력한 마지막 URL은 처음 한 번 가져옵니다. 사용자 이름이나 비밀번호가 포함된 URL은 기록에 저장하지 않습니다.

## 다시 가져오기 차이
- 같은 위치에 다시 가져오면 실행 전후 저장 파일을 비교해 SiteMirror-diff-<날짜>-<ID>.txt를 저장합니다. 차이 열기로 기본 텍스트 앱에서 엽니다. 추가, 변경, 변경 없음, 로컬 삭제, 404/410, 미확인을 구분합니다. HTML/CSS는 링크를 다시 쓴 후 비교합니다. -는 이전, +는 이후입니다. 처음에는 추가 목록입니다.
- 제외, 미방문, 실패는 삭제로 판단하지 않습니다. 취소나 한도 도달은 부분 비교이며 이어받기는 재개 직전과 비교합니다. 수동 편집도 포함합니다. 줄 차이는 UTF-8/Shift_JIS 텍스트를 파일당 256KB, 이전 내용 총 8MB, 변경 100개, 차이당 32000자까지 표시합니다. 이미지는 해시만 비교합니다. 보고서는 날짜와 ID를 붙여 매번 별도 파일로 저장하며 불필요한 보고서는 Finder에서 삭제할 수 있습니다. 로그인한 페이지 내용이 포함될 수 있습니다.

## 화면 구성
- URL 입력란 오른쪽 화살표에서 기록을 선택합니다. 처리 모드를 선택한 뒤 오른쪽 시작을 누릅니다. 가져오기 결과 제목 오른쪽에서 목록을 필터링합니다. 하단 결과 열기 메뉴에서 차이, 기록, Finder, 브라우저 열기를 선택합니다.
