## 起動

`../ExtensionLinker.app` を開きます。左に拡張子、右に対応アプリを表示します。

指定された20組（23種類の拡張子）の拡張子を初期一覧に表示します。起動時は現在のmacOSの設定を表示し、「プリセット → 初期プリセットを読み込む」で指定プリセットを読み込めます。右のアプリ名をクリックすると別のアプリを選べます。「変更を適用」で確認後にmacOSの既定アプリを変更します。未インストールの指定アプリは警告を表示し、適用をスキップします。Acrobat Readerの場合は.pdf行からReaderを選択してください。

検索、変更のみ表示、拡張子の追加、再読み込み（⌘R）、未適用の変更の取り消しに対応しています。「取り消す」は未適用の選択を取り消します。適用後の設定は元のアプリを選び直して再適用してください。

メインウインドウの空いている場所に.appをドロップすると、関連付ける拡張子を複数選択できます。新しい拡張子をその場で追加することもできます。

Finderの「アプリケーション」から.appを右側の対応アプリ欄へドラッグ＆ドロップして変更予定に追加できます。一覧内のアプリアイコンを別の行へドラッグして指定することもできます。アプリ選択画面では「ここにアプリをドラッグ＆ドロップ」の欄がドロップ先です。アプリの実際のアイコンを表示し、有効なアプリを重ねると、ドロップ先の行全体を青い背景と青枠で強調します。アプリ以外のファイル・フォルダ、複数同時のドロップは受け付けません。ドロップ後、「変更を適用」で反映してください。

macOSは拡張子から解決したUTType単位で設定します。.jpgと.jpegなど同じタイプの拡張子にも変更が及びます。拡張子ごとに異なるアプリを選んでも同じUTTypeの場合は最後の変更が有効になります。

## 設定

メニューバーの **ExtensionLinker → 設定…（⌘,）** から開きます。「インストール」タブの見出しは「dutiとHomebrewのインストール」です。

- dutiとHomebrewのインストール状態とパスを表示。
- dutiがインストール済みの場合、バージョンも表示。`duti -V` が `INTERNAL` を返すHomebrewビルドでは、実行ファイルの導入先からパッケージバージョンを取得し、その旨を表示。
- Homebrewがあれば「dutiをインストール」で `brew install duti` を実行。
- 終了後に実行ログと成功・失敗を表示。実行中はアプリを終了せずお待ちください。
- Homebrewがない場合は「Homebrewをインストール…」でターミナルに公式インストーラーを起動。ターミナルで操作を完了してから「再確認」を押します。公式導入ページへのリンクも表示。

GUIの関連付け変更にはdutiのインストールは不要です。dutiと同じLaunch Servicesの `LSSetDefaultRoleHandlerForContentType` を `.all` で実行し、ファイルを開く既定アプリを `.all` で読み戻して確認します。反映の確認は最大6回行い、実行用のshellロールは要求しません。設定失敗は行に表示します。再読み込みで指定したアプリへの反映を確認できれば、古いエラーを消します。

## ビルド

XcodeのSwift開発環境が必要です。

```sh
bash build.sh
```

`../ExtensionLinker.app` と `../../Latest Builds/ExtensionLinker.app` を更新し、ローカル用のad-hoc署名を行います。このビルドはApple Silicon用です。他のMacへの一般配布用のDeveloper ID署名・公証は含みません。

ソースはPackage.swiftをXcodeで開いて編集できます。Package.swiftに外部パッケージの依存はありませんが、通常配布版のビルドでは `../../Shared/Updater` が用意するSparkle.frameworkをリンクしてアプリに同梱します（`APP_STORE_BUILD=1` のときはリンクしません）。

API: [Apple Launch Services](https://developer.apple.com/documentation/coreservices/1444955-lssetdefaultrolehandlerforconten)、[対応アプリの取得](https://developer.apple.com/documentation/appkit/nsworkspace/urlsforapplications(toopen:)-60rkm)。

## 自分のプリセット

メイン画面の「プリセット」メニューから操作します。

- 「現在の組み合わせを保存…」で、一覧の設定と変更予定をUTF-8テキストに保存します。検索中でも一覧全体を保存します。未設定の行は除きます。
- 「読み込む…」で自分のテキストファイルを選びます。ファイル内の拡張子だけを変更予定に読み込み、未登録の拡張子は一覧へ追加します。
- コマンドは実行せず、関連付けの指定として読み取ります。「変更を適用」で反映します。
- 別のMacでアプリが未インストールの場合、その行に警告を表示します。
- 「初期プリセットを読み込む」は最後に指定したExcel・Word・Adobeアプリ等の組み合わせを呼び出します。

形式は次のとおりです。空行と、先頭の空白を除いて # から始まる行は無視します。

```sh
# Photoshop
duti -s com.adobe.Photoshop .gif all
duti -s com.adobe.Photoshop .jpg all
duti -s com.adobe.Photoshop .png all
duti -s com.adobe.Photoshop .webp all

# Illustrator
duti -s com.adobe.illustrator .ai all
```

対応形式は `duti -s アプリID .拡張子 all` です。別のコマンドや異なるロールを含む場合は、行番号付きのエラーを表示し、全体を読み込みません。

## 拡張子の別名

.jpg / .jpeg、.html / .htm、.tif / .tiffはそれぞれ1行にまとめて表示し、アプリ変更は両方の拡張子のファイルタイプに反映します。保存するテキストには、両方の拡張子のコマンドを書き出します。

読み込みファイルに両方が書かれている場合、同じアプリなら1行にまとめます。異なるアプリの場合は読み込まず、矛盾を示すエラーを表示します。同じ拡張子の重複も、同じアプリなら1つにまとめます。異なる指定の場合はエラーです。

## カテゴリタブ（0.2.0）

「すべて／デザイン／ビジネス／テキスト／開発／その他」で一覧を切り替えます。
画像・制作形式はデザイン、Office・PDFはビジネス、TXT・RTF・Markdown（.md / .markdown）はテキスト、コードは開発、それ以外はその他に分類します。
検索と「変更のみ」は選択中のカテゴリ内に適用します。タブを切り替えても変更予定は保持します。
下部の取り消し・適用・プリセット保存はすべてのカテゴリを対象にします。
拡張子の追加時はその拡張子のカテゴリへ移動し、プリセット読み込み時は「すべて」を表示します。

## 0.2.7の追加形式

ビジネスに `.doc / .docx`、`.ppt / .pptx`、デザインに `.psd`、`.indd`、開発に `.json`、`.ts / .tsx` を表示します。起動時は現在の関連付けを読み込み、アプリの変更は適用操作を行うまで反映しません。
