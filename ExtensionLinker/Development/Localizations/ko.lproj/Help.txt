확장자별로 파일을 여는 기본 앱을 설정합니다.

## 기본 사용법
1. 카테고리(전체, 디자인, 비즈니스, 텍스트, 개발, 기타)나 **확장자 또는 앱 검색**으로 확장자를 찾습니다.
2. 행을 이중 클릭(또는 오른쪽 클릭, ⌘/Control-클릭)하여 앱을 선택하거나, Finder의 ‘응용 프로그램’에서 .app을 행으로 드래그 앤 드롭합니다. 앱을 선택한 행은 ‘변경 예정’이 되며, 선택만으로는 적용되지 않습니다.
3. **변경 N개 적용**을 클릭하고 확인 창에서 **변경 적용**을 선택하면 모든 카테고리의 변경 예정을 한 번에 적용합니다.

- **변경 취소**는 적용하지 않은 변경 예정을 취소합니다.
- **변경 사항만**을 켜면 변경 예정인 행만 표시합니다.
- macOS는 파일 유형 단위로 설정하므로 같은 유형의 다른 확장자(예: .jpg와 .jpeg)도 함께 변경됩니다.
- 윈도우의 빈 곳에 .app 하나를 드롭하면 그 앱에 연결할 확장자를 한꺼번에 선택할 수 있습니다.
- 오른쪽 위의 + 버튼으로 목록에 없는 확장자를 추가할 수 있습니다.

## 프리셋
- **프리셋** 메뉴의 **현재 연결 저장…**은 목록의 연결을 텍스트 파일로 저장합니다.
- **불러오기…**는 파일을 변경 예정으로 불러오며, **변경 적용**을 클릭하면 적용됩니다.
- **기본 프리셋 불러오기**는 내장된 기본 프리셋을 변경 예정으로 지정합니다.

프리셋의 각 행은 ‘duti -s 앱ID .확장자 all’ 형식입니다. #으로 시작하는 행은 주석입니다. 불러온 내용은 명령으로 실행하지 않습니다.

## 설정
앱 메뉴의 **설정…**(⌘,)으로 엽니다.

### ‘시작 및 백그라운드’ 탭
- **로그인 시 실행**, **시작 시 메인 윈도우 표시 안 함**, **메뉴 막대에 표시**를 설정합니다.

### ‘설치’ 탭
- duti와 Homebrew의 설치 여부를 확인하고 설치할 수 있습니다.
- 연결 변경은 macOS 자체 기능으로 하므로 duti는 필요하지 않습니다. 터미널에서 같은 설정을 하려는 경우에 사용할 수 있습니다.

### ‘확장자’ 탭
- 메인 윈도우에 표시할 확장자를 추가하거나 제거합니다.
- 목록에서 제거해도 macOS의 연결은 바뀌지 않습니다.

### ‘앱 버전’ 탭
- Illustrator, Photoshop, InDesign처럼 여러 버전이 설치된 앱의 연결된 확장자를 모두 지정한 버전으로 열도록 합니다.
- **열 버전**에서 버전을 선택하고 **N개 전환**을 클릭합니다. **최신 버전(자동)**은 설치된 가장 새로운 버전으로 엽니다.
- macOS 연결 기록에 버전을 기록하고 연결을 관리하는 시스템 프로세스(lsd)를 다시 시작합니다. 변경 전 기록은 ~/Library/Application Support/ExtensionLinker/LaunchServicesBackups에 저장합니다.
- 메인 윈도우에서 앱을 다시 선택하면 해당 확장자는 최신 버전(자동)으로 돌아갑니다.

### 설정 공유 탭
- **내보내기…**로 확장자 목록(추가하거나 삭제한 확장자)을 ExtensionLinker-Settings.plist에 저장하고, **가져오기…**로 다른 Mac에서 불러옵니다. 가져올 때 ‘추가’(현재 목록에 더하기) 또는 ‘대치’를 선택할 수 있습니다.
- ‘설정 동기화’에서 iCloud Drive나 Dropbox 등의 폴더를 선택하면 같은 폴더를 선택한 Mac끼리 확장자 목록이 자동으로 맞춰집니다.
- 파일 연결(macOS의 기본 앱), 로그인 시 실행, 메뉴 막대는 Mac마다 설정합니다. 프리셋 파일은 ‘프리셋’ 메뉴에서 다룹니다.

## 키보드 단축키
- **⌘0**: 메인 윈도우 열기(닫은 후에도 다시 표시)
- **⌘R**: 현재 설정 다시 읽기
- **⌘,**: 설정
- **⌘?**: 도움말
- **⌘W**: 윈도우 닫기
- **⌘Q**: 종료

## 백그라운드 실행 및 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하면 윈도우를 다시 표시합니다.
- **메뉴 막대에 표시**를 켜면 메뉴 막대 아이콘에서 **메인 윈도우 열기**, **설정…**, **도움말**(**ExtensionLinker 도움말**, **note 글 열기**), **ExtensionLinker 종료**를 선택할 수 있습니다.
- 종료하려면 ⌘Q를 누르거나 앱 메뉴에서 **ExtensionLinker 종료**를 선택합니다.

## 권한
손쉬운 사용 등의 권한은 필요하지 않습니다. Homebrew는 터미널에서 설치하며 관리자 암호를 요청할 수 있습니다.

## 문제 해결
- 적용에 실패하면 해당 행에 오류가 표시됩니다. ⌘R로 다시 읽어 현재 연결을 확인하십시오.
- ‘설치되지 않음 · 다른 앱 선택’이 표시된 행은 지정한 앱이 이 Mac에 없으므로 적용되지 않습니다. 설치된 앱을 다시 선택하십시오.
- ‘별칭의 설정이 다릅니다’가 표시되면 앱을 선택하여 별칭 확장자의 설정을 통일할 수 있습니다.
- 적용한 변경을 되돌리려면 원래 앱을 다시 선택하고 다시 적용합니다. **변경 취소**는 적용하지 않은 변경 예정만 취소합니다.
- 도움말 메뉴에서 **note 글 열기**를 선택하면 note의 사용 안내 글을 브라우저에서 열 수 있습니다.

## 삭제
1. **로그인 시 실행**을 끕니다.
2. 앱을 종료합니다.
3. 앱을 휴지통으로 옮깁니다.

설정한 연결은 macOS에 남습니다.
