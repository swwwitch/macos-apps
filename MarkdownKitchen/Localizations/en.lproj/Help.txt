MarkdownKitchen shows your Markdown source on the left and only its headings on the right.

## How to Use

- The Format popup starts with HTML→Markdown and Minify HTML. Convert Back to Plain Markdown in the Doorkeeper menu uses the same conversion.
- Settings > Hotkeys supports Tools commands and individual Doorkeeper themes. New items have no default keys.
- Tools > Markdown → Plain Text opens a dialog with the selection or the whole document. Configure links, lists, headings and tables, then copy or save as .txt. Options are remembered. Conversion runs locally and leaves the document unchanged.
### Add the source
1. Type or paste Markdown into Source on the left.
2. You can also load a file with File > Open File… (⌘O) or by dropping a .md file onto the left pane or the Dock icon.
3. Headings appears on the right, indented by level. It updates as you type.

### What counts as a heading
- "# Heading" (ATX) and text underlined with "===" or "---" (Setext) are headings.
- <h1> to <h6> at the start of a line (attributes such as style allowed) are also headings, up to the matching closing tag. Tags inside are removed for display. Headings nested in <div> and similar are not included.
- "#" inside code blocks (``` or ~~~), leading YAML front matter, and HTML comments is ignored.
- Click a heading on the right to select and show that line in the source.
- Use the checkboxes (# to #####) at the top of the right pane to choose which levels to extract. Level 6 (######) is not shown. Checkboxes for levels missing from the source are dimmed.

## Preview
- Switch the right pane with Headings | Preview at its top. The app starts in Preview. The preview shows the source as HTML and updates as you type.
- HTML at the start of a line (such as <h2 style="…">) is shown as is, so Doorkeeper headings appear in color.
- Clicking a link in the preview opens it in your browser. Images are loaded from the internet.
- Bare URLs (starting with https://, http:// or www.) also become links in the preview. Text wrapped in ~~ is shown with a strikethrough.
- Scrolling the source on the left scrolls the preview to the same place.
- GitHub-style tables (a | header | … | row followed by a |---|---| delimiter row) and HTML tables (<table>) are shown with borders. :---, :---: and ---: in the delimiter row align left, center and right.
- Code blocks are colored with highlight.js (the language after ``` is used, such as ```swift; otherwise it is detected). It is bundled, so nothing is downloaded. Copy HTML does not include the colors, only the language class.
- Copy HTML above the preview (also in the Edit menu) copies the whole HTML shown in the preview.

## Raising and Lowering Headings
- The raise and lower buttons on the Source bar on the left, or Tools > Change All Heading Levels > Raise One Level (⌘[) and Lower One Level (⌘]), remove or add one "#" for all headings in the source.
- They affect headings at every level, whatever is checked in the right pane. If text is selected in the source, only headings in the selection change.
- If a level 1 heading would be raised or a level 6 heading lowered, nothing changes and the reason is shown.
- Underlined (=== or ---) headings are rewritten with "#". For HTML headings only the tag number changes (<h2> to <h3> and so on). Undo (⌘Z) reverts the whole change.

## Reordering Sections
- Drag a heading in the heading list on the right to move its section (up to the next heading of the same or a higher level, including body text and subheadings) within the source.
- A section cannot be moved into itself. Undo (⌘Z) reverts the move.

## Tidying and Table of Contents
- Choose from Tidy on the Source bar or from the Tools menu in the menu bar (in Tools, they are in the Tidy submenu; the eight items above Apply All run together with it, and the items below it run only when chosen). Only the selection is changed if text is selected; otherwise the whole source. Code blocks are left alone.
- **Add Space After Marks**: adds a space where a mark runs into the text, as in “##Heading”, “-item” or “1.item” (→ “## Heading”, “- item”, “1. item”). Lines such as **bold**, *italic*, ---, “-5” or “1.5” are left alone.
- **Remove Leading Spaces**: removes leading spaces (including four or more), tabs and full-width spaces, including list indentation and whitespace-only lines. Fenced code blocks and <pre> are preserved. Applying bulleted or numbered lists also removes leading whitespace.
- **Change twitter.com to x.com**: replaces twitter.com (also with www. or mobile.) in URLs and text with x.com. Not included in Apply All.
- **Remove UTM Parameters**: removes parameters starting with utm_ (utm_source, utm_medium and so on) from URLs. Other parameters and anything after # are kept. Not included in Apply All.
- **Wrap in div Block**: converts the selected lines (or the whole text) from Markdown to HTML, wraps them in a gray box (<div style="background-color: #efefef; …">…</div>) and minifies the result into one line. The box's background, padding, corner radius and bottom margin can be changed in the Themes tab of Settings.
- **Remove Trailing Spaces**: two or more spaces that make a Markdown line break are kept as two when the next line has text.
- **Empty Whitespace-Only Lines**: lines with only spaces or tabs (including full-width spaces) become blank lines.
- **Collapse Blank Lines**, **Use “-” for List Markers** (* and +), **Make Letters and Digits Half-width** (full-width letters and digits only), **Remove Spaces Between Japanese and Latin** (half-width spaces between Japanese text and Latin letters or digits; inline code is left alone), **Apply All** (all eight).
- **Remove Blank Lines**: removes every blank line (including lines with only spaces or tabs). Code blocks are left alone. Not included in Apply All.
- **Minify HTML**: joins each HTML block (a run of lines starting with a tag, up to a blank line) into one line, removing line breaks and extra spaces, including spaces after “;” and “:” in style. Markdown and blocks containing <pre> or <textarea> are left alone. Not included in Apply All.
- **Add Blank Lines Between Blocks**: inserts a blank line where headings, paragraphs, lists, quotes, code, tables, HTML and rules touch without one (always around headings and rules). Lines of the same paragraph, list, quote or table, and code blocks, are left alone.
- **Hard Breaks to Paragraphs**: turns hard line breaks (two or more trailing spaces, a trailing \, or <br>) and plain line breaks between paragraph lines into separate paragraphs with blank lines. Lists, quotes, tables, headings, code blocks and lines starting with an HTML tag are not split.
- **Remove Line Breaks**: joins the lines within each paragraph. A space is added where both sides are Latin letters, digits or ASCII punctuation; Japanese text is joined directly. Blank lines and code blocks are kept.
- **Delete Duplicate Lines**: keeps only the first of identical lines (order kept, blank lines untouched). **Sort Lines (Ascending / Descending)**: sorts lines with numbers in natural order (2 before 10). With a selection, the whole lines it touches are used. Neither is part of Apply All.
- **Insert Table of Contents**: builds a bulleted list from the headings at the checked levels and inserts it at the cursor.
- **Rewrite to Length…**: rewrites the selected text to about the target number of characters (counted without markup, tags and line breaks, as at the bottom left). Choose it from the Tools menu or the right-click menu. It uses the Apple Intelligence model on this Mac, so your text is not sent anywhere (macOS 26 or later with Apple Intelligence on). If the result is more than 10% off, it tries up to three times and shows the closest one. You can edit the result before choosing Replace, and undo with ⌘Z.
- **HTML Link…**: enter a URL and text to insert <a href="URL">text</a>. The selected text goes into Text (and into URL if it is a URL). A URL on the clipboard is filled in as the URL.
- Undo (⌘Z) reverts any of these.

## HTML to Markdown
- HTML→Markdown in Tidy on the Source bar on the left (also in the Tools menu) rewrites HTML mixed into the source as Markdown.
- Headings, paragraphs, line breaks, bold, italic, links, images, lists, quotes, code and rules are converted; other tags (span, div and so on) are removed and their contents kept.
- Markdown and code blocks (``` or ~~~) are left as they are. If text is selected, only the selection is converted. Undo (⌘Z) reverts it.
- With Ignore inside div elements and Ignore inside table elements on in the HTML→Markdown tab of Settings (both on by default), everything inside those elements, including nested ones, stays as HTML.

## Format for Doorkeeper
- Click Format for Doorkeeper on the Source bar (also in the Tools menu) and choose a theme (CSS Nite and DTP Transit by default) to replace ## and ### in the source with styled HTML headings (<h2 style="…"> and <h3 style="…">) for Doorkeeper event descriptions.
- The theme used last is checked. Add or delete themes in the Themes tab of Settings (Edit Themes… in the menu): a name, a base color (hex such as #0AF; click the swatch for the color panel) and the h3 background strength (%). h2 gets white text on the base color; h3 gets base-color text and rules on a light background.
- Headings already formatted with a theme (the same <h2 style="…"> / <h3 style="…"> decoration in another color) switch to the chosen theme without going back to Markdown. #### and deeper headings, body text, code blocks and HTML headings with other styles are not changed.
- If text is selected, only the selection is converted. Undo (⌘Z) reverts it, and HTML→Markdown turns the headings back into Markdown.

## Text Size
- The Smaller Text and Bigger Text buttons in the header, or View > Bigger Text (⌘+), Smaller Text (⌘−) and Default Text Size, change the text size of both panes. The size is kept for next time.

## Format
Choose from the Format menu in the menu bar or from the source’s right-click menu. Undo (⌘Z) reverts any of them.
- **Bold** (⌘B), **Italic** (⌘I), **Inline Code** (⌘E), **Strikethrough** (⇧⌘X, <s>…</s>), **Underline** (⌘U, <u>…</u>), **Comment** (⇧⌘M or ⌥⌘M, <!-- -->): wrap the selected text; choosing again removes the marks. With no selection, the marks are inserted with the cursor between them.
- **Heading 1–6 and Paragraph** (under Structure in the right-click menu): turn the paragraph at the cursor (all selected lines) into **Heading 1–6** (⌥⌘1–⌥⌘4; keys for Headings 5 and 6 can be set in Hotkeys) or a **Paragraph** (⌥⌘0, removes the “#”).
- **Ordered List** (⇧⌘7 or ⌥⌘5), **Unordered List** (⇧⌘8 or ⌥⌘6), **Blockquote** (⇧⌘9): toggle the paragraph at the cursor; if it already has that form, it is turned back. **Fenced Code Block** (⌥⌘8): wraps the selected lines (or the current line) in ```; choosing again removes the fences.
- **Shift Right** (⌥⌘]) and **Shift Left** (⌥⌘[): move the selected lines by two spaces.
- **Move Paragraph Up** (⌃⇧↑) and **Move Paragraph Down** (⌃⇧↓): swap the paragraph at the cursor (a block separated by blank lines; all selected paragraphs) with the one before or after. The blank lines between stay in place.
- **Link** (⌘K) and **Image** (⇧⌘I): make the selection [text](https://) with “https://” selected; a selected URL becomes [](URL).
- **Horizontal Rule**: inserts --- after the current line (or on it, if blank), with blank lines around it. Assign a key in the Hotkeys tab of Settings.
- **New Paragraph** (⌘↩): starts a new paragraph after a blank line below the current line.
- **Copy HTML** (⌥⌘C, in the Edit menu and the right-click menu): copies the whole HTML shown in the preview.
- **Return**: on a list line (-, *, +, 1., and task items - [ ]) or a quote (>), the next line gets the same marker (the next number for ordered lists). On an empty item the marker is removed and the list ends. An indented line continues with the same indent. Inside code blocks Return is a plain line break.
- **Tab** / **⇧Tab**: on list lines or a multi-line selection, shift right / left.

## Find and Replace
- Edit > Find > **Find and Replace…** (⌘F) shows the find and replace fields above the source. With text selected (within one line), that text becomes the search. Matches are highlighted in yellow with a count (such as 3 / 12).
- Press Return in the search field, or use **Find Next** (⌘G) and **Find Previous** (⇧⌘G), to step through matches; the search wraps around.
- **Match Case** (the Aa button): treat uppercase and lowercase as different.
- **Regular Expression** (the .* button): search with a regular expression; use $1 or \1 in the replacement ($0 is the whole match). An invalid pattern shows “Invalid pattern”.
- **Replace** (Return in the replace field): replaces the selected match and finds the next. **Replace All**: replaces every match. Undo (⌘Z) reverts either.
- The **@** menu beside the search field inserts **Line Break** (\n), **Tab** (\t) and **Blank Line** (^[ \t]*\n; an empty replacement deletes blank lines) and turns on regular expressions. The **@** menu beside the replace field inserts **Found Text** ($0) and **Found Text 1–5** ($1–$5) when regular expressions are on.
- **Done** (Esc) closes the bar. **Use Selection for Find** (⌘E) makes the selection the search; **Jump to Selection** (⌘J) scrolls back to the cursor or selection.
- Find keys can also be changed in the Hotkeys tab of Settings.

## Copying
- Choose a format in the pop-up at the top of the right pane (Markdown (# Heading), Markdown (blank line where the level changes), Tree (└ Heading), Simple Table of Contents or Text indented with tabs); the list then looks like that format.
- **Simple Table of Contents**: numbers the top-level headings “1. ”, “2. ”… and indents deeper headings with full-width spaces, without markers.
- Copy, or Edit > Copy Headings (⇧⌘C), copies all headings exactly as the list shows them.
- Right-click a heading for **Show in Source** and **Copy This Heading**.

## Source Display
- Choose in the View menu.
- **Source colors**: Auto (follows the system) / Light / Dark, for the source pane only.
- **Source style**: **MacDown style** (larger bold headings by level; colors for headings, links, emphasis, code, quotes and list markers; proportional font; the default) / **Colored** (fixed-width with colors) / **Plain** (fixed-width, no styling). HTML headings such as <h2> count as headings; nothing inside <div> or <table> is colored.
- **Show headings in bold**: used with Colored.
- **Source Font…**: uses the font and size chosen in the Fonts panel for the source pane (code stays fixed-width). **Use Default Font** goes back (the system font for MacDown style, fixed-width for Colored and Plain).
- **Line Spacing**: 1.1–1.5, the line height of the source pane (1.2 by default; the preview is unchanged).
- **Margins**: Narrow / Standard / Wide, for both the source pane and the preview.

## Settings
Open with the Settings button in the main window (⌘,).
- **Startup & Background**: Open at login, Hide main window at startup, Hide from Dock and App Switcher (keeps the app out of the Dock and ⌘Tab even with a window open; show it from the menu bar icon or by opening the app again in Finder), Show in menu bar
- **Hotkeys**: change the keys for format, convert, paragraph and heading commands . Click Change… and press keys that include ⌘ or ⌃ (Esc cancels). Reset to Default, Clear (no key; shown as None) and Reset All below are also available. Standard keys such as ⌘C, the app’s standard keys and keys used by another item cannot be assigned. The keys work only while MarkdownKitchen is in front
- **HTML→Markdown**: Ignore inside div elements, Ignore inside table elements (both on by default)
- **Right-Click**: choose which format items appear in the source’s right-click menu (all by default)
- **Themes**: Themes for Format for Doorkeeper (name, base color, h3 background strength)
- **Sharing**: export the editor display, heading copy format, hotkeys, HTML→Markdown, themes and right-click settings to a file and import it on another Mac (Add adds only themes you do not have yet; Replace uses the file’s settings). Set a folder in iCloud Drive, Dropbox or similar as the sync folder to keep several Macs in step automatically. The source text, the open file, open at login, the startup window and the menu bar stay on each Mac.

## Permissions
- No Accessibility or other permissions are needed.
- Files are written only when you choose Save or Save As…. The app does not use the network.

## Keeping the source
- The source on the left is kept by the app and comes back at the next launch.
- Replacing the source by loading a file can be undone with Undo (⌘Z).
- File > Save (⌘S) overwrites the loaded file; with no file loaded it works as Save As…. Save As… (⇧⌘S) writes to a file you choose, and later ⌘S saves there.
- File > New (⌘N) clears the source and removes the link to the file. If there are unsaved changes, you are asked whether to save them. You can undo the clearing with ⌘Z.
- File > New Window (⌃⌘N) opens a window with its own source. The source, the link to a file and Find are separate for each window. Menu commands and keys act on the front window. Windows left open when you quit open again at the next launch (if “Close windows when quitting an application” is on in System Settings > Desktop & Dock, their source is discarded as when you close them). Closing one discards its source (if there are unsaved changes, you are asked whether to save them). The main window works the same way: closing it discards its source and the link to its file, so it opens with an empty source next time (quitting treats it like a new window).
- While the source is linked to a file, its name and folder appear below the Source bar. With unsaved changes it shows “Unsaved” and the close button shows a dot. Show in Finder reveals the file; Unlink keeps the source and removes the link (⌘S then works as Save As…).
- The previous content is backed up before each overwrite in ~/Library/Application Support/MarkdownKitchen/Backups (latest 20); File > Show Backups Before Overwrite opens it. If another app changed the file after it was loaded, you are asked before it is overwritten.
- The file keeps the encoding it was loaded with (UTF-8 if some characters cannot be represented).

## Launching and Quitting
- Closing the window does not quit the app. Click the Dock icon or press ⌘0 to show the main window again.
- With Show in menu bar on, the menu bar icon also offers Open Main Window, Settings… and Help.
- To quit, choose Quit MarkdownKitchen (⌘Q) from the app menu.
- Choose Check for Updates… in the app menu to look for a new version. Until distribution is set up, it shows that updates are being prepared and does not connect.

## Troubleshooting
- If a heading is missing, check that "#" is followed by a space and that its level is checked in the right pane.
- If text is garbled, save the file as UTF-8 and load it again.
