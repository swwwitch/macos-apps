MarkdownKitchen 在左侧显示 Markdown 原稿，在右侧只显示其中的标题。

## 使用方法

- 整理弹出菜单顶部为HTML→Markdown和HTML压缩。Doorkeeper的还原为纯Markdown使用相同转换。
- 快捷键设置也支持工具命令和各个Doorkeeper主题。新增项目默认未设置快捷键。
- Markdown → 纯文本在对话框中读取选区，未选择时读取全文。可设置链接、列表、标题和表格，再复制或保存为.txt。选项会保存，在本机转换，不修改原稿。
### 放入原稿
1. 在左侧“原稿”中输入或粘贴 Markdown。
2. 也可以通过“文件”菜单的“打开文件…”（⌘O），或将 .md 文件拖到左侧窗格或 Dock 图标上来载入。
3. 右侧“标题”会按级别缩进显示原稿中的标题，并随输入即时更新。

### 标题的判定
- “# 标题”（ATX）以及用“===”“---”下划线标记的文本（Setext）视为标题。
- 行首的 <h1>–<h6>（可带 style 等属性）直到对应的结束标签也视为标题。显示时去掉其中的标签。<div> 等内部的标题不在对象范围内。
- 代码块（```、~~~）、开头的 YAML 前置元数据和 HTML 注释中的“#”不视为标题。
- 点按右侧的标题，会在左侧原稿中选中并显示该行。
- 用右侧窗格顶部的复选框（# 至 #####）选择要提取的级别。不显示 6 级标题（######）。原稿中没有的级别，其复选框显示为灰色。

## 预览
- 用右侧窗格顶部的“标题｜预览”切换显示。启动时为预览。预览将原稿转换为 HTML 显示，并随输入更新。
- 行首的 HTML（如 <h2 style="…">）按原样显示，因此 Doorkeeper 用的标题也以颜色显示。
- 点按预览中的链接会在浏览器中打开。图像从互联网载入。
- 仅为网址的文本（以 https://、http:// 或 www. 开头）在预览中也会自动成为链接。用 ~~ 包围的文字显示为删除线。
- 滚动左侧原稿时，预览也会移到相同位置。
- GitHub 写法的表格（| 标题 | … | 下一行为 |---|---| 分隔行）和 HTML 表格（<table>）显示边框。分隔行中的 :---、:---:、---: 分别表示左对齐、居中、右对齐。
- 代码块用 highlight.js 着色（写 ```swift 等语言名时按该语言，否则自动判断。已内置于 App，不会联网）。“拷贝 HTML”不含着色，只带语言的 class。
- 点按预览上方的“拷贝 HTML”（“编辑”菜单中也有），拷贝与预览相同的完整 HTML。

## 批量升降标题级别
- 点按左侧“原稿”栏中的升级、降级按钮，或选择“工具”菜单“更改标题级别（全部）”中的“升一级”（⌘[）、“降一级”（⌘]），将原稿中标题的“#”统一减少或增加一个。
- 对象是所有级别的标题，与右侧窗格的勾选无关。如果在原稿中选择了范围，则只更改其中的标题。
- 如果会把 1 级标题升级或把 6 级标题降级，则不做更改并显示原因。
- 下划线（===、---）形式的标题会改写为“#”形式。HTML 标题只更改标签中的数字（如 <h2>→<h3>）。可用撤销（⌘Z）一次恢复。

## 调整章节顺序
- 在右侧标题列表中拖移标题，即可在原稿中移动该标题的章节（直到下一个同级或更高级标题之前，包括正文和下级标题）。
- 不能移到自身章节内。可用撤销（⌘Z）恢复。

## 整理与目录
- 从左侧“原稿”栏的“整理”或菜单栏的“工具”中选择（在“工具”中位于“整理”子菜单；“全部整理”上方的八项可一起执行，下方的项目不包含在其中，仅在选择时执行）。如有选择则只处理所选部分，否则处理全文。代码块内不做更改。
- **删除行首空格**：删除包括四个以上空格、制表符和全角空格在内的行首空白，也处理列表缩进和仅含空白的行。保留围栏代码块和 <pre> 内的内容。设置项目符号或编号列表时也删除行首空白。
- **删除行尾空格**：构成 Markdown 换行的两个以上空格，若下一行是正文则统一保留两个。
- **清空仅含空白的行**：将只有空格或制表符（包括全角空格）的行改为空行。
- **在符号后加空格**：在“##标题”“-项目”“1.项目”这样符号与文字相连的行中加入半角空格（“## 标题”“- 项目”“1. 项目”）。**粗体**、*斜体*、---、“-5度”、“1.5倍”之类的行不变。
- **将连续空行合并为一行**、**列表符号统一为“-”**（* 和 +）、**字母和数字改为半角**（仅全角字母和数字）、**删除日文与西文之间的空格**（日文与半角字母数字之间的半角空格，行内代码不变）、**全部整理**（以上八项）。
- **将 twitter.com 改为 x.com**：把网址等中的 twitter.com（包括 www. 和 mobile.）改为 x.com。不包含在“全部整理”中。
- **删除 utm 参数**：删除网址中以 utm_ 开头的参数（utm_source、utm_medium 等）。其他参数和 # 之后的部分保留。不包含在“全部整理”中。
- **用 div 块包围**：将所选行（未选择时为全文）的 Markdown 转为 HTML，用灰色框（<div style="background-color: #efefef; …">…</div>）包围，并 Minify 为一行。框的背景色、内边距、圆角和下边距可在设置的“主题”标签中更改。
- **删除空行**：删除所有空行（包括只有空格或制表符的行）。代码块内保留。不包含在“全部整理”中。
- **压缩 HTML**：将以标签开头的 HTML 块（直到空行）中的换行和空格压缩为一行，也会去掉标签内多余的空格以及 style 中“; ”“: ”后的空格。Markdown 部分和包含 <pre>、<textarea> 的块不做更改。不包含在“全部整理”中。
- **在元素之间插入空行**：在标题、段落、列表、引用、代码、表格、HTML、分隔线之间没有空行的地方插入空行（标题和分隔线前后都插入）。同一段落、列表、引用、表格的各行之间及代码块内不插入。
- **强制换行改为分段**：将行尾两个以上空格、行尾的 \、<br> 形成的强制换行以及段落文字之间的普通换行改为用空行分隔的段落。列表、引用、表格、标题、代码块和以 HTML 标签开头的行不拆分。
- **删除换行**：连接段落内的各行。前后均为英文字母、数字或英文符号时插入一个半角空格，日文之间直接连接。保留空行和代码块。
- **删除重复行**：相同内容的行只保留第一行（顺序不变，空行除外）。**排序（升序／降序）**：按考虑数字的顺序（2 在 10 之前）排序各行。如有选择，则以所选涉及的整行为对象。两者均不包含在“全部整理”中。
- **插入目录**：用右侧列表中勾选级别的标题生成项目符号目录，插入到光标位置。
- **按字数改写…**：将所选文本改写为接近目标字数（与左下角相同，不计符号、标签和换行）。可从“工具”菜单或右键菜单中选择。使用本机的 Apple 智能模型，原稿不会发送到外部（需 macOS 26 或更高版本并打开 Apple 智能）。偏差超过一成时最多重试三次，并显示最接近的结果。可先修改结果再“替换”，也可用 ⌘Z 撤销。
- **HTML 链接…**：输入链接地址和文本，插入 <a href="链接地址">文本</a>。所选文字会填入“文本”（若所选为网址，也填入链接地址）。剪贴板中有网址时会预先填入链接地址。
- 均可用撤销（⌘Z）恢复。

## HTML→Markdown
- 选择左侧“原稿”栏“整理”（菜单栏的“工具”中也有）中的“HTML→Markdown”，将原稿中混入的 HTML 改写为 Markdown。
- 转换标题、段落、换行、粗体、斜体、链接、图像、列表、引用、代码和分隔线；其他标签（span、div 等）会被去掉并保留内容。
- Markdown 部分和代码块（```、~~~）内不做更改。如有选择，则只转换所选部分。可用撤销（⌘Z）恢复。
- 设置的“HTML→Markdown”标签页中的“忽略 div 元素内部”“忽略 table 元素内部”（均默认开启）开启时，这些元素内部（包括嵌套）保持为 HTML。

## 为 Doorkeeper 整理格式
- 点按左侧“原稿”栏的“为 Doorkeeper 整理格式”（菜单栏的“工具”中也有）并选择主题（默认为 CSS Nite 和 DTP Transit），将原稿中的 ## 和 ### 替换为 Doorkeeper 活动说明用的带样式 HTML 标题（<h2 style="…">、<h3 style="…">）。
- 上次使用的主题带有勾号。主题可在设置的“主题”标签页（菜单中的“编辑主题…”）中添加或删除：名称、基本颜色（如 #0AF 的十六进制，点按色块可打开颜色面板）和 h3 背景浓度（%）。h2 为基本颜色背景加白字，h3 为基本颜色的文字和线条加浅色背景。
- 已用主题整理过的标题（仅颜色不同、装饰相同的 <h2 style="…">、<h3 style="…">）无需改回 Markdown，会直接换成所选主题的颜色。#### 及更深的标题、正文、代码块和其他样式的 HTML 标题不做更改。
- 如有选择，则只转换所选部分。可用撤销（⌘Z）恢复，也可用 HTML→Markdown 改回 Markdown 标题。

## 文字大小
- 点按标题栏的“缩小文字”“放大文字”按钮，或选择“显示”菜单的“放大文字”（⌘+）、“缩小文字”（⌘−）、“默认文字大小”，更改左右窗格的文字大小。大小会保留到下次。

## 格式
从菜单栏的“格式”或原稿的右键菜单中选择。均可用撤销（⌘Z）恢复。
- **粗体**（⌘B）、**斜体**（⌘I）、**行内代码**（⌘E）、**删除线**（⇧⌘X，<s>…</s>）、**下划线**（⌘U，<u>…</u>）、**注释**（⇧⌘M 或 ⌥⌘M，<!-- -->）：包围所选文字；再次选择则去掉。未选择时插入符号并将光标置于其间。
- **标题 1–6、段落**（右键菜单中在“结构”里）：将光标所在段落（所选的所有行）改为**标题 1–6**（⌥⌘1–⌥⌘4；标题 5、6 的按键可在“快捷键”中指定）或**段落**（⌥⌘0，去掉“#”）。
- **编号列表**（⇧⌘7 或 ⌥⌘5）、**项目符号列表**（⇧⌘8 或 ⌥⌘6）、**引用**（⇧⌘9）：切换光标所在段落；已是该形式则恢复。**代码块**（⌥⌘8）：用 ``` 包围所选行（无选择时为光标所在行），已包围则去掉。
- **增加缩进**（⌥⌘]）、**减少缩进**（⌥⌘[）：将所选行移动两个半角空格。
- **段落上移**（⌃⇧↑）、**段落下移**（⌃⇧↓）：将光标所在段落（以空行分隔的块；如有选择则为所选段落）与前后段落交换。中间的空行保持不变。
- **链接**（⌘K）、**图像**（⇧⌘I）：将所选文字改为 [文字](https://) 并选中“https://”；若选中的是 URL 则改为 [](URL)。
- **水平线**：在当前行之后（若为空行则在该行）插入 ---，前后以空行分隔。可在设置的“快捷键”中指定按键。
- **新段落**（⌘↩）：在当前行后空一行开始新段落。
- **拷贝 HTML**（⌥⌘C，位于“编辑”菜单和右键菜单）：拷贝与预览相同的完整 HTML。
- **Return**：在列表（-、*、+、1.，以及任务项 - [ ]）或引用（>）行中，下一行会加上相同的符号（编号列表为下一个数字）。在空项目上按下会去掉符号并结束列表。缩进的行会以相同缩进开始下一行。代码块内为普通换行。
- **Tab**／**⇧Tab**：在列表行或多行选择时增加／减少缩进。

## 查找和替换
- 选择“编辑”菜单“查找”中的**查找和替换…**（⌘F），在原稿上方显示查找和替换栏。若先选择文字（一行之内）再打开，会直接查找该文字。匹配处以黄色显示，并显示数量（如 3 / 12）。
- 在查找栏中按 Return，或使用**查找下一个**（⌘G）、**查找上一个**（⇧⌘G）依次选择匹配处；到末尾后回到开头。
- **区分大小写**（Aa 按钮）：开启后将大写和小写视为不同。
- **正则表达式**（.* 按钮）：开启后用正则表达式查找；替换栏中可用 $1 或 \1 引用匹配的组（$0 为整个匹配）。写法不正确时显示“正则表达式无效”。
- **替换**（在替换栏中按 Return）：替换当前所选的一处并查找下一处。**全部替换**：替换所有匹配处。均可用撤销（⌘Z）恢复。
- 查找栏右侧的 **@** 可插入**换行**（\n）、**制表符**（\t）、**空行**（^[ \t]*\n；替换为空即可删除空行），选择后会开启正则表达式。替换栏右侧的 **@** 在使用正则表达式时可插入**找到的文本**（$0）和**查找结果 1–5**（$1–$5）。
- **完成**（Esc）关闭查找栏。**使用所选内容查找**（⌘E）将所选文字设为查找内容，**跳到所选内容**（⌘J）滚动回光标或所选位置。
- 查找的按键也可在设置的“快捷键”中更改。

## 拷贝
- 在右侧窗格顶部的弹出菜单中选择格式（Markdown（# 标题）、Markdown（级别变化处加空行）、树形（└ 标题）、简洁目录、用制表符缩进的文本），列表会以该格式显示。
- **简洁目录**：最上层标题加“1. ”“2. ”编号，更深的标题不加符号，用全角空格缩进。
- 点按“拷贝”或选择“编辑”菜单的“拷贝标题”（⇧⌘C），按列表当前显示的格式拷贝全部标题。
- 右键点按标题，可选择**在原稿中显示**、**拷贝此标题**。

## 原稿显示
- 在“显示”菜单中选择。
- **原稿配色**：自动（跟随系统）／浅色／深色，仅作用于左侧原稿栏。
- **原稿显示**：**MacDown 风格**（按级别放大并加粗标题，为标题、链接、强调、代码、引用、列表符号着色，非等宽字体；默认）／**着色**（等宽并着色）／**纯文本**（等宽、无修饰）。<h2> 等 HTML 标题也视为标题，<div>、<table> 内部不着色。
- **以粗体显示标题**：用于“着色”。
- **原稿字体…**：将字体面板中选择的字体和大小用于原稿栏（代码仍为等宽）。**恢复默认字体**可还原（MacDown 风格为系统字体，着色、纯文本为等宽）。
- **行距**：1.1–1.5，原稿栏的行高（默认 1.2；预览不变）。
- **边距**：窄／标准／宽，同时作用于原稿栏和预览。

## 设置
点按主窗口的“设置”按钮（⌘,）打开。
- **启动与后台**：登录时打开、启动时不显示主窗口、不在程序坞和应用程序切换器中显示（开启后即使窗口打开也不会出现在程序坞和 ⌘Tab 中；可通过菜单栏图标或在访达中再次打开应用来显示）、在菜单栏中显示
- **快捷键**：更改格式、转换、段落和标题操作的按键。点按“更改…”，然后按下包含 ⌘ 或 ⌃ 的按键（按 Esc 取消）。也可以使用“恢复默认”“清除”（无按键，显示为“未设置”）和下方的“全部恢复默认”。⌘C 等标准按键、App 标准按键或其他项目已使用的按键不能指定。这些按键仅在 MarkdownKitchen 位于最前面时有效
- **HTML→Markdown**：忽略 div 元素内部、忽略 table 元素内部（均默认开启）
- **右键**：选择原稿右键菜单中显示的格式项目（默认全部显示）
- **主题**：为 Doorkeeper 整理格式的主题（名称、基本颜色、h3 背景浓度）
- **设置共享**：可将原稿显示、标题复制格式、快捷键、HTML→Markdown、主题和右键菜单的设置导出为文件，并在其他 Mac 上导入（“添加”只加入尚未有的主题，“替换”改为文件中的设置）。将 iCloud 云盘、Dropbox 等中的文件夹设为同步文件夹后，多台 Mac 会自动保持一致。原稿和打开的文件、登录时打开、启动时的窗口和菜单栏在每台 Mac 上分别保留。

- **⌘0**：打开主窗口
- **⌘,**：设置
- **⌘W**：关闭窗口
- **⌘?**：MarkdownKitchen 帮助
- **⌘Q**：退出 MarkdownKitchen

## 权限
- 不需要辅助功能等权限。
- 只有选择“存储”或“存储为…”时才会写入文件。App 不进行网络通信。

## 原稿的保存
- 左侧原稿由 App 保存，退出后下次启动时会恢复。
- 载入文件替换的原稿可以用撤销（⌘Z）恢复。
- “文件”菜单的“存储”（⌘S）会覆盖载入的文件；未载入文件时相当于“存储为…”。“存储为…”（⇧⌘S）存储到所选文件，之后的 ⌘S 会覆盖该文件。
- “文件”菜单的“新建”（⌘N）会清空原稿并取消与文件的关联。有未存储的更改时会询问是否存储。清空的原稿可用“撤销”（⌘Z）恢复。
- “文件”菜单的“新建窗口”（⌃⌘N）会打开拥有另一份原稿的窗口。原稿、与文件的关联和查找在每个窗口中分别保留。菜单和按键的操作作用于最前面的窗口。退出时仍打开的窗口会在下次启动时重新打开（如果在“系统设置”>“桌面与程序坞”中打开了“退出 App 时关闭窗口”，则与关闭窗口时一样丢弃原稿）。关闭后原稿会被丢弃（有未存储的更改时会询问是否存储）。主窗口也一样，关闭后原稿和与文件的关联会被丢弃，下次打开时为空白原稿（退出时的处理与新窗口相同）。
- 与文件关联时，“原稿”栏下方会显示文件名和位置。有未存储的更改时会显示“未保存”，关闭按钮上会显示圆点。点按“在访达中显示”可显示文件，点按“取消关联”会保留原稿并取消关联（之后 ⌘S 相当于“存储为…”）。
- 每次覆盖前的内容会备份到 ~/Library/Application Support/MarkdownKitchen/Backups（最新 20 个），可通过“文件”菜单的“显示覆盖前的备份”打开。如果载入后文件被其他 App 更改，覆盖前会先确认。
- 使用载入时的文本编码存储（若有无法表示的字符则使用 UTF-8）。

## 启动与退出
- 关闭窗口不会退出 App。点按 Dock 图标或按 ⌘0 可再次显示主窗口。
- 打开“在菜单栏中显示”后，也可以从菜单栏图标选择“打开主窗口”“设置…”“帮助”。
- 要退出，请从 App 菜单选择“退出 MarkdownKitchen”（⌘Q）。
- 在 App 菜单中选择“检查更新…”可查看新版本。在分发准备完成之前，会显示正在准备更新且不进行通信。

## 疑难解答
- 如果没有显示标题，请确认“#”后面有空格，以及右侧窗格中是否勾选了该级别。
- 如果出现乱码，请将文件另存为 UTF-8 后再载入。

## 帮助与 note 文章
- 通过“帮助”菜单的“MarkdownKitchen 帮助”（⌘?）打开此帮助。
- “帮助”菜单的“打开 note 文章”会在浏览器中打开 note 上的说明文章。

## 删除 App
1. 关闭“登录时打开”。
2. 选择“退出 MarkdownKitchen”。
3. 将 MarkdownKitchen 移到废纸篓。
