MarkdownKitchen은 왼쪽에 Markdown 원고를, 오른쪽에 제목만 뽑아 표시하는 앱입니다.

## 사용 방법
### 원고 넣기
1. 왼쪽 '원고'에 Markdown을 입력하거나 붙여넣습니다.
2. 파일 메뉴의 '파일 열기…'(⌘O) 또는 .md 파일을 왼쪽 패널이나 Dock 아이콘에 드롭해도 불러올 수 있습니다.
3. 오른쪽 '제목'에 원고의 제목이 수준에 맞춰 들여쓰기되어 표시됩니다. 입력하는 대로 바로 갱신됩니다.

### 제목으로 보는 것
- '# 제목'(ATX)과 '===' '---' 밑줄(Setext)을 제목으로 다룹니다.
- 줄 맨 앞의 <h1>~<h6>(style 등의 속성 포함 가능)도 대응하는 닫는 태그까지 제목으로 다룹니다. 안쪽 태그는 빼고 표시합니다. <div> 등의 안에 있는 것은 대상이 아닙니다.
- 코드 블록(```, ~~~), 맨 앞의 YAML 프런트 매터, HTML 주석 안의 '#'은 제목으로 보지 않습니다.
- 오른쪽 제목을 클릭하면 왼쪽 원고에서 그 줄을 선택해 보여 줍니다.
- 오른쪽 패널 위쪽의 체크박스(# ~ #####)로 추출할 수준을 고릅니다. 제목 6(######)은 표시하지 않습니다. 원고에 없는 수준의 체크박스는 흐리게 표시됩니다.

## 미리보기
- 오른쪽 패널 위의 '제목 | 미리보기'로 표시를 전환합니다. 실행하면 미리보기로 시작합니다. 미리보기는 원고를 HTML로 바꿔 표시하고 입력에 맞춰 갱신합니다.
- 줄 맨 앞의 HTML(<h2 style="…"> 등)은 그대로 표시하므로 Doorkeeper용 제목도 색으로 확인할 수 있습니다.
- 미리보기의 링크를 클릭하면 브라우저에서 엽니다. 이미지는 인터넷에서 불러옵니다.
- URL만 있는 문자열(https://, http://, www.로 시작)도 미리보기에서 자동으로 링크가 됩니다. ~~로 감싼 글자는 취소선으로 표시합니다.
- 왼쪽 원고를 스크롤하면 미리보기도 같은 위치로 움직입니다.
- GitHub 방식의 표(| 제목 | … | 다음 줄에 |---|---| 구분 줄)와 HTML 표(<table>)를 괘선을 붙여 표시합니다. 구분 줄의 :---, :---:, ---:로 왼쪽·가운데·오른쪽 정렬이 됩니다.
- 코드 블록은 highlight.js로 색을 입힙니다(```swift처럼 언어 이름을 쓰면 그 언어, 없으면 자동 판단. 앱에 포함되어 있어 통신하지 않습니다). 'HTML 복사'에는 색이 들어가지 않고 언어의 class만 붙습니다.
- 미리보기 위의 'HTML 복사'(편집 메뉴에도 있음)로 미리보기와 같은 HTML 전체를 복사합니다.

## 제목 수준 일괄 올리기·내리기
- 왼쪽 '원고' 막대의 올리기·내리기 버튼 또는 도구 메뉴 '제목 수준 변경(전체)'의 '한 단계 올리기'(⌘[), '한 단계 내리기'(⌘])로 원고 제목의 '#'을 한꺼번에 하나 줄이거나 늘립니다.
- 대상은 오른쪽 패널의 체크와 관계없이 모든 수준의 제목입니다. 원고에서 범위를 선택했다면 그 안의 제목만 바뀝니다.
- 제목 1을 올리거나 제목 6을 내리게 되면 아무것도 바꾸지 않고 이유를 표시합니다.
- 밑줄(===, ---) 형식의 제목은 '#' 형식으로 고쳐 씁니다. HTML 제목은 태그의 숫자(<h2>→<h3> 등)만 바꿉니다. 실행 취소(⌘Z)로 한 번에 되돌릴 수 있습니다.

## 제목 단위로 순서 바꾸기
- 오른쪽 제목 목록에서 제목을 드래그하면 그 제목의 장(같거나 상위 수준의 다음 제목 전까지, 본문과 하위 제목 포함)을 원고 안에서 옮깁니다.
- 자기 장 안으로는 옮길 수 없습니다. 실행 취소(⌘Z)로 되돌릴 수 있습니다.

## 정리와 목차
- 왼쪽 '원고' 막대의 '정리' 또는 메뉴 막대의 '도구'에서 고릅니다('도구'에서는 '정리' 하위 메뉴에 있습니다. '모두 정리' 위의 여덟 항목은 한꺼번에 실행할 수 있고, 아래 항목은 포함하지 않고 고를 때만 실행합니다). 범위를 선택했다면 그 안만, 아니면 전체가 대상입니다. 코드 블록 안은 바꾸지 않습니다.
- **줄 앞 공백 삭제**: 네 칸 이상의 공백, 탭, 전각 공백을 포함하여 목록과 공백만 있는 줄의 앞 공백도 삭제합니다. 펜스 코드 블록과 <pre> 안은 유지합니다. 글머리 기호 및 번호 목록을 적용할 때도 앞 공백을 삭제합니다.
- **줄 끝 공백 삭제**: Markdown 줄바꿈이 되는 2개 이상의 공백은 다음 줄이 본문이면 2개로 맞춰 남깁니다.
- **공백만 있는 줄 비우기**: 공백이나 탭(전각 공백 포함)만 있는 줄을 빈 줄로 만듭니다.
- **기호 뒤에 공백 넣기**: '##제목', '-항목', '1.항목'처럼 기호와 글자가 붙은 줄에 반각 공백을 넣습니다('## 제목', '- 항목', '1. 항목'). **굵게**, *기울임*, ---, '-5도', '1.5배' 같은 줄은 바꾸지 않습니다.
- **연속된 빈 줄을 한 줄로**, **목록 기호를 '-'로 통일**(*와 +), **영숫자를 반각으로**(전각 영문자·숫자만), **일본어와 영문 사이 공백 삭제**(일본어와 반각 영숫자 사이의 반각 공백, 인라인 코드 안은 그대로), **모두 정리**(여덟 가지 모두).
- **twitter.com을 x.com으로**: URL 등의 twitter.com(www.·mobile. 포함)을 x.com으로 바꿉니다. '모두 정리'에는 포함하지 않습니다.
- **utm 매개변수 삭제**: URL에서 utm_source, utm_medium 등 utm_로 시작하는 매개변수를 지웁니다. 다른 매개변수와 # 뒤는 남깁니다. '모두 정리'에는 포함하지 않습니다.
- **div 블록으로 감싸기**: 선택한 줄(선택이 없으면 전체)의 Markdown을 HTML로 바꾸고 회색 상자(<div style="background-color: #efefef; …">…</div>)로 감싼 뒤 Minify해서 한 줄로 만듭니다. 상자의 배경색·안쪽 여백·모서리 둥글기·아래 여백은 설정의 '테마' 탭에서 바꿀 수 있습니다.
- **빈 줄 삭제**: 빈 줄(공백이나 탭만 있는 줄 포함)을 모두 지웁니다. 코드 블록 안은 남깁니다. '모두 정리'에는 포함하지 않습니다.
- **HTML 압축**: 태그로 시작하는 HTML 덩어리(빈 줄까지)의 줄바꿈과 공백을 줄여 한 줄로 만듭니다. 태그 안의 불필요한 공백과 style의 '; ', ': ' 뒤 공백도 줄입니다. Markdown 부분과 <pre>, <textarea>를 포함한 덩어리는 바꾸지 않습니다. '모두 정리'에는 포함되지 않습니다.
- **요소 사이에 빈 줄 넣기**: 제목, 단락, 목록, 인용, 코드, 표, HTML, 구분선이 빈 줄 없이 붙어 있는 곳에 빈 줄을 넣습니다(제목과 구분선은 앞뒤 모두). 같은 단락·목록·인용·표의 줄 사이와 코드 블록 안에는 넣지 않습니다.
- **강제 줄바꿈을 단락으로**: 줄 끝 공백 2개 이상, 줄 끝의 \, <br>에 의한 강제 줄바꿈과 단락 문장 사이의 보통 줄바꿈을 빈 줄로 나눈 단락으로 바꿉니다. 목록, 인용, 표, 제목, 코드 블록, 태그로 시작하는 HTML 줄은 나누지 않습니다.
- **줄바꿈 삭제**: 단락 안의 줄을 이어 붙입니다. 앞뒤가 모두 영문자·숫자·영어 기호이면 반각 공백을 하나 넣고, 일본어 경계는 붙입니다. 빈 줄과 코드 블록은 남깁니다.
- **중복 줄 삭제**: 같은 내용의 줄은 첫 줄만 남깁니다(순서 유지, 빈 줄 제외). **정렬(오름차순/내림차순)**: 숫자를 고려한 순서(2가 10보다 앞)로 줄을 정렬합니다. 선택했다면 그 범위에 걸친 줄 전체가 대상입니다. 둘 다 '모두 정리'에는 포함되지 않습니다.
- **목차 삽입**: 오른쪽 목록에서 체크한 수준의 제목으로 글머리표 목차를 만들어 커서 위치에 넣습니다.
- **글자 수를 지정해 다시 쓰기…**: 선택한 글을 목표 글자 수(왼쪽 아래와 같이 기호·태그·줄바꿈 제외)에 가깝게 다시 씁니다. 도구 메뉴나 오른쪽 클릭 메뉴에서 고릅니다. 이 Mac의 Apple Intelligence 모델을 쓰므로 원고를 외부로 보내지 않습니다(macOS 26 이상, Apple Intelligence가 켜져 있을 때). 목표와 10% 이상 차이 나면 세 번까지 다시 시도해 가장 가까운 결과를 보여 줍니다. 결과를 고친 뒤 [바꾸기]할 수 있고 ⌘Z로 되돌릴 수 있습니다.
- **HTML 링크…**: 링크 주소와 텍스트를 입력해 <a href="링크 주소">텍스트</a>를 넣습니다. 선택한 글자는 텍스트에 들어갑니다(선택이 URL이면 링크 주소에도). 클립보드에 URL이 있으면 링크 주소에 미리 넣습니다.
- 모두 실행 취소(⌘Z)로 되돌릴 수 있습니다.

## HTML→Markdown
- 왼쪽 '원고' 막대의 '정리'(메뉴 막대의 '도구'에도 있음)에서 'HTML→Markdown'으로 원고에 섞인 HTML을 Markdown 형식으로 바꿉니다.
- 제목, 단락, 줄바꿈, 굵게, 기울임, 링크, 이미지, 목록, 인용, 코드, 구분선을 변환하고, 그 밖의 태그(span, div 등)는 빼고 내용을 남깁니다.
- Markdown 부분과 코드 블록(```, ~~~) 안은 바꾸지 않습니다. 범위를 선택했다면 그 안만 변환합니다. 실행 취소(⌘Z)로 되돌릴 수 있습니다.
- 설정의 'HTML→Markdown' 탭에서 'div 요소 안은 무시', 'table 요소 안은 무시'(둘 다 기본값 켬)가 켜져 있으면 그 요소 안(중첩 포함)은 HTML 그대로 둡니다.

## Doorkeeper용으로 정리
- 왼쪽 '원고' 막대의 'Doorkeeper용으로 정리'(메뉴 막대의 '도구'에도 있음)를 클릭하고 테마(기본값은 CSS Nite와 DTP Transit)를 고르면 원고의 ##와 ###을 Doorkeeper 이벤트 설명용 스타일 HTML 제목(<h2 style="…">, <h3 style="…">)으로 바꿉니다.
- 지난번에 쓴 테마에는 체크가 붙습니다. 테마는 설정의 '테마' 탭(메뉴의 '테마 편집…')에서 추가·삭제합니다. 이름, 기본 색(#0AF 같은 16진수, 색 견본을 클릭하면 색상 패널), h3 배경 농도(%)를 정합니다. h2는 기본 색 배경에 흰 글자, h3은 기본 색 글자·선과 연한 배경이 됩니다.
- 테마로 이미 정리한 제목(색만 다르고 장식이 같은 <h2 style="…">, <h3 style="…">)은 Markdown으로 되돌리지 않고 고른 테마의 색으로 바꿉니다. #### 이하 제목, 본문, 코드 블록, 다른 장식의 HTML 제목은 바꾸지 않습니다.
- 범위를 선택했다면 그 안만 변환합니다. 실행 취소(⌘Z)로 되돌리거나 HTML→Markdown으로 Markdown 제목으로 되돌릴 수 있습니다.

## 글자 크기
- 머리글의 '글자 작게', '글자 크게' 버튼 또는 보기 메뉴의 '글자 크게'(⌘+), '글자 작게'(⌘−), '기본 글자 크기'로 좌우 패널의 글자 크기를 바꿉니다. 크기는 다음에도 유지됩니다.

## 서식
메뉴 막대의 '서식' 또는 원고의 오른쪽 클릭 메뉴에서 고릅니다. 모두 실행 취소(⌘Z)로 되돌릴 수 있습니다.
- **굵게**(⌘B), **기울임**(⌘I), **인라인 코드**(⌘E), **취소선**(⇧⌘X, <s>…</s>), **밑줄**(⌘U, <u>…</u>), **주석**(⇧⌘M 또는 ⌥⌘M, <!-- -->): 선택한 글자를 감쌉니다. 다시 고르면 해제합니다. 선택이 없으면 기호를 넣고 그 사이에 커서를 둡니다.
- **제목 1~6, 단락**(오른쪽 클릭 메뉴에서는 '구조' 안): 커서가 있는 단락(선택한 모든 줄)을 **제목 1~6**(⌥⌘1~⌥⌘4, 제목 5·6의 키는 '단축키'에서 지정) 또는 **단락**(⌥⌘0, '#' 제거)으로 바꿉니다.
- **번호 목록**(⇧⌘7 또는 ⌥⌘5), **글머리표 목록**(⇧⌘8 또는 ⌥⌘6), **인용**(⇧⌘9): 커서가 있는 단락을 전환합니다. 이미 그 형식이면 되돌립니다. **코드 블록**(⌥⌘8): 선택한 줄(선택이 없으면 커서가 있는 줄)을 ```로 감쌉니다. 이미 감싸져 있으면 해제합니다.
- **들여쓰기 늘리기**(⌥⌘]), **들여쓰기 줄이기**(⌥⌘[): 선택한 줄을 반각 공백 2개만큼 옮깁니다.
- **단락 위로 이동**(⌃⇧↑), **단락 아래로 이동**(⌃⇧↓): 커서가 있는 단락(빈 줄로 나뉜 덩어리, 선택했다면 그 범위의 단락)을 앞뒤 단락과 바꿉니다. 사이의 빈 줄은 그대로 둡니다.
- **링크**(⌘K), **이미지**(⇧⌘I): 선택한 글자를 [글자](https://) 형태로 만들고 'https://'를 선택합니다. URL을 선택했다면 [](URL)로 만듭니다.
- **가로줄**: 현재 줄 뒤(빈 줄이면 그 줄)에 ---를 넣고 앞뒤를 빈 줄로 나눕니다. 키는 설정의 '단축키'에서 지정할 수 있습니다.
- **새 단락**(⌘↩): 현재 줄 뒤에 빈 줄을 두고 새 단락을 시작합니다.
- **HTML 복사**(⌥⌘C, 편집 메뉴와 오른쪽 클릭 메뉴): 미리보기와 같은 HTML 전체를 복사합니다.
- **Return**: 목록(-, *, +, 1., 체크박스 - [ ] 포함)이나 인용(>) 줄에서는 다음 줄에 같은 기호(번호 목록은 다음 번호)를 붙입니다. 내용이 없는 항목에서 누르면 기호를 지우고 목록을 끝냅니다. 들여쓴 줄은 같은 들여쓰기로 다음 줄을 시작합니다. 코드 블록 안에서는 보통 줄바꿈입니다.
- **Tab** / **⇧Tab**: 목록 줄이나 여러 줄을 선택했을 때 들여쓰기를 늘리거나 줄입니다.

## 찾기 및 대치
- 편집 메뉴 '찾기'의 **찾기 및 대치…**(⌘F)로 원고 위에 찾기와 대치 칸을 표시합니다. 글자를 선택한 뒤(한 줄 안) 열면 그 글자를 찾습니다. 일치한 곳은 노란색으로 표시하고 개수(예: 3 / 12)를 보여 줍니다.
- 찾기 칸에서 Return 또는 **다음 찾기**(⌘G), **이전 찾기**(⇧⌘G)로 일치한 곳을 차례로 선택합니다. 끝까지 가면 처음으로 돌아갑니다.
- **대소문자 구분**(Aa 버튼): 켜면 대문자와 소문자를 다른 글자로 찾습니다.
- **정규 표현식**(.* 버튼): 켜면 정규 표현식으로 찾습니다. 대치 칸에서는 $1 또는 \1로 일치한 그룹을 쓸 수 있습니다($0은 일치 전체). 잘못된 표현식이면 '정규 표현식이 올바르지 않음'이 표시됩니다.
- **대치**(대치 칸에서 Return): 선택한 한 곳을 바꾸고 다음을 찾습니다. **모두 대치**: 일치한 곳을 모두 바꿉니다. 모두 실행 취소(⌘Z)로 되돌릴 수 있습니다.
- 찾기 칸 오른쪽의 **@**에서 **줄바꿈**(\n), **탭**(\t), **빈 줄**(^[ \t]*\n, 대치를 비우면 빈 줄을 지움)을 넣을 수 있습니다. 고르면 정규 표현식이 켜집니다. 대치 칸 오른쪽의 **@**에서는 정규 표현식일 때 **찾은 텍스트**($0), **찾은 결과 1~5**($1~$5)를 넣을 수 있습니다.
- **완료**(Esc)로 막대를 닫습니다. **선택 부분으로 찾기**(⌘E)는 선택한 글자를 찾을 말로 하고, **선택 부분으로 이동**(⌘J)은 커서나 선택 위치로 스크롤해 돌아갑니다.
- 찾기의 키도 설정의 '단축키'에서 바꿀 수 있습니다.

## 복사
- 오른쪽 패널 위의 팝업에서 형식(Markdown(# 제목), Markdown(수준이 바뀌는 곳에 빈 줄), 트리(└ 제목), 간단한 목차, 탭으로 들여쓴 텍스트)을 고르면 목록이 그 형식으로 보입니다.
- **간단한 목차**: 가장 상위 수준에 '1. ', '2. ' 번호를 붙이고, 더 깊은 제목은 기호 없이 전각 공백으로 들여씁니다.
- '복사' 또는 편집 메뉴의 '제목 복사'(⇧⌘C)로 목록에 표시 중인 형식 그대로 모든 제목을 복사합니다.
- 제목을 오른쪽 클릭하면 **원고에서 보기**, **이 제목 복사**를 선택할 수 있습니다.

## 원고 표시
- 보기 메뉴에서 고릅니다.
- **원고 배색**: 자동(시스템을 따름)/라이트/다크. 왼쪽 원고 칸에만 적용됩니다.
- **원고 표시**: **MacDown 스타일**(제목을 수준에 따라 크고 굵게, 제목·링크·강조·코드·인용·목록 기호 색 구분, 비고정폭 서체. 기본값)/**색 구분**(고정폭으로 색 구분)/**일반**(고정폭, 꾸밈 없음). <h2> 같은 HTML 제목도 제목으로 다루고 <div>, <table> 안은 색을 입히지 않습니다.
- **제목을 굵게 표시**: '색 구분'일 때 사용합니다.
- **원고 글꼴…**: 서체 패널에서 고른 글꼴과 크기를 원고 칸에 씁니다(코드는 고정폭 그대로). **기본 글꼴로 되돌리기**로 되돌립니다(MacDown 스타일은 시스템 글꼴, 색 구분·일반은 고정폭).
- **줄 간격**: 1.1~1.5. 원고 칸의 줄 높이를 바꿉니다(기본값 1.2, 미리보기는 그대로).
- **여백**: 좁게/표준/넓게. 원고 칸과 미리보기의 안쪽 여백을 바꿉니다.

## 설정
메인 윈도우의 '설정' 버튼(⌘,)으로 엽니다.
- **시작 및 백그라운드**: 로그인 시 열기, 시작할 때 메인 윈도우 숨기기, Dock 및 앱 전환기에 표시 안 함(켜면 윈도우가 열려 있어도 Dock과 ⌘Tab에 표시하지 않습니다. 메뉴 막대 아이콘이나 Finder에서 앱을 다시 열어 표시할 수 있습니다), 메뉴 막대에 표시
- **단축키**: 서식·변환·단락·제목 조작의 키를 변경합니다. ‘변경…’을 클릭하고 ⌘ 또는 ⌃를 포함한 키를 누릅니다(Esc로 취소). ‘기본값으로 되돌리기’, ‘지우기’(키 없음, ‘없음’으로 표시)와 아래의 ‘모두 기본값으로’도 쓸 수 있습니다. ⌘C 같은 표준 키, 앱의 기본 키, 다른 항목과 겹치는 키는 쓸 수 없습니다. 키는 MarkdownKitchen이 앞에 있을 때만 작동합니다
- **HTML→Markdown**: div 요소 안은 무시, table 요소 안은 무시(둘 다 기본값 켬)
- **오른쪽 클릭**: 원고의 오른쪽 클릭 메뉴에 표시할 서식 항목 선택(기본값은 모두 표시)
- **테마**: Doorkeeper용으로 정리의 테마(이름, 기본 색, h3 배경 농도)
- **설정 공유**: 원고 표시, 제목 복사 형식, 단축키, HTML→Markdown, 테마, 오른쪽 클릭 설정을 파일로 내보내 다른 Mac에서 가져올 수 있습니다(‘추가’는 아직 없는 테마만 더하고, ‘대치’는 파일의 설정으로 바꿉니다). iCloud Drive나 Dropbox 등의 폴더를 동기화 폴더로 설정하면 여러 Mac을 자동으로 맞춥니다. 원고와 열려 있는 파일, 로그인 시 열기, 시작 시 윈도우, 메뉴 막대는 Mac마다 남습니다.

## 권한
- 손쉬운 사용 등의 권한은 필요하지 않습니다.
- '저장' 또는 '다른 이름으로 저장…'을 고를 때만 파일에 씁니다. 네트워크 통신도 하지 않습니다.

## 원고 보관
- 왼쪽 원고는 앱에 보관되어 종료해도 다음 실행 때 돌아옵니다.
- 파일을 불러와 바뀐 원고는 실행 취소(⌘Z)로 되돌릴 수 있습니다.
- 파일 메뉴의 '저장'(⌘S)은 불러온 파일에 덮어씁니다. 불러온 파일이 없으면 '다른 이름으로 저장…'이 됩니다. '다른 이름으로 저장…'(⇧⌘S)은 고른 파일에 저장하고, 이후 ⌘S는 그 파일에 덮어씁니다.
- 파일 메뉴의 '새로 만들기'(⌘N)는 원고를 비우고 파일과의 연결도 해제합니다. 저장하지 않은 변경이 있으면 저장할지 묻습니다. 비운 원고는 실행 취소(⌘Z)로 되돌릴 수 있습니다.
- 파일 메뉴의 '새 윈도우'(⌃⌘N)는 별도의 원고를 가진 윈도우를 엽니다. 원고, 파일과의 연결, 찾기는 윈도우마다 따로 유지됩니다. 메뉴와 키 조작은 맨 앞의 윈도우에 적용됩니다. 종료할 때 열려 있던 윈도우는 다음 실행 시 다시 열립니다(시스템 설정 > 데스크탑 및 Dock에서 '앱 종료 시 윈도우 닫기'가 켜져 있으면 닫을 때와 마찬가지로 원고가 사라집니다). 닫으면 원고는 사라집니다(저장하지 않은 변경이 있으면 저장할지 묻습니다). 메인 윈도우도 마찬가지로 닫으면 원고와 파일과의 연결이 사라지고, 다음에 열면 빈 원고가 됩니다(종료할 때의 처리는 새 윈도우와 같습니다).
- 파일과 연결되어 있는 동안 '원고' 막대 아래에 파일 이름과 위치를 표시합니다. 저장하지 않은 변경이 있으면 '저장 안 됨'이 붙고 닫기 버튼에 점이 표시됩니다. 'Finder에서 보기'로 파일을 보여 주고, '연결 해제'로 원고는 남긴 채 연결을 해제합니다(이후 ⌘S는 '다른 이름으로 저장…').
- 덮어쓰기 전 내용은 ~/Library/Application Support/MarkdownKitchen/Backups에 백업합니다(최신 20개). 파일 메뉴의 '덮어쓰기 전 백업 보기'로 엽니다. 불러온 뒤 다른 앱에서 파일이 바뀌었으면 덮어쓰기 전에 확인합니다.
- 불러올 때의 문자 인코딩으로 저장합니다(표현할 수 없는 문자가 있으면 UTF-8).

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock 아이콘을 클릭하거나 ⌘0을 눌러 메인 윈도우를 다시 표시합니다.
- '메뉴 막대에 표시'를 켜면 메뉴 막대 아이콘에서도 '메인 윈도우 열기', '설정…', '도움말'을 선택할 수 있습니다.
- 종료하려면 앱 메뉴에서 'MarkdownKitchen 종료'(⌘Q)를 선택합니다.
- 앱 메뉴의 '업데이트 확인…'으로 새 버전을 확인합니다. 배포 준비가 끝날 때까지는 업데이트 준비 중으로 표시되며 통신하지 않습니다.

## 문제 해결
- 제목이 보이지 않으면 '#' 뒤에 공백이 있는지, 오른쪽 패널에서 그 수준이 체크되어 있는지 확인하십시오.
- 글자가 깨지면 파일을 UTF-8로 다시 저장한 뒤 불러오십시오.

## 도움말과 note 글

- 도움말 메뉴의 'note 글 열기'로 note의 해설 글을 브라우저에서 엽니다.
