# MarkdownKitchen

Markdownの整形・加工用のアプリです。左右2ペインで、左にオリジナルの原稿、右に見出しだけを抜き出したものを表示します。

- 左の原稿は Markdown を色分け（見出し・強調・リンク・コード・引用・リストの記号。HTMLの見出しも見出しとして扱い、<div>・<table> の中は色を付けない。[MarkdownSyntax.swift](Sources/MarkdownKitchen/MarkdownSyntax.swift)、設定「原稿の表示」：MacDown風（見出しをレベルに応じて大きく・色分け・等幅ではない書体）／色分け（等幅）／プレーン）。見出しの行を太字で表示（設定「見出しを太字で表示」、初期値オン）。入力・ペースト、ファイルメニューの「ファイルを開く…」（⌘O）、左ペインやDockアイコンへの .md ドロップで読み込み
- 右の見出しは入力に合わせてすぐに更新。クリックすると原稿の該当行を選択して表示
- ATX（`#`）・Setext（`===`・`---`）・行頭のHTML見出し（`<h1>`〜`<h6>`、属性付き可。上げ下げはタグの数字を変える）に対応。コードブロック・先頭のYAMLフロントマター・HTMLコメントの中は除外
- 「HTML→Markdown」で原稿に混ざったHTMLをMarkdownに変換（[HTMLToMarkdown.swift](Sources/MarkdownKitchen/HTMLToMarkdown.swift)）。Markdownとコードブロックはそのまま、選択範囲があればその中だけ、⌘Zで戻せる。設定の「HTML→Markdown」タブの「div要素内は無視」「table要素内は無視」（初期値オン）でその中はHTMLのまま
- 「Doorkeeper用に整形」で ## と ### をDoorkeeper用の装飾付きHTML見出しに変換（[DoorkeeperHTML.swift](Sources/MarkdownKitchen/DoorkeeperHTML.swift)）。ボタンをクリックしてテーマを選んで適用。テーマ（名前・基本カラー・h3の背景の濃さ）は設定の「テーマ」タブで追加・編集。初期値は CSS Nite（#0AF・30%）と DTP Transit（#993366・20%）
- ヘッダーのボタン・⌘+／⌘−で左右のペインの文字サイズを変更（9〜32pt、保存される）
- プレビューのコードブロックは highlight.js 11.9.0（BSD-3-Clause、[Resources/highlight](Resources/highlight/)、37言語の common 版・GitHub 配色のライト／ダーク）で色分け。同梱なので通信なし。「HTMLをコピー」には色付けを入れず `class="language-…"` だけ
- 右ペインは「見出し｜プレビュー」で切り替え。プレビューは原稿をHTMLにしてWKWebViewで表示（[MarkdownHTML.swift](Sources/MarkdownKitchen/MarkdownHTML.swift)、行頭のHTMLはそのまま）
- 「書式」メニュー・右クリック：太字 ⌘B・斜体 ⌘I・インラインコード ⌘E・取り消し線 ⇧⌘X（<s>）・下線 ⌘U（<u>）・コメント ⇧⌘M／⌥⌘M、見出し1〜4 ⌥⌘1〜4（5・6は未割り当て）・段落 ⌥⌘0、番号付きリスト ⇧⌘7／⌥⌘5・箇条書き ⇧⌘8／⌥⌘6（⌥⌘ は設定に出さない別のキー）・引用 ⇧⌘9・コードブロック ⌥⌘8、字下げ ⌥⌘]／⌥⌘[、段落を上へ／下へ移動 ⌃⇧↑／⌃⇧↓、リンク ⌘K・画像 ⇧⌘I・水平線（キーは未割り当て）、新しい段落 ⌘↩、HTMLをコピー ⌥⌘C（[MarkdownFormat.swift](Sources/MarkdownKitchen/MarkdownFormat.swift)）
- 入力の補助（MacDown の NSTextView+Autocomplete を参考）：リスト・引用の行で Return を押すと記号を続ける（空の項目で終了、- [ ] も継続）、字下げした行は同じ字下げで改行、リストの行と複数行の選択では Tab／⇧Tab で字下げ
- 検索と置換（⌘F）：原稿の上に自前のバー（標準の検索バーより大きい欄）。一致の黄色表示と件数、大文字と小文字の区別、正規表現（置換で $1・\1）、置き換え・すべて置き換え、欄の右の「@」で改行・タブ・空行（検索）や $0〜$5（置換）を挿入。次／前 ⌘G／⇧⌘G、選択部分を検索に使用（キーは未割り当て）、選択部分へジャンプ ⌘J（[FindReplace.swift](Sources/MarkdownKitchen/FindReplace.swift)）。検索のキーも「ホットキー」で変更可
- 設定の「ホットキー」で書式・見出しの操作のキーを変更（[ShortcutSettings.swift](Sources/MarkdownKitchen/ShortcutSettings.swift)。記録欄は全アプリ共通の HotkeyField（Shared/HotkeyRecorder）で「変更…」「初期値に戻す」「割り当てを解除」。⌘ か ⌃ を含むキーだけ、⌘C などの標準のキー・アプリ標準のキー・重複は割り当て不可。保存は `markdownKitchen.shortcuts` の MenuShortcut のまま、[MenuShortcutCombo.swift](Sources/MarkdownKitchen/MenuShortcutCombo.swift) で KeyCombo と変換）
- 設定の「設定の共有」で、原稿の表示・見出しのコピー形式・ホットキー・HTML→Markdown・テーマ・右クリックの設定を書き出し・読み込み（テーマは「追加する」も可）、iCloud Drive・Dropbox などのフォルダーで複数のMacと同期（共通部品 Shared/SettingsSync。原稿・開いているファイル・ログイン起動・メニューバーはMacごと）
- 見出しの一覧をドラッグして章ごと並べ替え（[MarkdownTidy.swift](Sources/MarkdownKitchen/MarkdownTidy.swift) の SectionMover）
- 「整形」：行末の空白・連続する空行・リストの記号・全角英数字・和欧間のスペース、HTMLのMinify・要素間に空行を入れる・強制改行を改段落に（行末の空白2つ・\・<br>と、段落の文章どうしの改行）・改行を削除（英語の境目は半角スペース）・重複行を削除・並べ替え（昇順／降順）（この3つは「すべて整える」には含めない）、目次の挿入
- プレビューは原稿のスクロールに追従。「HTMLをコピー」でプレビューと同じHTMLを全文コピー
- 右ペイン上部のポップアップで形式を選ぶと一覧がその見た目になり、「コピー」（⇧⌘C）でその形式のままコピー（Markdown／Markdown（レベルが変わるところに空行）／ツリー（└ 見出し）／シンプル目次（1. と全角スペースの字下げ）／タブで字下げしたテキスト）
- 右ペインのチェックボックス（# 〜 #####）で抜き出すレベルを選択。原稿に無いレベルは淡色
- 見出しレベルの一括上げ下げ（⌘[／⌘]）。対象はすべてのレベル、原稿で選択していればその範囲内。⌘Zで一括で戻せる

「新規」（⌘N）で原稿を空にしてファイルとの連携を外す（未保存の変更があれば保存するか確認）。「新規ウインドウ」（⌃⌘N）で別の原稿を持つウインドウを開く。ファイルを開くと、前面の原稿が空ならそこへ、そうでなければ新規ウインドウに読み込む（原稿・ファイルとの連携・検索はウインドウごと。開いたまま終了すると次回開き直し、閉じると原稿を消す）。ファイルを書き換えるのは「保存」（⌘S、読み込んだファイルに上書き）と「別名で保存…」（⇧⌘S）のときだけ。上書き前の内容は ~/Library/Application Support/MarkdownKitchen/Backups に控える（新しい20件）。ほかのアプリで変更されていたら上書き前に確認。原稿の内容を送信することはない（プレビューは原稿内の画像URLを読み込む）。原稿はアプリ内（UserDefaults）に保存し、次回起動時に戻ります。

## ビルド

```sh
./build.sh              # ビルド → 検証 → /Applications と Latest Builds へ配置
NO_DEPLOY=1 ./build.sh  # 配置せず build/ にだけ作る
./test.sh               # 見出し抽出のテストとローカライズの検査
```

- SwiftPM（`Package.swift`）。ソースは [Sources/MarkdownKitchen](Sources/MarkdownKitchen/)、文字列・ヘルプは [Localizations](Localizations/)（ja / en / zh-Hans / ko）。
- 見出し抽出は [HeadingParser.swift](Sources/MarkdownKitchen/HeadingParser.swift)、テストは [Tests/HeadingParserCheck.swift](Tests/HeadingParserCheck.swift)。
- 共通部品（AppSurface・StartupWindow・SettingsSection・HelpDocument・AboutSection・MenuBarPresence・LoginAtLaunch・UpdateSupport）は各 `sync` スクリプトがビルド時に上書きするので、直接編集しない。
- 構成は BundleIDInspector を下敷きにしている（設定は自前の `SettingsWindow`）。
- アイコンは [Assets/make-icon.sh](Assets/make-icon.sh)（GenerateIcon.swift から .icns を生成）。
