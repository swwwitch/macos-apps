# CCAutoUpdateOff

macOS 13以降 / Intel・Apple Silicon対応（Universal）のネイティブアプリ。Creative Cloudのアプリの自動更新がオンになっていないかを見張り、オンなら通知・メールで知らせます。Creative Cloudの設定は変更しません（1.1.0から読み取り専用）。

紹介記事：[Creative Cloudの自動更新がオンになっていたら知らせてくれるアプリ「CCAutoUpdateOff」を作りました（note）](https://note.com/dtp_tranist/n/n22872a3cbb8d)

- 対象ファイル：`~/Library/Application Support/Adobe/OOBE/com.adobe.accc.apps.<ユーザーID>.prefs`（`Apps_Panel_Pref` の中の `ccmPreferences` XML）。全体は `prodPref/autoUpdatePreferences/autoUpdateEnabled`、アプリ別は各 `app` の `autoUpdatePreference`。値が無いアプリはCreative Cloudの画面と同じくオンとして扱う。
- Creative Cloudは［環境設定］→［アプリ］でスイッチを切り替えた瞬間にファイルを書き込み、画面に出すアプリだけを `app` エントリに残す（2026-10-14実測）。フォルダーの変更（DispatchSource）、1時間ごと、スリープ復帰、アプリのアクティブ化、メニューバーのメニューを開いたときに読み直す。
- 判定：全体がオフ＝オフ。全体がオンでオン（未設定を含む）のアプリあり＝オン（知らせる）。全体がオンでアプリがすべてオフ＝注意（表示のみ）。
- 通知（初期値オン）：オンになったとき、またはオンのアプリの組み合わせが変わったときに1回。クリックでCreative Cloudを開く。
- メール送信（初期値オフ）：オンの間、1日1回、指定した時刻（初期値 9:00）を過ぎてから。「メール」アプリの既定アカウントからAppleScriptで送る（Automationの許可が必要）。テスト送信あり。
- 自動更新が効いていて「以前のバージョンを削除」もオンのアプリも知らせる（初期値オン、設定で切り替え）。全体がオフならアプリの行を薄く表示し、効かない値は「—」。
- 常駐（初期値オン）、ログイン時に起動（初期値オフ）、メニューバーのアイコンで状態表示（初期値表示）。⌘,で設定。
- 設定の「設定の共有」タブ（共通部品 Shared/SettingsSync）：知らせる内容・通知・メール送信（宛先・送信時刻）を `CCAutoUpdateOff-Settings.plist` に書き出し・読み込み、iCloud Drive・Dropbox などのフォルダーで同期。ログイン起動・常駐・メニューバーはMacごと。
- ［環境設定］→［アプリ］を直接開くURLスキームはCreative Cloudに無いため、Creative Cloudを開くだけ。
- 4言語（日本語・英語・簡体字中国語・韓国語）の表示とオフラインヘルプ（⌘?）。アプリ自身は外部通信なし（メール送信オン時のみ「メール」アプリが送信）。

## 開発

```sh
./build.sh   # build/CCAutoUpdateOff.app
./test.sh    # 疑似設定ファイルで読み取り・判定・複数ユーザーの統合・メール文面と送信日の判定を検証
```

文字列・ヘルプ・Info.plistは `make-resources.py`、アイコンは `Assets/make-icon.sh`（`GenerateIcon.swift`）から再生成します。共有の `AppHeader.swift`・`AppSurface.swift`・`HelpDocument.swift`・`SettingsSection.swift`・`AboutSection.swift`・`WindowActivationPolicy.swift`・`LoginAtLaunch.swift`・`SettingsSync.swift` をビルド時に参照します。

## 制限

組織の管理者が自動更新をロックしている場合は管理者の設定が優先されます。メールはMacが起動・ログイン中で、このアプリが動いているときだけ送れます（スリープ中の分は復帰後）。

このビルドはローカル利用向けに証明書（PL9S9PXX96）で署名しています。Developer ID署名・公証・更新配信先は未設定です。Intel実機での動作は未確認です。

## 2026年10月22日の変更

通常・テストメールの件名に送信元のMac名、本文にMac名とホスト名を記載。Mac名が空の場合はホスト名を使用する。シリアル番号・IPアドレスは含めない。設定同期は共通のv2方式へ移行（全Macを対応版に更新）。

## 通知設定の共通化（2026-10-24、1.4.0 (17)）

通知のON/OFF、許可状態、macOSの通知設定への導線を共通化しました。許可要求は設定での明示操作時に限定し、起動・処理完了時には要求しません。既存設定を保持します。実機検証の残項目は `Shared/AppStandards/Records/NOTIFICATIONS-20261024.md` に記録しています。

## 2026-10-25 Dock非表示時のメニュー修正（1.4.0 build 18）

メイン・設定ウインドウがある間はアプリメニューを使用でき、最小化中もDock・⌘Tabに残ります。最後の対象ウインドウを閉じると再び隠し、非アクティブパレットと保存済みの設定値を保持します。
