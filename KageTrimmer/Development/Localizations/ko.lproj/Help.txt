스크린샷 등 이미지의 그림자를 더 작게 다듬거나, 그림자가 없는 이미지에 그림자를 추가하여 PNG로 저장합니다.

## 사용 방법
1. **그림자 크기**(그림자 없음, XS, S, L)와 **얇은 테두리 추가** 여부를 선택합니다.
2. 이미지를 메인 윈도우에 드롭하거나 **파일** 메뉴의 **이미지 선택…**(⌘O)으로 불러옵니다. Finder의 ‘다음으로 열기’를 사용하거나 Dock의 앱 아이콘에 드롭해도 처리할 수 있습니다. 여러 이미지를 한 번에 처리할 수 있습니다.

- 그림자가 있는 이미지는 기존 그림자를 제거한 후 선택한 크기의 그림자를 다시 적용합니다.
- 그림자가 없는 이미지에는 그림자를 추가합니다.
- **얇은 테두리 추가**는 그림자가 없는 이미지에 그림자를 추가할 때만 사용됩니다.

## 저장 위치와 파일 이름
원본 이미지는 변경하지 않습니다. 처리한 PNG는 원본 이미지와 같은 폴더에 ‘원래 이름+접미사.png’로 저장됩니다. 접미사는 그림자 크기에 따라 정해집니다.

- **그림자 없음**: -no-shadow
- **XS**: -xs
- **S**: -s
- **L**: -l

같은 이름의 파일이 이미 있으면 대치하지 않고 ‘이름-s 2.png’, ‘이름-s 3.png’처럼 번호를 붙여 저장합니다. 저장 위치나 접미사를 변경하는 설정은 없습니다.

## 그림자 없음
‘그림자 없음’은 기존 그림자를 제거하는 모드입니다. 그림자가 없는 이미지에는 그림자를 추가하지 않고 건너뜁니다.

## 설정
앱 메뉴의 **설정…**(⌘,)에서 엽니다. ‘시작 및 백그라운드’ 탭에서 다음 항목을 설정할 수 있습니다.

- **로그인 시 실행**
- **시작 시 메인 윈도우 표시 안 함**
- **메뉴 막대에 표시**
- **앱 표시 단축키**: KageTrimmer 윈도우를 표시합니다. 기본값은 ⌃⌥⌘U이며 활성화되어 있습니다. **기본값 복원**을 클릭하면 기본값으로 되돌릴 수 있습니다.

## 키보드 단축키
- **⌘0**: 메인 윈도우 열기
- **⌘O**: 이미지 선택
- **⌘,**: 설정
- **⌘?**: 도움말
- **⌘W**: 윈도우 닫기
- **⌘M**: 윈도우 최소화
- **⌘Z / ⇧⌘Z**: 실행 취소 / 실행 복귀(입력란 편집 시)
- **⌘Q**: KageTrimmer 종료
- **⌃⌥⌘U**(기본값): KageTrimmer 윈도우 표시(다른 앱을 사용하는 중에도 사용 가능)

## 권한
손쉬운 사용 권한은 필요하지 않습니다. 원본 이미지 폴더에 쓸 수 없는 경우 해당 폴더에 대한 접근 허용을 요청합니다. 원본 이미지가 있는 폴더를 선택한 후 **접근 허용**을 클릭하십시오.

## 실행과 종료
- 윈도우를 닫아도 앱은 종료되지 않습니다. Dock의 앱 아이콘을 클릭하거나, 메뉴 막대 아이콘(**메뉴 막대에 표시**가 켜져 있을 때)에서 **메인 윈도우 열기**를 선택하거나, 앱 표시 단축키를 눌러 윈도우를 다시 표시할 수 있습니다.
- 로그인 시 실행되었거나 **시작 시 메인 윈도우 표시 안 함**이 켜져 있으면 메인 윈도우를 표시하지 않고 시작합니다.
- 파일을 전달하여 앱을 실행한 경우 윈도우를 표시하고 처리한 후 종료합니다. 이미 실행 중인 앱에 파일을 전달한 경우 처리한 후에도 계속 실행됩니다.
- 종료하려면 앱 메뉴의 **KageTrimmer 종료**(⌘Q)나 메뉴 막대 아이콘의 **KageTrimmer 종료**를 선택합니다. 이미지 처리 중에는 종료할 수 없습니다. 처리가 끝난 후 다시 종료하십시오.

## 문제 해결
- 처리 결과는 드롭 영역 아래에 표시됩니다. ‘그림자가 없어 건너뜀’으로 표시된 이미지는 그림자 없음 모드에서 처리되지 않습니다.
- 이미지를 읽거나 저장할 수 없는 경우 이미지 형식과 원본 이미지 폴더의 접근 권한을 확인하십시오.
- 단축키를 등록할 수 없는 경우 다른 앱과 조합이 겹칠 수 있습니다. 설정에서 다른 키 조합을 선택하십시오.
- 로그인 시 실행되지 않는 경우 앱을 응용 프로그램 폴더에 두고 시스템 설정의 로그인 항목에서 허용되어 있는지 확인하십시오.
- 도움말 메뉴에서 **note 글 열기**를 선택하면 note의 사용 안내 글을 브라우저에서 열 수 있습니다.

## 앱 삭제
1. **로그인 시 실행**을 끕니다.
2. 앱을 종료합니다.
3. KageTrimmer를 휴지통으로 이동합니다.
