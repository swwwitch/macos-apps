## 기본 사용법
1. 왼쪽에 PDF를 드롭하거나 "PDF 선택…"(⌘O)을 누르세요. 여러 PDF를 추가할 수 있습니다.
2. 오른쪽에서 슬라이드 크기, 배치, 페이지 상자, 페이지 범위, 저장 위치(PDF와 같은 폴더/데스크탑/지정한 폴더)를 선택하세요.
3. "변환"(⌘Return)을 누르세요. PDF마다 Keynote 프레젠테이션(.key) 1개를 만듭니다.
4. "Finder에서 보기"로 저장된 파일을 확인할 수 있습니다.

## 작동 방식
각 페이지를 1페이지 PDF로 나누고 Keynote에 새 프레젠테이션을 만들게 하여 슬라이드마다 한 페이지씩 이미지로 배치합니다. 페이지는 벡터로 유지되어 확대해도 선명하지만 텍스트로 편집할 수는 없습니다. 테마는 "배경과 테마"에서 선택할 수 있습니다(처음에는 Keynote 기본값). 변환 중에는 Keynote가 실행되어 만드는 중인 윈도우가 표시됩니다.

## 옵션
- **슬라이드 크기**: "PDF에 맞춤"은 첫 페이지 비율로 긴 변을 1920으로 합니다. 16:9, 4:3 고정 크기도 선택할 수 있습니다.
- **배치**: "페이지 전체 맞춤"은 전체를 표시하고, "슬라이드 채우기"는 확대하며 넘치는 부분은 슬라이드 밖에 남습니다.
- **페이지 상자**: 보통 재단 상자입니다. 인쇄용 PDF의 재단선을 빼려면 마감 상자를 선택하세요.
- **페이지 범위**: 모든 PDF에 적용됩니다.
- **페이지 배경 제거**: 각 페이지에서 먼저 그려진 전면 채우기(Illustrator 등)나 부모 페이지 요소(InDesign)를 제거하여 Keynote 마스터 배경이 보이게 합니다. 사진, 텍스트, 선이 먼저 그려진 페이지는 그대로 둡니다. 찾은 배경은 색상 견본과 페이지 수로 표시되며 배경마다 마스터를 지정할 수 있습니다.
- **테마와 마스터**: "Keynote에서 불러오기"로 테마와 마스터 목록을 읽어 옵니다(직접 만든 테마도 선택 가능). 마스터 하나를 고르면 모든 슬라이드에, 배경별로 고르면 해당 배경의 페이지에 적용됩니다.
- "Keynote에서 열어 두기"를 끄면 저장 후 프레젠테이션을 닫습니다.

## 원본과 저장
원본 PDF는 변경하지 않습니다. 같은 이름에는 번호를 붙이며 덮어쓰지 않습니다. 취소하면 만드는 중인 프레젠테이션은 저장하지 않고 닫으며 완료된 파일은 유지합니다. 실행 취소는 없으니 Finder에서 삭제하세요.

## 설정과 단축키
설정(⌘,) › 시작 및 백그라운드:
- 로그인 시 실행(기본 끔)
- 시작 시 메인 윈도우 표시 안 함
- 창을 닫아도 계속 실행
- 메뉴 막대에 표시
- 앱 실행 키보드 단축키
계속 실행 중에는 Dock 또는 메뉴 막대 아이콘에서 다시 열 수 있습니다.
### 키보드 단축키
- **⌘O**: PDF 선택
- **⌘Return**: 변환
- **Esc**: 변환 취소
- **⌘0**: 메인 윈도우 열기(닫은 후에도 다시 표시)
- **⌘W**: 윈도우 닫기
- **⌘,**: 설정
- **⌘?**: 도움말
- **⌘Q**: 종료
※ 변환 중에는 종료할 수 없으니 완료를 기다리거나 먼저 취소하세요.

## 권한
처음 변환할 때 macOS가 Keynote 제어 허용 여부를 묻습니다. "허용"을 선택하세요. 거부했다면 시스템 설정 › 개인정보 보호 및 보안 › 자동화에서 PDF2Keynote의 Keynote를 켜세요. 손쉬운 사용이나 전체 디스크 접근 권한은 필요 없습니다.

## 개인정보
모든 처리는 이 Mac에서 이루어지며 PDF를 업로드하지 않고 앱 자체는 네트워크에 연결하지 않으며("note 글 열기"는 브라우저로 엽니다) 진단 로그를 저장하지 않습니다. 임시 파일은 변환 후 삭제합니다.

## 문제 해결
- **Keynote가 없음**: App Store에서 설치하세요.
- **Keynote가 응답하지 않음**: Keynote의 대화상자를 닫고 다시 시도하세요.
- 암호로 보호된 PDF는 변환할 수 없습니다.
- 페이지가 비어 있거나 위치가 어긋나면 다른 페이지 상자를 선택해 보세요.
- 앱 메뉴의 "업데이트 확인…"과 "업데이트 자동 확인"은 업데이트 주소와 서명 키가 설정되지 않아 준비 중으로 표시되며 네트워크에 연결하지 않습니다. 공증도 설정되지 않았습니다. Apple Silicon, macOS 13 이상.
- 도움말 메뉴의 "note 글 열기"에서 사용법과 지원 정보를 볼 수 있습니다.

## 삭제
로그인 시 실행을 끄고 종료한 후 앱을 휴지통으로 옮기세요. 설정 식별자: jp.local.PDF2Keynote.
