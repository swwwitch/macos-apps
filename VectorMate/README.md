# VectorMate（旧名 AiHelper）

macOS 13以降 / Intel・Apple Silicon対応（Universal）の常駐アプリ（Dock・アプリケーションスイッチャー・メニューバーに表示）。Illustratorの作業を補助します。

## 機能

### メトリクス → プロポーショナルメトリクス

選択中のテキストの自動カーニングを「メトリクス」以外から「メトリクス」に変えると、OpenTypeの「プロポーショナルメトリクス」をONにします（参考：ai-scripts の `jsx/text/single-function/AutoKerning-Metrics.jsx`）。

- Illustratorが前面のときだけ、クリック・Return / Enter / Tab・⌘キーの0.35秒後と、Illustratorが前面に来たときに `do javascript` で選択を確認（イベント駆動。ポーリングなし）。
- 前回の確認と同じ選択で、テキストごとに「メトリクス以外 → メトリクス」に変わったものだけONにする。メトリクスのまま手動でOFFにしたものは戻さない。
- 選択の同一判定：ドキュメント名＋テキストフレームの anchor（文字ツールの選択は characterOffset・length・ストーリー先頭フレームの anchor）。position は中央・右揃えのポイント文字だとカーニングで幅が変わってずれるので使わない。対象は最大200個。
- 前面のIllustratorをパスで指定するので、複数バージョンを開いていても前面のものに送る。
- ONにした操作はIllustratorの取り消し1段分。

- 「メトリクス」から別の方式に変えたときはOFFにする（設定 metricsOffEnabled、初期値オン）。

### UIの明るさ

［設定］→［ユーザーインターフェイス］の明るさ（暗・やや暗め・やや明るめ・明）を1段ずつ変えます。Illustratorが前面のときだけ ⇧F2 で明るく、⇧F1 で暗く（Carbonのホットキーを前面アプリに合わせて登録・解除。設定で変更・解除可）。状態は `uiBrightness`（0／0.5／0.51／1、いちばん近い段階）で読み、ボタン（description「暗」「やや暗め」「やや明るめ」「明」）を押して［OK］。処理中に押した分は合計して後で反映。参考：ViewToggles.jsx。

### シェイプ形成ツールのカラー

［シェイプ形成ツールオプション］の「次のカラーを利用」を「スウォッチ」「オブジェクト」に切り替えます。状態は `Planar/MergeTool/PaintFills`（0：オブジェクト、1：スウォッチ）。`app.selectTool("Adobe Shape Builder Tool")` → Return でオプション（AXLayoutArea「〜オプション」）を開き、両方の項目を持つポップアップを AXPress して矢印キーと Return で選び［OK］（SetAiMenuState.applescript の applyToolOption と同じ）。ドキュメントが必要で、ツールはシェイプ形成ツールのまま。

### ツールの切り替え・パネル

「ツール」タブ。いずれも初期値オフ、Illustratorが前面のときだけ、アクセシビリティの許可が必要。

- 修飾キーのダブルタップで選択ツール：選んだキー（control・option・command・shift、初期値 control。設定 doubleTapKey）だけを0.3秒以内に押して離し、0.35秒以内にもう一度で `app.selectTool('Adobe Select Tool')`。ほかのキー・クリック・修飾キーを挟むと数えない（flagsChanged のグローバル監視）。
- アートボードツール → アートボードパネル、グラデーションツール → グラデーションパネル：クリック・キー（⌘以外）の0.35秒後、修飾キーをすべて離した0.35秒後と1秒後（Keyboard Maestro のホットキーはキーが届かず、マクロの selectTool が終わるのを待つ）、Illustratorが前面に来たときに `app.getSelectedToolName()`（非公開。2026で実測、名前は `Adobe Crop Tool`／`Adobe Gradient Vector Tool`）で読み、ほかのツールから切り替わったときだけ `executeMenuCommand('Adobe Artboard Palette'／'Adobe Gradient Palette')`。メニューはパネルの表示・非表示を切り替えるので、［ウィンドウ］の項目に ✓ が無いときだけ実行（AXMenuItemMarkChar）。

### クイック変形

「クイック変形を表示」（メニューバー・ファイルメニュー・メインウインドウのボタン・ホットキー ⌃⌥⌘T）で開く、前面に浮くパレット（ai-scripts の `jsx/transform/QuickTransformPalette.jsx` から移植）。

- 反転・回転（水平・垂直、90°ずつ。基準点9か所が基点）、回転スライダー（-180〜180°、15°刻み・Shiftで90°刻み。刻みごとに差分だけ回し、離すと0に戻る）、移動・複製（選択全体の幅／高さ＋マージン。中央は同じ位置に複製）。Option＋クリックで複製してから変形し、複製を選択する。
- 変形は JSX と同じく1回の合成行列（`transform(…, Transformation.DOCUMENTORIGIN)`）で、基点は可視／幾何境界から求める。マージンは定規の単位（rulerType）で、反転・回転のあとは基準点の側へずらす。
- 1操作＝1回の `do javascript`（取り消し1段）。連打は順番に実行する。パネルは nonactivatingPanel で、開いてもIllustratorが前面のまま。基準点・マージン・プレビュー境界は保存する（Macごと）。

### すべてのパレットを閉じる

ホットキー ⌥W（設定で変更・解除可）で、開いている単位パレット・クイック環境設定・クイック変形をまとめて閉じる。Illustratorが前面のときだけ登録する。

### バックグラウンド保存・書き出しをオフ

［設定］→［ファイル管理］の「バックグラウンドで保存」「バックグラウンドで書き出し」をオフにします（参考：`jsx/AppleScript/DisableBackgroundSaveExport.applescript`、`helpers/SetAiMenuState.applescript`、`jsx/preference/ViewToggles.jsx`）。

- app.preferences では読めない（`enableBackgroundSave`／`enableBackgroundExport` は存在しないキーと同じく常に true）。状態は設定ファイル「Adobe Illustrator Cloud Prefs」の小文字始まりのキーから読む（BackgroundSaveExportState.jsx と同じ）。「確認」はダイアログボックスのチェックボックスを読んで［キャンセル］で閉じる。
- JavaScriptで書いても再起動まで効かないため、アクセシビリティでダイアログボックス（AXLayoutArea「環境設定」）を開き、パネル見出し「ファイル管理」を待ってからチェックボックス（description で照合）を外して［OK］。チェックボックスが見つからなければ［キャンセル］で閉じる。メニューが効かないときは1回だけ押し直す。
- ［OK］の前にチェックボックスがすべて外れたことを確かめる。Illustratorが起動していないときは起動しない。
- 日本語版で実機確認済み（2026-10-18）。英語版のメニュー名・ラベルは未検証。

### 環境設定セット

Illustratorの主要な環境設定を、名前を付けたセットでまとめて切り替えます（ai-scripts の `jsx/preference/PresetManager.jsx` から移植）。

- メインウインドウの「環境設定」タブはセットの切り替えだけ。ラジオボタンでセットを選ぶと、全項目を1回の `do javascript` で `app.preferences` に書き込み、ドキュメントが開いていれば `zoomout`→`zoomin` で再描画して読み戻す。続いて UIの明るさ・バックグラウンドの3項目・シェイプ形成ツールのカラーを、今と異なるときだけそれぞれの手順（環境設定のダイアログボックス／ツールオプション）で変え、最後にもう一度読み戻す。今の環境設定と一致するセットに印が付く（一致しなければ「どのセットとも一致しません」）。
- 各セットの中身は設定の「環境設定セット」タブで編集（追加・複製・削除・並べ替え・すべて初期値に戻す）。編集は下書きで、［上書き］で保存、［元に戻す］で最後に保存した状態に戻す（Illustratorには書き込まない）。「今の設定を取り込む」で選んでいるセットの値をIllustratorの今の環境設定で置き換える（下書きに入る）。初期値は JSX と同じ［デフォルト］［プリセット1］（設定 prefPresets、設定の共有の対象）。
- 項目は JSX と同じ30項目に、UIの明るさ（4段階）・シェイプ形成ツールの「次のカラーを利用」・バックグラウンドの3項目（バックグラウンドで書き出し・保存、復帰データの自動保存）・ガイドをロック（［表示］→［ガイド］の項目名が「ガイドをロック」か「ガイドをロック解除」かで読み、`lockguide` で切り替え。切り替えはドキュメントを開いているときだけ）・スクリプト実行の許可（`ShowExternalJSXWarning`、オンで false＝外部 .jsx の実行前に警告しない）を加えた37項目：一般（詳細なツールヒント・ホーム画面・以前の新規ドキュメント・裁ち落としを印刷ボタン）、選択範囲・アンカー表示（選択範囲へズーム・カンバス上でロック解除・パスに制限2つ・アンカーポイントのサイズ 5/7/9/11）、アートボード（ロック・非表示を一緒に移動・名前・ハイライトのカラー10色・ストローク幅1〜4）、テキスト（エリア内文字の自動サイズ・最近使用したフォントの表示数 0/1〜30・字形の保護・異体字）、ユーザーインターフェイス（カンバスカラー）、ガイド（シアン／ライトブルー、ライン／点線）、スマートガイド（オブジェクトのハイライト）、パフォーマンス（アニメーションズーム・ヒストリー数1〜1000・リアルタイムの描画と編集）、ファイル管理（オリジナルの編集・Adobe Fonts・保存先・リンクを更新）、クリップボード（SVGコード）。
- 読み取りは JSX と同じく、色・サイズはいちばん近い選択肢にスナップ、`hitShapeOnPreview`／`hitTypeShapeOnPreview` は 0 がオン、`maximumUndoDepth` の 0 は未登録として 100、`text/recentFontMenu/showNEntries` の 0 は表示数オフ。
- 明るさは `uiBrightness`、シェイプ形成ツールのカラーは `Planar/MergeTool/PaintFills` を JavaScript で読む。バックグラウンドの3項目は JavaScript で読めないため、一致の判定はバックグラウンド欄と同じ値（設定ファイルまたはダイアログボックスで読んだ値）を使い、読めていなければ比べない。「今の設定を取り込む」はバックグラウンドの3項目をダイアログボックスで読む（読めなければ最後に分かっている値、それも無ければセットの値のまま）。シェイプ形成ツールのカラーはドキュメントが開いていなければ変えずに知らせる。ダイアログボックスの手順で失敗したら、どの手順かをメッセージに出す。
- JSX の2カラム表示・変更件数の表示は移植していない。
- **未確認：** 実機での書き込みと読み戻し（Node で環境設定をスタブして往復は確認済み）。2.11.0 で加えた明るさ・バックグラウンド・シェイプ形成ツールのカラーの切り替え（続けてダイアログボックスを開く手順）と、ドキュメントなしで `Planar/MergeTool/PaintFills` が読めるか。

### 関連付け

複数の版のIllustrator（2021〜2026 はすべて Bundle ID `com.adobe.illustrator`）がインストールされているとき、Illustratorに関連付けられた拡張子をまとめて指定の版で開くようにします（ExtensionLinker 0.2.29 の「アプリの版」から移植。Illustratorのみ）。

- 対象は .ai・.ait・.eps・.svg のうちチェックしたもの（設定 versionExtensions、初期値はすべて）。ほかのアプリに関連付けられていた拡張子もIllustratorに変わる。各行に今開くアプリ（版）を表示。同じ版が複数ある（例：「Adobe Illustrator 2026」と「Adobe Illustrator 2026 en」）ときは選択肢は1つにまとまり、どちらで開くかは Launch Services が決めるので、行には実際に開く方を表示。
- 公開APIは版を記録しない（`LSHandlerPreferredVersions = "-"`）ため、`~/Library/Preferences/com.apple.LaunchServices/com.apple.launchservices.secure.plist` の LSHandlers に `LSHandlerPreferredVersions.LSHandlerRoleAll = <CFBundleVersion>` を書き、`killall lsd`。動的UTI（.ait・.aia など）は拡張子（LSHandlerContentTag）で記録。
- 書き込む前に、記録と LSCopyDefaultRoleHandlerForContentType の食い違い（lsd がまだ保存していない変更）がないことを確かめる。変更前の記録は `~/Library/Application Support/VectorMate/LaunchServicesBackups` に10世代。
- 再起動後、urlForApplication(toOpen:) が期待する版になるまで最大5秒待って確かめ、確かめられなければ元の記録に戻す。

### キーボードショートカット（同期タブ）

同期フォルダーに置いた .kys をすべて、Illustratorのキーボードショートカットのセットとして使えるようにします。

- 読み込み元はフォルダー（設定 shortcutSource、初期値 `キーボードショートカット`）、選ぶセットは「使用するセット」（設定 shortcutSetName、.kys 名。フォルダーに無ければ名前順の最初）。どちらも設定の共有の対象。2.13 までの .kys 1つの指定は、そのフォルダーとファイル名に読み替え、すぐ保存する。同期フォルダーが空欄なら初期値を使う。同期タブの読み込み元はすべて、先頭の「同期フォルダー」（設定 syncFolder、初期値 `~/sw Dropbox/takano masahiro/sync-setting/ai`、設定の共有の対象）からの相対パス。`/` か `~` で始まれば絶対パスとして使う。［選択…］で同期フォルダーの中を選ぶと相対パスで保存。2.12〜2.13 の絶対パスは読み込み時に同期フォルダーの中なら相対パスに直し、2.12 の初期値（存在しない sw.kys）は新しい初期値に置き換える。
- ［リンクして選ぶ］でフォルダー内の .kys をすべて `~/Library/Preferences/Adobe Illustrator <版> Settings/ja_JP/<名前>.kys` にシンボリックリンクする。版は起動中のIllustratorの主番号、起動していなければ数字だけの Settings フォルダーの最大。同じ先へのリンクはそのまま、別の先へのリンクは張り替え、実ファイルは `~/Library/Application Support/VectorMate/LinkBackups/KeyboardShortcuts/<日時>` に移す。
- Illustratorが起動していれば、［編集］→［キーボードショートカット...］（AXLayoutArea「キーボードショートカット」）の最初の AXComboBox（セット）を実際のマウスクリック（CGEvent）で開き、一覧の項目をクリックして、値が変わったのを確かめて［OK］。値の書き込み・矢印キー・System Events のクリックではセットが変わらず、開いた一覧の項目は AX に出ないので、行の位置はコンボボックス上端から 1行目 +32、区切り線を挟んで2行目以降は +59 から 22.5 ずつ（Illustrator 30.8.2、2026-10-24 実測）。すでに選ばれていれば［キャンセル］で閉じる。実行中はマウスポインタが動く。
- 起動中に置いた .kys は一覧に出ない（2026-10-20 実測）。一覧に無ければリンクだけ作り、再起動してからもう一度押すよう知らせる。
- **未確認：** VectorMate からの実行（AppleScript では「Illustrator 初期設定」⇄「sw-2020」を実機確認済み）、今のセットを変更した「[カスタム]」から切り替えるときの確認ダイアログボックス、英語版のメニュー名。

### まとめて同期（同期タブ）

- 同期フォルダーの下の［まとめて同期］で、ドキュメントプロファイル・合成フォントのリンク作成（その場で実行）と、キーボードショートカットの［リンクして選ぶ］（Illustratorを操作）を続けて行う。結果はそれぞれの項目に出る。

### ドキュメントプロファイル・合成フォント（同期タブ）

- 読み込み元のフォルダー（設定 linkSource.profiles／linkSource.compositeFonts、初期値は同期フォルダーの「New Document Profiles」「合成フォント」、設定の共有の対象）の中のファイルを、［リンクを作成］で1つずつ `~/Library/Application Support/Adobe/Adobe Illustrator <版>/ja_JP/<同じ名前のフォルダー>` にシンボリックリンクする（隠しファイルは除く）。フォルダーごとのリンクにしないのは、Illustrator側にしか無いファイル（既定のプロファイル・ほかの合成フォント）を残すため。
- 版は起動中のIllustratorの主番号、起動していなければ数字だけの「Adobe Illustrator <版>」フォルダーの最大。リンクの扱いはキーボードショートカットと同じで、実ファイルは `~/Library/Application Support/VectorMate/LinkBackups/<日時>/<フォルダー名>` に移す。Illustratorを操作しないので、その場で実行する。
- フォルダーは対象外（Temp.localized など）。読み込み元がリンク先そのもの、または中のファイルがリンク先へのリンクのときは、実ファイルを退避すると元が無くなるので何もしない。張り替えは一時名のリンクを rename(2) で置き換え、実ファイルの退避後にリンクを作れなければ元に戻す。
- 2026-10-20 15:20、合成フォントのリンク作成の直後に、同期フォルダー側（sync/合成フォント）の8ファイルが消えた（退避した Illustrator 側の8つから戻した）。原因は未特定。VectorMate は読み込み元を書き換えない（テストで確認）。読み込み元が Illustrator 側へのリンクだった場合は上の確認で止まる。
- シンボリックリンクにした合成フォントはIllustratorで読める（2026-10-20 ユーザー確認）。
- **未確認：** 上の消えた件の原因、起動中に加えたプロファイル・合成フォントが再起動なしで出るか。

### その他タブ：Illustratorの設定を初期化

- ［初期化…］は確認のうえ、起動中のIllustratorを `terminate` で終了（保存の確認があるので最大120秒待つ。終了しなければ何もしない）し、その版の `~/Library/Application Support/Adobe/Adobe Illustrator <版>`・`~/Library/Preferences/Adobe Illustrator <版> Settings`（「キャッシュも削除」がオンなら `~/Library/Caches/com.adobe.illustrator` も。設定 resetIncludesCache、初期値オン）をゴミ箱に入れて、同じアプリを起動し直す。版は起動中のIllustratorの主番号で、起動していなければ使えない。同期タブのリンク（Application Support・Preferences 内）も消える。**未確認：** 実機での一連の動作。

## 権限

- オートメーション（Adobe Illustrator）：`do javascript`。osascript を子プロセスで使う（タイムアウト5秒＋強制終了）。
- アクセシビリティ：キー入力のグローバル監視と、環境設定・ツールオプションのダイアログボックスの操作。クリックの監視には不要。

## 開発

```sh
python3 make-resources.py            # 文字列4言語・ヘルプ・Info.plist
Assets/make-icon.sh                  # アイコン
./test.sh                            # スクリプト生成・応答の解析・文字列の検査
./build.sh                           # build/VectorMate.app、/Applications と Latest Builds へ配置（SKIP_DEPLOY=1 で配置しない）
```

共通部品（AppHeader・AppSurface・StartupWindow・HelpDocument・SettingsSection・AboutSection・WindowActivationPolicy・LoginAtLaunch・AccessibilityPermission・MenuBarPresence・UpdateSupport）は `../Shared` から直接コンパイルします。
