# FileSorter

フォルダーに加わったファイルを、ルールに合わせて別のフォルダーへ移動するAppKit/SwiftUIアプリ。Apple Silicon / macOS 13以降。

- ルール：監視するフォルダー・名前に含む語（カンマ区切り）・拡張子（カンマ区切り）・移動先。語か拡張子のどちらかに当てはまれば移動（大文字小文字を区別せず、濁点などの合成・分解の違いも同一視）。上から順に調べ、最初に当てはまったルールで移動。
- 最初のルール：「請求書」（ダウンロード、名前に 請求書・invoice → Dropbox-shared/sw経理関連2017-2018/PDF-IN）、「音楽」（ダウンロード、mp3・m4a・flac → Dropbox-shared/music）。
- ダウンロード中（.download・.crdownload など）は待ち、大きさが変わらなくなってから移動。移動先に同名があれば番号を付ける（上書きしない）。
- 起動前からあったファイルは自動では動かさず、「今あるファイルを振り分ける…」で件数を確認してから移動。
- ⌃⌥F でメインウインドウを呼び出す。

Keyboard Maestroの「Hazelからの移行」グループの「「ダウンロード」フォルダー：請求書／音楽」を元にした。

## しくみ

- 監視は `DispatchSource.makeFileSystemObjectSource`（kqueue）。変化があったときだけ一覧を比べる（ポーリングなし）。
- ルールはフォルダーの場所を含むため設定の共有（書き出し・同期）の対象外。
- ファイルの中身は読まない。外部通信なし（更新確認を除く。配信先は未設定）。

## ビルド・テスト

```
./test.sh            # ルール・途中のファイル・重複名の単体テスト＋4言語の翻訳検証
./build.sh           # build/FileSorter.app
./build.sh --deploy  # /Applications と Latest Builds へ配置
Assets/make-icon.sh  # アイコンを作り直す
```
