# CommandDee

<img src="Assets/CommandDee.png" width="128" alt="CommandDeeアイコン">

[ダウンロード（プレリリース）](https://github.com/swwwitch/CommandDee/releases) · macOS 13以降 / Apple Silicon

現時点ではDeveloper ID署名・公証を行っていない検証用ビルドです。Finder／Path Finderでのショートカット実動作と再ログイン時の自動起動は未検証です。

Finder／Path Finderで選択したファイル・フォルダーを、⌘Dでバージョン番号付き、⌃⌘Dで日付付き、⌃⌘Eでeditedと日付付きで複製するmacOSネイティブアプリ。macOS 13以降・Apple Silicon向け。

## 使い方

1. ReleasesからZIPをダウンロードして展開し、`CommandDee.app`をアプリケーションフォルダーに置いて起動します。メニューバーに「⌘D」が表示されます。
2. 「アクセシビリティ設定を開く」からCommandDeeを許可します。
3. Finder／Path Finderでファイルやフォルダーを選択して⌘Dを押します。初回のオートメーション許可では対象アプリの操作を許可します。
4. 元ファイルと同じフォルダにコピーが作成されます。

| 選択した名前 | 複製先 |
| --- | --- |
| aaa.txt | aaa-v2.txt |
| aaa.txt（v2が存在） | aaa-v3.txt |
| aaa-v2.txt | 同じディレクトリの最大番号＋1 |
| aaa.txt（v2とv5が存在） | aaa-v6.txt |
| README | README-v2 |
| フォルダ.name | フォルダ.name-v2 |

同じディレクトリ内で、ベース名・拡張子が一致する `-vN` の最大番号＋1を採番します。欠番は埋めません。バージョン付きファイルを選んだ場合も同じ規則です。該当する番号がない場合はv2から始めます。

拡張子を維持します。既存ファイルを上書きしません。複数選択・フォルダにも対応します。コピー後も元ファイルの選択を維持します。複数項目の途中で失敗した場合、成功したコピーは残し、失敗した項目を表示します。コピー操作の一括Undoは未実装です。

⌘Dの置き換えはFinder／Path Finderが最前面の場合だけです。検索欄などテキスト入力中は標準のキー操作を維持します。メニューバーから一時停止・終了できます。ログイン時の起動は環境設定から切り換えできます。初回は自動起動を登録します。macOS側で承認が必要な場合は設定画面に表示します。

## 日付付きの複製（⌃⌘D）

Macのローカル日付（グレゴリオ暦）を `-YYYYMMDD` 形式で拡張子の前に付けます。末尾にハイフン＋6桁（YYMMDD）または8桁（YYYYMMDD）の数字がある場合は、その部分を今日の日付（必ず8桁のYYYYMMDD）に置き換えます。

例：2026年10月5日の場合

- `aaa.txt` → `aaa-20261005.txt`
- `aaa-20261001.txt` → `aaa-20261005.txt`
- `aaa-261001.txt` → `aaa-20261005.txt`
- `aaa-v3-20261001.txt` → `aaa-v3-20261005.txt`

元ファイルは残します。複数選択・フォルダにも対応します。同名がすでにある場合（元ファイルが今日の日付の名前の場合も含む）は、複製せずエラーを表示します。既存ファイルを上書きしたり、追加の番号を付けたりしません。

## edited付きの複製（⌃⌘E）

- `aaa.txt` → `aaa-edited-20261005.txt`（2026年10月5日の例）
- 末尾に日付があれば今日の日付に置換し、`-edited-YYYYMMDD` に揃えます。
- すでに `-edited-YYMMDD` または `-edited-YYYYMMDD` があれば、editedを重複させず日付を更新します。
- 拡張子・原本を保持し、同名があれば複製せず通知します。

日付付き複製の旧ショートカット⌃⌥⌘Dは解除しました。

## 親フォルダー名のトグル名前変更（⌃E）

親フォルダーが `Project` の場合、`aaa.txt` → `aaa-Project.txt`、`aaa-Project.txt` → `aaa.txt` へ元ファイルの名前を変更します。拡張子を保持し、親フォルダー名が末尾に完全一致する場合だけ外します。

⌃Eは複製しません。再度実行すると元の名前に戻ります。同名が存在する場合は、元ファイルも既存のファイルも変更せず停止します。複数選択・フォルダに対応し、各項目の親フォルダー名を使います。環境設定の「読み飛ばす親フォルダー名」と完全一致する階層は読み飛ばし、さらに上の名前を使います。連続する一致も読み飛ばします。ファイルやフォルダー自体は移動しません。

メニューバー → 環境設定…で変更できます。初期値はログインユーザー名（短いアカウント名）。空欄で読み飛ばしを無効化でき、変更は自動保存されます。「ログインユーザー名に戻す」でリセットできます。

例：設定が `takano` の場合、`/projectA/aaa.txt` も `/projectA/takano/aaa.txt` も名前は `aaa-projectA.txt` になります。

## フォルダーへの対応

4つのショートカットすべてでフォルダーを選択できます。複製では中身も含めてコピーし、⌃Eではフォルダー自体の名前を変更します。通常のフォルダー名のドット以降は拡張子として扱いません。

親フォルダーが `Project` の場合：

| キー | 選択したフォルダー | 結果 |
| --- | --- | --- |
| ⌘D | assets（最大v5） | assets-v6 を複製 |
| ⌃⌘D | assets-261001 | assets-20261005 を複製（日付の例） |
| ⌃⌘E | assets | assets-edited-20261005 を複製（日付の例） |
| ⌃E | assets ⇄ assets-Project | 元フォルダーの名前を変更 |

## ビルドと検証

Xcode Command Line Toolsが必要です。外部パッケージへの依存はありません。

```sh
git clone https://github.com/swwwitch/CommandDee.git
cd CommandDee
./test.sh
./build.sh
```


- `./build.sh`：Swift/AppKitでビルド、ad-hoc署名、署名検証。既存ビルドはBackupsに保存。
- `./test.sh`：番号付きコピー、既存名の衝突、原本保持、日本語、拡張子なし、隠しファイル、フォルダ、壊れたシンボリックリンクの衝突、存在しない入力、日付追加・更新、同名保護、タイムゾーンと年境界など91項目を検証。
- ビルド・署名検証・91項目のテスト・初回画面の表示は確認済み。
- Finderで自動入力した⌘Dは初回テストで標準コピーになったため、イベント取得位置を修正。修正後のアプリはアクセシビリティ未許可のため、Finder／Path Finderでのショートカット実動作は未検証です。

更新・移動で権限が外れた場合、システム設定でCommandDeeを再登録して再起動してください。配布用のDeveloper ID署名・公証は未実施です。

イベントの取得にはAppleの[CGEvent.tapCreate](https://developer.apple.com/documentation/coregraphics/cgevent/tapcreate(tap:place:options:eventsofinterest:callback:userinfo:))を使用します。

## 基本設定とヘルプ

起動時は設定画面を表示します（初回のみ）。以降はメニューバーに常駐し、アプリを開き直すと環境設定を表示します。ウインドウを閉じても終了しません。CommandDeeの画面で⌘Q、またはメニューバーの終了で終了します。⌘Wはウインドウを閉じ、⌘, は環境設定を開きます。処理中は完了まで終了を待ちます。

4つのショートカットは環境設定のボタンを押して変更できます。Command／Control／Optionのいずれかを含むキーを入力してください。Escで取消。同じ組み合わせの重複は登録できません。初期値に戻すボタンがあります。設定と一時停止状態は保存されます。

メイン画面は設定項目を中心にし、使い方は「ヘルプ」へ移しました。インストール先は `/Applications/CommandDee.app`。ログイン時の起動が有効になったことは設定画面で確認済みです。実際の再ログインとFinder／Path Finderでのキー操作は未検証です。

アイコンは組み込み画像生成で、BrowserSwitcherの青い角丸タイルを参照して作成。`Assets/CommandDee.png` と `Assets/CommandDee.icns`、生成プロンプトは `Assets/icon-generation.txt` に保存しています。
