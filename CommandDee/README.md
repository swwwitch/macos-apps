## 使い方

1. ReleasesからZIPをダウンロードして展開し、`CommandDee.app`をアプリケーションフォルダに置いて起動します。メニューバーに追加を選ぶと、モノクロの書類アイコン（文字なし）が表示されます。
2. 「アクセシビリティ設定を開く」からCommandDeeを許可します。
3. Finder／Path Finderでファイルやフォルダを選択して⌘Dを押します。初回のオートメーション許可では対象アプリの操作を許可します。
4. 元ファイルと同じフォルダにコピーが作成されます。

| 選択した名前 | 複製先 |
| --- | --- |
| aaa.txt | aaa-v2.txt |
| aaa.txt（v2が存在） | aaa-v3.txt |
| aaa-v2.txt | 同じディレクトリの最大番号＋1 |
| aaa-edited-20261006-v3.ai | aaa-edited-20261006-v4.ai |
| aaa.txt（v2とv5が存在） | aaa-v6.txt |
| README | README-v2 |
| フォルダ.name | フォルダ.name-v2 |

同じディレクトリ内で、ベース名・拡張子が一致する `-vN` の最大番号＋1を採番します。欠番は埋めません。バージョン付きファイルを選んだ場合も同じ規則です。該当する番号がない場合はv2から始めます。

`-edited-YYYYMMDD`、`-YYYYMMDD`、`-edited` は維持し、`-vN` を更新します（6桁の日付にも対応）。この場合は、日付・edited部分も一致する名前の最大番号を参照します。

拡張子を維持します。既存ファイルを上書きしません。複数選択・フォルダにも対応します。コピー後も元ファイルの選択を維持します。複数項目の途中で失敗した場合、成功したコピーは残し、失敗した項目を表示します。コピー操作の一括Undoは未実装です。

⌘Dの置き換えはFinder／Path Finderが最前面の場合だけです。検索欄などテキスト入力中は標準のキー操作を維持します。メニューバーから一時停止・終了できます。ログイン時の起動は設定から切り替えできます。初回は自動起動を登録します。macOS側で承認が必要な場合は設定画面に表示します。

## 日付付き（名前変更 ⌃D／複製 ⌃⌘D）

⌃Dは複製せず、選んだ項目の名前に日付を付けます（日付が古ければ今日に更新）。⌃⌘Dは日付を付けた複製を作ります。

Macのローカル日付（グレゴリオ暦）を `-YYYYMMDD` 形式で拡張子の前に付けます。末尾にハイフン＋6桁（YYMMDD）または8桁（YYYYMMDD）の数字がある場合は、その部分を今日の日付（必ず8桁のYYYYMMDD）に置き換えます。

例：2026年10月5日の場合

- `aaa.txt` → `aaa-20261005.txt`
- `aaa-20261001.txt` → `aaa-20261005.txt`
- `aaa-261001.txt` → `aaa-20261005.txt`
- `aaa-20261001-v3.txt` → `aaa-20261005-v3.txt`

⌃⌘Dでは元ファイルを残します。複数選択・フォルダにも対応します。今日の日付（6桁・8桁）が付いている項目は、何もせず静かにスキップします。別の同名項目がある場合は、複製せずエラーを表示します。既存ファイルを上書きしたり、追加の番号を付けたりしません。

## edited付きの複製（⌃⌘E）

- `aaa.txt` → `aaa-edited.txt`
- 日付や番号はそのまま残します（`aaa-20261001.txt` → `aaa-edited-20261001.txt`、並びは設定の「接尾辞の並び順」）。
- すでに `-edited` が付いている項目はスキップします。
- 拡張子・原本を保持し、同名があれば複製せず通知します。

日付付き複製の旧ホットキー⌃⌥⌘Dは解除しました。

## 親フォルダ名のトグル名前変更（⌃P）

親フォルダが `Project` の場合、`aaa.txt` → `aaa-Project.txt`、`aaa-Project.txt` → `aaa.txt` へ元ファイルの名前を変更します。拡張子を保持し、親フォルダ名が末尾に完全一致する場合だけ外します。

⌃Pは複製しません。再度実行すると元の名前に戻ります。同名が存在する場合は、元ファイルも既存のファイルも変更せず停止します。複数選択・フォルダに対応し、各項目の親フォルダ名を使います。設定の「読み飛ばす親フォルダ名」と完全一致する階層は読み飛ばし、さらに上の名前を使います。連続する一致も読み飛ばします。ファイルやフォルダ自体は移動しません。

メニューバー → 設定…で変更できます。初期値はログインユーザー名（短いアカウント名）。空欄で読み飛ばしを無効化でき、変更は自動保存されます。「ログインユーザー名に戻す」でリセットできます。

例：設定が `takano` の場合、`/projectA/aaa.txt` も `/projectA/takano/aaa.txt` も名前は `aaa-projectA.txt` になります。

## フォルダへの対応

どの操作でもフォルダを選択できます。複製では中身も含めてコピーし、⌃D・⌃Pではフォルダ自体の名前を変更します。通常のフォルダ名のドット以降は拡張子として扱いません。

親フォルダが `Project` の場合：

| キー | 選択したフォルダ | 結果 |
| --- | --- | --- |
| ⌘D | assets（最大v5） | assets-v6 を複製 |
| ⌃D | assets-261001 | assets-20261005 に名前を変更（日付の例） |
| ⌃⌘D | assets-261001 | assets-20261005 を複製（日付の例） |
| ⌃⌘E | assets | assets-edited を複製 |
| ⌃P | assets ⇄ assets-Project | 元フォルダの名前を変更 |

## ビルドと検証

Xcode Command Line Toolsが必要です。外部パッケージへの依存はありません。

```sh
git clone https://github.com/swwwitch/macos-apps.git
cd macos-apps/CommandDee
./test.sh
./build.sh
```


- `./build.sh`：Swift/AppKitでビルド、ad-hoc署名、署名検証。既存ビルドはBackupsに保存。
- `./test.sh`：番号付きコピー、既存名の衝突、原本保持、日本語、拡張子なし、隠しファイル、フォルダ、壊れたシンボリックリンクの衝突、存在しない入力、日付追加・更新、同名保護、タイムゾーンと年境界など154項目を検証。
- ビルド・署名検証・154項目のテスト・初回画面の表示は確認済み。
- Finderで自動入力した⌘Dは初回テストで標準コピーになったため、イベント取得位置を修正。修正後のアプリはアクセシビリティ未許可のため、Finder／Path Finderでのホットキー実動作は未検証です。

更新・移動で権限が外れた場合、システム設定でCommandDeeを再登録して再起動してください。配布用のDeveloper ID署名・公証は未実施です。

イベントの取得にはAppleの[CGEvent.tapCreate](https://developer.apple.com/documentation/coregraphics/cgevent/tapcreate(tap:place:options:eventsofinterest:callback:userinfo:))を使用します。

## 基本設定とヘルプ

起動時は設定画面を表示します（初回のみ）。以降はメニューバーに常駐し、アプリを開き直すと設定を表示します。ウインドウを閉じても終了しません。CommandDeeの画面で⌘Q、またはメニューバーの終了で終了します。⌘Wはウインドウを閉じ、⌘, は設定を開きます。処理中は完了まで終了を待ちます。

ホットキー（初期値：⌘D 連番で複製、⌃D 日付付き、⌃⌘D 日付付きで複製、⌃⌘E edited付きで複製、⌃P 親フォルダ名、⌃S 2項目の名前を入れ替え）は設定のボタンを押して変更できます。⌃は複製せずに名前を変え、⌘・⌃⌘は複製します（D＝date、E＝edited、P＝parent、S＝switch）。Command／Control／Optionのいずれかを含むキーを入力してください。Escでキャンセル。同じ組み合わせの重複は登録できません。初期値に戻すボタンがあります。設定と一時停止状態は保存されます。

メイン画面は設定項目を中心にし、使い方は「ヘルプ」へ移しました。インストール先は `/Applications/CommandDee.app`。ログイン時の起動が有効になったことは設定画面で確認済みです。実際の再ログインとFinder／Path Finderでのキー操作は未検証です。

アイコンは組み込み画像生成で作成し、ほかのアプリと同じマスタード色の角丸タイルに重なった書類と⌘記号を配置しています。`Assets/CommandDee.png` と `Assets/CommandDee.icns`、生成プロンプトは `Assets/icon-generation.txt` に保存しています。

## 接尾辞の並び順

設定の「接尾辞の並び順」で、バージョン・edited・日付の全6通りから選べます。初期値は `-edited-20261006-v4`。ほかの例：`-v4-edited-20261006`、`-20261006-edited-v4`。設定を変えただけでは既存ファイルを変更せず、次の複製時に適用します。並び順が違っても同じベース名・拡張子・日付・editedの有無なら、同じ系列として最大番号を参照します。

今日の日付をスキップする場合は並び順も変更しません。editedがまだない項目へのedited新規付与は実行します。親フォルダ名のトグルには、この設定は適用しません。


## 2項目の名前を入れ替え（1.7.0）

Finder／Path Finderで同じフォルダの2項目を選び、⌃Sを押すと名前全体（拡張子を含む）を交換します。例：`DoSomething-v16.jsx` と `DoSomething-.jsx`。ホットキーは設定で変更できます。

ファイル同士・フォルダ同士に対応。複製せず、内容・更新日時はそれぞれの項目に保持します。最大番号の探索や更新日時によるスキップは行わず、選択した2項目を交換します。macOSの原子的な交換を使用し、交換非対応のファイルシステムでは変更せずエラーを表示します。戻すには同じ2項目で再実行してください（FinderのUndoには非対応）。

参考：[ファイル名バージョニングの現場で、最新ファイルを“バージョン番号なし”にする](https://note.com/dtp_tranist/n/nbfa9e4aa5b39)

## メニューバーへの追加

初回案内で「メニューバーに追加」を選ぶとモノクロアイコンを表示します。「追加しない」「あとで」も選べます。後からアプリメニューの「メニューバー設定…」で変更できます。ログイン起動とは独立した設定です。アイコンを非表示にしてもアプリは終了しません。
