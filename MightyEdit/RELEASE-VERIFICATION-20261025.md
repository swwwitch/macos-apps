# MightyEdit 0.3.3 (116) 開発Mac検証記録

2026-10-25 JST。正本：~/Git/macos-apps。Bundle ID：jp.local.TextPalette。

## 変更

- 「その他」に選択範囲からクリップボードの文字列をすべて削除する機能を追加。空文字列・非テキストは変更なし。Web選択のコピー前に削除対象を保持。完全一致、正規表現なし。
- 初期ホットキーは⌥⇧⌘D。⌃⇧はDefault Folder X用のため使用しない。
- 共通HotkeyFieldに既定OFFの列揃えオプションを追加し、MightyEditでのみ有効化。
- 日英中韓の表示・ヘルプと更新履歴を更新。英語の既存Dock説明を生成元へ復元。
- ビルド時に同期されるSettingsSyncの生成コピーを共通ソースと一致させた。今回のアプリでは設定保存名は変わらない。
