# 選択したテキストをその場で整えるMac用パレット「MightyEdit」

改行の整理やリストへの変換、全角・半角の統一など、文章を整えるときの操作をひとつのパレットにまとめました。

ほかのアプリで編集可能な文字を選び、MightyEditのボタンを押すと、その場で選択範囲を置き換えます。加工後の再選択にも対応していますが、入力欄によっては利用できない場合があります。

## できること

- 行の編集：改行や空白行の削除、並べ替え、シャッフル、重複行の削除、指定文字数での改行
- リスト：番号、箇条書き、丸数字、英字、Markdownなどへの変換
- 文字の整形：全角・半角、和欧間のスペース、句読点などを整理
- 欧文：タイトルケース、camelCaseなどへの変換
- 日付：西暦・和暦や日付表記の変換、曜日の追加
- 桁区切りのカンマ、行末の句点、選択範囲の数値の合計

## 表示を自分に合わせる

パレット上部で「アイコン＋テキスト」「アイコンのみ」「テキストのみ」を切り替えられます。「超簡易」「簡易モード」「全部入り」それぞれの表示項目を環境設定で指定できます。

ホットキーの変更や、指定したアプリが前面になったときのパレット自動表示にも対応します。自動表示はMightyEditが起動している間に動作します。

## 動作環境と試用版について

MightyEdit 0.1.27（ビルド28）。macOS 13以降、Apple Silicon搭載Mac用です。Intel Macには対応しません。

現在は未公証の試用版です。Apple Distribution署名はありますが、Developer IDによる公証は未実施で、Gatekeeperの評価は拒否となります。ダウンロード後の通常起動は制限される場合があります。

選択文字を操作するため、アクセシビリティの許可が必要です。独自エディタや読み取り専用の文章には対応しない場合があります。プレーンテキストで置き換えるため、文字の装飾を保持できない場合があります。
