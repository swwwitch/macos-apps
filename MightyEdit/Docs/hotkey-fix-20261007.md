# ホットキー修正 0.1.55 (67)

対象: Control+6 / Control+7 の実行失敗報告。

- 登録は有効、一時停止なし。設定画面に登録エラーなし。
- 旧処理は HotKeyReleased 後に1秒以内に修飾キーを離さないと黙って中止していた。
- HotKeyPressed で受け付け、キー本体と修飾キーのセッション状態を確認して離した後に1回だけ実行する。
- キー長押しのタイムアウトを撤廃。前面アプリ変更・無効化・再登録では待機を中止する。
- 機能ホットキーでは検証済みの前面アプリを対象として設定し、以前のパレット対象が残る影響を避ける。

検証:
- HotkeyReleaseGateTests: Control長押し、重複抑止、一度だけ実行、アプリ変更、無効化、設定変更のキャンセルが成功。
- PaletteTargetSessionTests 成功。既存変換テスト実行ファイル: 170変換 / 19整形 / 23日付ケース成功。
- 署名付きビルド成功。Applications / Latest Builds の署名、バージョン、内容一致確認。Applicationsから起動確認。
- 実キーボードによる Control+6 / Control+7 と対象アプリでの置換結果は未確認。今回報告の原因が1秒制限であることまでは特定していない。

## 応答速度の調整 0.1.56 (68)

ユーザーより67では実行できたがボタンより遅いと報告。修飾キーを待つ処理を外し、トリガーの数字キーが離れた時点で実行する。確認間隔は10ms。貼り付けは既存のprivateStateとCommandのみのイベントフラグを保持する。二重実行抑止・アプリ切替キャンセルのテスト成功。対象アプリでControlを押したままの貼り付け動作・体感速度は未確認。
