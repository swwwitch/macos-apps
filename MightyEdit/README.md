# MightyEdit

macOS 13以降で動作する、Swift / AppKit製の常駐テキスト加工パレット。0.3.4 (build 117)。UIは日本語・英語・簡体字中国語・韓国語に対応（macOSの言語設定に従い、それ以外の言語では英語）。
`MightyEdit.app`を開き、ほかのアプリの編集可能な文字を選択してボタンをクリックします。

- **改行を削除**：空行（スペース・タブだけの行を含む）を区切りとして残し、本文の改行だけを削除して連結。スペースは補いません。
- **すべての改行を削除**：空行を含め、選択範囲の改行をすべて削除して連結。
- **番号付きリスト**：空行を除く各行に `1. `、`2. `…を付加。
- **箇条書き**：空行を除く各行に `・` を付加。
- **白丸数字**：空行を除く各行に `① `、`② `…を付加。50まで丸数字、51以降は `(51) ` 形式。
- **英字番号（A.）**：`A. `〜`Z. `、以降は `AA. `、`AB. `…を付加。
- **Markdown箇条書き**：空行を除く各行に `- ` を付加。
- **リスト記号を削除**：行頭の番号や箇条書き記号を除去し、本文・空行・インデントを保持。

「番号付きリスト」「箇条書き」「Markdown箇条書き」「リスト記号を削除」は「白丸数字」「英字番号（A.）」とともにパレットの「リスト」グループに3列でまとめています。

## ホットキー

設定の検索欄で機能名・現在のホットキー（記号／Control・Option・Command等の名前）を検索できます。欄のクリックですぐキー入力待ちになり、［変更］ボタンはありません。

- ⌃⌥⌘,：カンマを付ける
- ⌃⌥⌘.：カンマを取る
- ⌃⌥⌘=：数値を合計（JISでは＝の入力にShiftも使用）

- Control＋1：番号付きリスト
- Control＋3：白丸数字
- Control＋4：英字番号（A.）
- Control＋6：箇条書き
- Control＋7：Markdown（`- `）
- Control＋-：正負反転
- Control＋Option＋1：日付スペシャル

対象アプリで文字を選び、キーを押して離すと実行します。初期値の適用範囲「すべてのアプリ」ではパレットが非表示でも動作します。
各ホットキーには適用範囲があります。設定のホットキーで操作名の下のポップアップから「すべてのアプリ」（初期値、従来どおり）か「パレット表示中のみ」を選ぶと、すぐ保存されます（キーの「適用」は不要）。メニューバーの「ホットキー」の各操作のサブメニューでも選べ、「パレット表示中のみ」の操作には「（パレット表示中のみ）」と表示します。「パレット表示中のみ」のキーはパレットを隠している・閉じている間は登録せず、前面のアプリでそのキー本来の操作が働きます。パレットを表示すると登録し、キーを離した時点でパレットが隠れていれば何もしません。ホットキー全体の有効／無効・一時停止・各操作の無効化・対象外アプリの扱いは適用範囲にかかわらず同じです。同じキーの重複はパレットを隠している間も検出して表示します。「割り当てを初期値に戻す」は適用範囲も「すべてのアプリ」に戻します。UserDefaultsの `shortcutScope-<操作ID>`（`global`／`palette`）に保存し、キーがない場合は `global` として扱います。
メニューバーの「ホットキー」でControl＋数字への変更・各操作の無効化・全体の有効／無効・一時停止・割り当て初期化ができます。設定は保存され、一時停止だけは再起動で解除されます。
同じキーの重複割り当ては選べません。登録失敗はメニューにエラー表示します。Mission Controlなどとの全競合は検出できないため、反応しない場合は割り当てを変えてください。

加工後は、置換結果を確認してその文字を選択し直します。アクセシビリティによる選択範囲の変更に対応する入力欄が対象です。別アプリ・入力欄への移動や選択変更を検出した場合は選択を戻しません。結果が空の場合はカーソルだけが残ります。コピーのみのモードでは選択を変更しません。

空行・行末改行・行頭のインデントはリスト加工時に保持します。
既存の番号（`1.`、`１．`、`1)`、`（1）`、`1、`、`①`〜`㊿`）や箇条書き記号（`・`、`●`、`○`、`•`など）を取り除いてから付け直します。
`- `、`* `、`+ ` は直後に空白がある場合に取り除きます。重複した記号も除去し、記号だけの行は空行にします。
小数（`3.14`）や本文中の記号は保持します。行頭の番号・記号はリストとして扱うため、本文として残したい行は選択範囲から外してください。

## 初回の許可

メニューバーの「文字」アイコンから「アクセシビリティ設定を開く…」を選び、
システム設定 → プライバシーとセキュリティ → アクセシビリティでMightyEditを許可してください。
一覧に出ない場合は＋ボタンからこのフォルダの `MightyEdit.app` を追加します。

パレットは前面に常駐し、クリックしても対象アプリをアクティブのまま保ちます。
「起動・常駐」の「ウインドウを閉じても常駐」がオン（初期値）のとき、閉じるボタンはパレットを隠すだけで、メニューバーから再表示・終了できます。オフでは閉じるボタンで終了します。
位置は保存されます。ログイン時の自動起動は設定しません。

## 対応範囲

アクセシビリティAPIで選択文字と選択範囲を取得できる編集欄が対象です。
パスワード欄、読み取り専用の文章、独自キャンバスなどでは使えない場合があります。
選択文字が取得できない場合、全文コピーなどの代替操作は行いません。
Webページ・Electronアプリ（Safari・Chrome・Firefox・Notion・Googleドキュメントなど）の入力欄では、選択文字を⌘Cで取得します（アクセシビリティの選択位置がずれる・ダミーの欄しか見えないため）。加工結果を貼り付けた後は⇧←で結果を選択し直します。この場合、続けて押したホットキーは実行しません。

置換には対象アプリへの⌘Vを使います。通常の貼り付けとして扱われるため、取り消しや書式の扱いは対象アプリに依存します。
プレーンテキストの貼り付けです。選択範囲内の文字ごとの装飾は維持されない場合があります。
クリップボードを一時使用し、1秒後に元の取得可能なデータを戻します。
その間に別のコピーが行われた場合は上書きしません。応答が遅いアプリでの貼り付けは要確認です。
表示する「貼り付けを送信しました」はイベント送信を示し、対象アプリでの置換成功を検証した表示ではありません。
メニューの「置き換えずにコピー」で加工結果だけをコピーすることもできます。

## 開発

```sh
zsh build.sh
zsh test.sh MightyEdit.app
```

`test.sh` は全ユニットテスト（TextTransform・HTML Minifier/Beautifier・LineTools・ExcludedApps・HotkeyScope・HotkeyReleaseGate・PaletteTargetSession・グリッド）と翻訳チェック `Tests/check-localization.py` を実行します。個別に実行する場合は、UI文言を参照するファイルと一緒に `Source/Localization.swift Source/LocalizationFallback.swift` もコンパイルします（例：`xcrun swiftc -parse-as-library Source/LineTools.swift Source/HTMLMinifier.swift Source/TextTransform.swift Source/TypographyOption.swift Source/DateTransform.swift Source/Localization.swift Source/LocalizationFallback.swift Tests/TextTransformTests.swift -o /tmp/textpalette-tests`）。

UI文言は `make-resources.py` の1つの表（キー｜日本語｜英語｜簡体字中国語｜韓国語）で管理し、`Resources/<言語>.lproj/Localizable.strings`・`Help.txt`（元は `Localization/Help/<言語>.txt`）と、テスト用の日本語表 `Source/LocalizationFallback.swift` を生成します。build.shが毎回生成し、`.lproj` をバンドルへコピーします。

ビルドにはXcode Command Line Toolsを使用。0.1.5以降は既存のApple Distribution証明書でローカル署名し、Bundle IDを保持します。署名に失敗した場合はビルドを中止し、アドホック署名に戻しません。証明書の指定は `MIGHTYEDIT_SIGNING_IDENTITY` で変更できます。公証・Developer IDによる外部配布は未対応です。

### 許可ダイアログボックスが繰り返し出る／オンなのに使えない

0.1.5では加工ボタンからOSの許可ダイアログボックスを出す処理を削除しました。パレットの設定ボタンでシステム設定を開きます。
旧版は更新ごとに変化するコードハッシュによるアドホック署名でした。今回の署名切り替え後は一度、古い登録を削除し、現在のアプリを＋で登録し直す必要がある場合があります。
メニューの「許可するアプリをFinderで表示」で起動中の実体を確認してください。通常は `Latest Builds/MightyEdit.app` を使い、バックアップから起動しないでください。
許可は自動で再確認します。反映されない場合はMightyEditを終了し、同じ場所から起動し直してください。
実装参考：[Apple NSPanel](https://developer.apple.com/documentation/AppKit/NSPanel)。

## 桁区切り

- ⌃⌥⌘,：カンマを付ける（`1234567.89` → `1,234,567.89`）
- ⌃⌥⌘.：カンマを削除（`1,234,567.89` → `1234567.89`）

選択範囲内の半角数値が対象です。符号、小数部分、周囲の文字、改行は保持します。数値に変換せず文字列として加工するため、長い数値も丸めません。桁区切りとして正しいカンマだけを扱い、文章中のカンマや `1,2,3` のような並びは変更しません。CSV解析・小数点にカンマを使う表記・全角数字には対応しません。
ホットキーの変更候補にControl＋,とControl＋Option＋,を追加しました。既存のキー設定は保持します。

## 改行・その他

- **空白行削除**：スペース・タブだけの行を含めて空行を削除。
- **1行おきに空行**：既存の空行を整理し、各本文行の間に空行を1つ配置。繰り返し実行しても増殖しません。
- **末尾に。を付ける**：空行を除く各行末に「。」を付加。既存の「。」は重複させません。
- **末尾の。を削除**：各行末の「。」を削除。文中の「。」は保持。

本文のインデント・行末スペースは保持します。空行整理時、元の末尾に改行があれば1つ保持します。これらの操作では改行コードをLFに統一します。

## 括弧付きのリスト

- `［1］ バナナ`、`［2］ りんご`…（0.2.24でControl＋Option＋1を日付スペシャルへ移し、初期値はなし）
- Control＋Option＋4：`［A］ バナナ`、`［B］ りんご`…

通常のリストと同様、既存の記号は除去して付け直します。括弧付き形式も「リスト記号を削除」で解除できます。既存のホットキー設定は保持します。

## Minify（空白圧縮）

「改行」カテゴリのMinifyは、選択範囲全体の改行（CR、LF、縦タブ、フォームフィード、Unicode改行区切り）・タブを削除し、連続する半角スペースを1つにまとめます。`<br>`・`<br />`タグや文字参照、全角スペースは残します。前後の半角スペースも1つまでは残します。
HTMLを解析・再構成する処理ではなく、指定の空白整理を文字列全体に適用します。コード・属性値内の空白も対象です。

## 文字の整形

- **全角英数字を半角に**：全角のA〜Z・a〜z・0〜9のみ変換。記号・全角スペース・カナは保持。
- **半角カナを全角に**：半角カナを全角に変換。濁点・半濁点を結合し、半角カナ用句読点・括弧も変換。英数字は保持。
- **和欧間のスペースを削除**：日本語（漢字・かな）と半角英数字の境目の半角／全角スペースを削除。
- **和欧間にスペース追加**：同じ境目を半角スペース1つに統一。

英単語同士・日本語同士のスペース、改行コード、タブは保持します。括弧や句読点をまたいだスペース調整はしません。これらのボタンには既定のホットキーを割り当てていません。
ボタンは3列で折り返し、収まらないカテゴリはパレット内でスクロールできます。

## 数値を合計

「その他」の「数値を合計」は、選択内の半角・全角の数字を抽出し、元の文章を残して空行と `合計：…` を追記します。小数、正負の符号、3桁区切りのカンマに対応します。原文と元の改行コードを保持し、すでに末尾に空行があれば追加の空行を増やしません。
10進数で計算し、精度の上限・加算時の丸め／桁あふれを検出した場合は文章を変更せず案内します。数字がない場合も同様です。
項目番号、日付、前回追記した合計なども選択内にあれば加算対象です。漢数字・単位換算・数式評価は対象外です。

## 正負反転

「その他」の「正負反転」は、各行の先頭（インデントの後）にある数値の正負を反転します。`12` → `-12`、`-3.5円` → `3.5円`、`+7` → `-7`。2つ目以降の数値・行の残りの文字・インデントは変更しません。
半角・全角の数字、3桁区切りのカンマ、小数に対応します。マイナスは `-`・`−`・`－` を取り除き、付けるときは半角の数字には `-`、全角の数字には `－` を使います。`0`・`0.00` など値が0の数値と、先頭が数値でない行はそのままです。
ホットキーの初期値はControl＋-です。

## 欧文

- **全角に／半角に**：ASCII英数字・記号・スペースと全角の対応文字を相互変換。日本語・カナ・改行・タブは保持します。
- **単語ごとに大文字**：英語（A〜Z）の各単語の先頭を大文字、残りを小文字にします。`the art of design` → `The Art Of Design`。
- **タイトル（title-case）**：各行を見出しとして、先頭・末尾・コロンやダッシュ後の先頭語を大文字にし、途中の冠詞・接続詞・主な前置詞を小文字にします。`the art of design` → `The Art of Design`。

単語の判定は半角英字が対象です。略語・固有名詞の特別扱いは行いません（`NASA` → `Nasa`）。ハイフン区切りは別の語、アポストロフィを含む短縮形は一語として扱います。タイトル形式はアプリ内の固定ルールで、特定の出版スタイルへの完全準拠ではありません。

## その他のリスト

「リスト」の「その他のリスト」で別ウインドウを開き、種類のラジオボタンをクリックすると即座に適用します。選択した種類は保存されます。プレビューはサンプルです。対象アプリで選択した現在のテキストに適用します。
黒丸数字（❶〜⓴）、漢数字（一、二、三、）、大字（壱 弐 参、十は拾）、丸囲み英字（Ⓐ〜Ⓩ）、ローマ数字（I. / i.）、✓、□、✅、Markdownタスクリスト（- [ ]）に対応します。空行・インデントを保持し、既存のリスト記号を除去して付け直します。チェック済みのMarkdownも未チェックに置き換えます。
黒丸数字の21以降・丸囲み英字の27以降・ローマ数字の4000以降は(21)のような数字形式になります。漢数字は十・百・千・万・億・兆で表します。

## ボタンの表示

メニューバーの「文字」→「ボタンの表示」で「アイコン＋テキスト」「アイコンのみ」「テキストのみ」を選べます。表示設定は保存されます。アイコンのみでもマウスオーバーで機能名を確認できます。パレットは幅を狭くし、ラベルを最大2行で表示します。

## 行の整理と文字数での折り返し

「行を並べ替え」は行単位の昇順で数字の大小を考慮します（item2 → item10）。すでに昇順の選択範囲は降順にします。加工後の選択を保ってもう一度押すと、昇順・降順が切り替わります。空行も並べ替えます。「重複行を削除」は完全に一致する行について最初の1行を残し、順序を保持します。行頭・行末のスペースや大文字・小文字の違いは別の行として扱います。
「指定した文字数で改行」は小ウインドウで文字数を選び、▲▼で1文字ずつ調整して適用します（1〜10,000文字、初期値40）。文字数は保存されます。各行を指定文字数で折り返し、既存の改行・空行は残します。絵文字や結合文字も1文字として数えます。英単語の途中でも指定文字数で折り返します。
「区切り文字で改行」は小ウインドウで区切り文字（初期値「、」）を入力して適用します。区切り文字のところで改行し、区切り文字と前後のスペース・タブは削除します（「区切り文字を行末に残す」で残せます）。「行頭に付加」に入れた文字は空行以外の各行の先頭に付けます（`Mac macOS アプリ開発` を区切り文字スペース・行頭に付加 `#` で `#Mac`／`#macOS`／`#アプリ開発`）。入力値は保存されます。`BrowserSwitcher、BundleIDInspector、CarmaChameleon` → 3行。
「改行をスペースに」は空行を区切りとして残し、本文の行を半角スペース1つで連結します。連結する境目にあるスペースやタブは1つのスペースに揃えます。従来の「改行を削除」はスペースを入れずに連結します。

## ランダムとウインドウサイズ

「行をシャッフル」は選択した行をランダムに並べ替えます。行の内容・重複行・空行は残します。偶然、同じ順序になることもあります。ウインドウの端をドラッグして縦横にリサイズでき、横幅に応じて全カテゴリのボタン列数が変わります。サイズと位置は保存されます。

## 日付

「日付」の「年月日 ↔ yyyy-mm-dd」は、選択テキスト内のyyyy年mm月dd日とyyyy-mm-ddを相互変換します。月日は2桁に揃えます（2026年1月2日 → 2026-01-02）。複数の日付や両形式が混在する文章も一度に変換できます。周囲の文章・改行は保持し、存在しない日付は変更しません。半角数字と西暦0001〜9999年を対象とし、スラッシュ形式・和暦・全角数字は変換しません。

## 日付スペシャル

「日付」の「日付スペシャル」（Control＋Option＋1）は、選択テキスト内の日付をさまざまな形式に変換した候補を、ポインタの位置にメニューで表示します。選んだ候補で選択範囲を置き換えます。候補はグループごとに区切り線で分けます。`2026/10/14` の場合は次のとおりです。

- 西暦：2026年10月14日、2026年10月14日（水）、2026年10月14日（水曜日）、2026年10月14日 水曜日
- 和暦：令和8年10月14日、令和8年10月14日（水）、令和8年10月14日（水曜日）
- 和暦の略記：R8.10.14、R8/10/14
- 月日：10月14日（水）、10月14日（水曜日）、10/14（水）
- 数字：2026-10-14、2026/10/14、2026/10/14（水）、2026.10.14、20261014
- 英語：Oct 14, 2026、October 14, 2026、Wed, Oct 14, 2026
- 全角・漢数字：２０２６年１０月１４日、二〇二六年十月十四日、令和八年十月十四日

月日は0を付けない形（2026年1月2日）で表示します（yyyymmddを除く）。
「日付スペシャル（ゼロ埋めあり）」は同じ候補に、0を付けた形（2026年01月02日、令和8年01月02日、R8.01.02、2026/01/02など）を加えて表示します。月日が1桁の日付では、西暦・和暦・略記・数字の各形式を0付き→0なしの順に並べます。月日のグループと全角・漢数字は0なしだけです。ホットキーの初期値はありません。
変換元は、ほかの日付変換が対象とする形式（yyyy年m月d日、yyyy-m-d、和暦、m月d日、m-d、曜日付き）に加え、`yyyy/m/d`、`yyyy.m.d`、`yyyymmdd`、`m/d` です。追加の4形式は存在する日付だけを変換し、`12345678` や `2026.2.30` などはそのまま残します。年のない日付は今年として扱います。曜日付きの日付からは曜日のない形も候補にします。
選択内に複数の日付があれば、すべてを同じ形式にした文章を候補にします。和暦は明治6年（1873年）以降が対象で、それより前の日付は和暦の候補を出しません。選択と同じ結果や重複する候補は表示しません。日付がない場合は「日付が見つかりません」と表示します。
メニューを開いた後に選択が変わっていた場合は置き換えず、もう一度メニューを表示します。

## camelCase（先頭小文字）

「camelCase（先頭小文字）」はhello world → helloWorldのように、先頭の単語を小文字にして以降の単語の先頭を大文字にします。半角英数字を対象に、単語間の半角スペース・タブ・ハイフン・アンダースコアを取り除いて連結します。HelloWorldやXMLHttpRequestもhelloWorld・xmlHttpRequestに揃えます。改行・行頭のインデント・日本語・区切り以外の記号は保持します。

## 指定アプリで自動表示

## 対象外アプリ

設定の「対象外アプリ」タブ（共通部品 Shared/ExcludedApps）で、MightyEditを働かせないアプリを指定できます。「追加…」で/Applicationsからアプリを選び、一覧の行を選んで「削除」で外します。一覧はMacごとの設定で、書き出し・同期の対象外です。一覧にはアプリのアイコンと名前、Bundle IDを表示します。アプリはBundle IDで識別し、同じアプリやMightyEdit自身は追加できません（理由を表示します）。一覧は保存され、再起動・更新後も保持します。アプリを削除した場合は「アプリが見つかりません」とBundle IDを表示します。一覧から外してもアプリ本体には影響しません。
対象外のアプリが前面にある間は、機能とパレット呼び出しのホットキーを解除し、キー操作をそのアプリへそのまま通します。MightyEditの設定などMightyEdit自身が前面のときも同様に解除します。ほかのアプリへ切り替えると再び有効になります。
加工の直前（キーを離したとき・ボタンを押したとき・貼り付けの送信前）にも前面のアプリを確認し、対象外なら選択文字の読み取りも貼り付けも行わず、パレットに「対象外のアプリのため実行しません」と表示します。メニューバーからパレットを表示した場合も、対象が対象外のアプリなら同じ理由を表示し、パレットを薄く表示します。自動表示に登録していても、対象外のアプリではパレットを自動表示しません。
