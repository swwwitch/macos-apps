# BrowserSwitcher アイコン

正本はマスタード色の角丸タイル、茶色の地球儀、白い塗りの矢印。銀色・グレーの外側タイルは削除し、周囲は透過。

BrowserSwitcher-icon.pngを各サイズへ変換したBrowserSwitcher.icnsを、アプリと画面ヘッダーの両方で使用。

built-in image_genによる編集指示：銀色の外側タイルと影を除去。内側のマスタードタイル・茶色の地球儀・白い矢印を保持し、周囲を透過、正方形キャンバスへ中央配置。

シリーズ調整：ExtLink/Assets/ExtLink-Mustard.iconset/icon_512x512@2x.png と Shared/DesignAssets/app-icons-mustard-final.png を参照。built-in image_genでマスタードと茶色、角丸、余白、質感を近づける。地球儀と白い矢印、外側透過を保持。
