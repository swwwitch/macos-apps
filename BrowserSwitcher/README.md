# BrowserSwitcher 1.6.27（ビルド47）

通常配布版はmacOSのNSWorkspace APIでHTTPとHTTPSの既定ブラウザーを変更します。Homebrew、defaultbrowser、Keyboard Maestroは不要です。macOSの確認が表示された場合は許可してください。両方の設定を読み直して一致した場合のみ成功を表示します。

一覧のクリックと矢印キーは選択のみです。「切り替える」、⌘Return、⌘クリックまたはダブルクリックで実行します。設定の「起動・常駐」では、ログイン時に起動、起動時にメインウインドウを表示しない、メニューバーへの表示、アプリを呼び出すホットキーを設定できます。「表示」では一覧から除外するブラウザーを設定できます。

初期の呼び出しキーはControl＋Option＋Qの2回押し（0.4秒以内）です。変更した呼び出しキーも2回押しで動作します。Esc／⌘Wで非表示、⌘Qで終了します。

ヘルプはヘルプメニューの「BrowserSwitcherヘルプ」（⌘?）から開けます。メニュー名と本文はアプリの言語（日本語・英語・簡体字中国語・韓国語、ほかの言語は英語）で表示します。本文は`Localizations/<言語>.lproj/Help.txt`にあり、`python3 check-localization.py`で4言語のそろいを検証します（build.shでも実行）。見出し（`##`・`###`）、箇条書き（`- `）、手順（`1. `）、強調（`**…**`）は共通部品`HelpDocument.swift`で整形して表示します。ヘルプメニューの「note記事を開く」は、Info.plistの`SWNoteArticleURL`（現在はサポートマガジン）を開きます。

`./build.sh`で通常配布版をビルドし、Latest Buildsへ検証済みコピーを配置します。

App Sandboxでは既定アプリの変更が制限されるため、この直接切り替え機能はApp Store版の動作保証を意味しません。

## 検証状況（2026-10-04）

ビルド・コード署名検証済み。通常配布版1.6.7（ビルド16）でSafariからFirefoxへの変更後、HTTPとHTTPSの両方がorg.mozilla.firefoxであることを診断コマンドで確認しました。アプリにも「Firefox に切り換えました。」と表示されています。

設定からHomebrew/defaultbrowserの依存・導入画面を削除しています。macOSが変更の確認を表示した場合はユーザーが許可してください。

## メニューバーへの追加

初回案内で「メニューバーに追加」を選ぶとモノクロアイコンを表示します。「追加しない」「あとで」も選べます。後からアプリメニューの「メニューバー設定…」で変更できます。ログイン起動とは独立した設定です。アイコンを非表示にしてもアプリは終了しません。
