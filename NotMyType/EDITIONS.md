# NotMyType プロ版・Lite版の違い

最終更新：2026-10-26。対象ソース：プロ版1.61.2（100）、Lite版1.8.2（24）。公開済み版の仕様を保証する表ではありません。

プロ版の正式名は「NotMyType」です。両版のライブラリと設定は別々に保存されます。

## 両版でできること

- フォントファイル・フォルダーを登録し、ファミリー・書体・複数選択でアクティブ／解除。
- 不可視のファイル・フォルダー内のフォントを読み込む（OH MY FONTなど）。不可視属性は変更しません。
- セットの作成・編集、フォントの追加・取り外し、一覧からセットへのドラッグ＆ドロップ。
- 条件を指定するカスタムスマートセット。
- フォント検索と検索オプション、カテゴリ切替時の検索解除（Option＋クリックでは検索を保持）。
- 検索条件があるとき、検索オプションボタンのOption＋クリックで条件を全解除。
- プレビュー、字形一覧、配色・カーニング・トラッキングなどの調整。
- 重複フォントの確認・解決、ウォッチフォルダー、ライブラリ再構築、フォントキャッシュ消去。
- ライブラリ共有と設定同期、ログイン起動、アプリを呼び出すホットキー。
- ツールのリンク集と、ユーザーが追加するカスタムリンク。
- macOSに登録されているAdobe Fontsの一覧表示。

## 主な違い

| 機能 | プロ版 | Lite版 |
| --- | --- | --- |
| お気に入り | あり | なし |
| プロジェクト管理 | あり。制作ファイル・フォルダー・フォント名を参照 | なし |
| プロジェクトへの追加・取り外し、ドラッグ＆ドロップ | あり | プロジェクト機能なし |
| macOSのフォントコレクション | あり | なし |
| ベンダー別・種類別のサイドバー | あり | なし |
| サイドバー区分の表示・並び順の設定 | あり | なし |
| 公式フォント情報（FontDB） | あり | 同梱しない |
| ベンダーによる検索オプション | あり | なし |
| FontDBに基づく分類・リリース年の絞り込み | あり | なし |
| Adobe Fontsのアプリ内ON／OFF | インストール済みフォントに対応 | 一覧表示のみ。切替はCreative Cloudで操作 |
| Adobeアプリの不足フォント自動アクティベート | あり（設定で有効化） | なし |
| フォントを点検 | あり | なし |
| Illustrator・InDesignのフォントを統一 | あり | なし |
| FontExplorer X Proのセット読み込み | あり | なし |
| 最近アクティブ・最近非アクティブ・最近追加の標準スマートセット | あり | なし |
| フォント保存フォルダーを開くデバッグメニュー | リンク集内。Option押下時のみ表示する実装 | なし |

Adobe FontsのON／OFFはCreative Cloudでインストール済みのフォントが対象です。未登録キャッシュを直接登録する機能とは区別します。macOSの保護対象など、すべてのフォントを自由に解除できるわけではありません。

## 記録の扱い

- 本表は現行ソース、両版README、メニュー構成を照合して作成。全項目を今回実機で再検証したという意味ではありません。
- プロ版99のデバッグ通常非表示は確認済み。Option押下中の表示確認は残っています。
- 更新履歴とビルド・公開状態は [CHANGELOG.md](CHANGELOG.md) に記載します。
- 機能差が変わったら本表と両版READMEを同時に更新します。

両通常配布版のキャッシュ消去確認画面は一覧だけがスクロールし、見出しと下部操作を保持します（1.61.2／100、1.8.2／24）。App Store版のキャッシュ機能削除とは別です。

## 2026-10-27 検証版101の追加差分

- フル版のみ：字形の右クリックコピー（文字＋フォント情報／輪郭PDF）、一覧右クリックと右下のアクティブ操作トグル、起動中のPath Finderでデバッグフォルダーを開く。
- OH MY FONTの不可視表示には手動案内となる場合があります。実機検証の範囲はCHANGELOG.mdに記載。Liteへは未適用。


2026-10-27 検証版：アクティブ／非アクティブのトグル操作と処理進捗は両版で対応。字形の右クリックコピーと16分類はフル版のみ。Illustratorへのフォント保持は実機未確認。

2026-10-28：通常版1.63.0（103）にカード表示を追加。共通テキスト・文字サイズで書体を比較し、検索・カテゴリを適用。Lite版にはカード表示なし。

2026-10-28：通常版1.63.1（104）は、カードのダブルクリックで同じウインドウ内の単独プレビューへ回転切替。日本語／英語／カスタム、行間・カラム数の調整に対応。戻る／Escで一覧へ復帰。Lite版には含まれません。

- 2026-10-29（未ビルド）：カードの5段階レーティング・評価別フィルター・数字キーによる評価は通常版のみ。Lite版には追加しない。

- 2026-10-30：通常版の評価フィルターは指定評価以上。未評価は0だけ。Lite版は変更なし。
